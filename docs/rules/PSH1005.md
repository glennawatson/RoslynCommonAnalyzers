# PSH1005 — Structs should define equality members to avoid boxing comparisons

| Item | Value |
| --- | --- |
| Package | PerformanceSharp.Analyzers |
| Category | Allocations |
| Severity | Warning |
| Code fix | Yes, for supported declarations |
| Default | Enabled |

## Cause

A public or internal struct neither overrides `Equals(object)` nor implements
`IEquatable<T>` with itself as `T`. Record structs, `ref struct` types, and private
nested structs are not reported. Implementing equality with a different type does
not satisfy the rule.

The inherited equality method can box values: copy them into objects on the heap.
It can also inspect fields at runtime to compare them. Typed equality avoids this
work in operations such as list searches and dictionary lookups. The rule reports
the struct even if no comparison appears in your code.

## Example

Before:

```csharp
public struct Counter
{
    public int Count;
}
```

After, using the record conversion in C# 10 or later:

```csharp
public record struct Counter
{
    public int Count;
}
```

## Code fix

The available actions depend on the declaration and framework:

- **Convert to a record struct:** adds `record` and keeps the existing members.
  If the instance data is immutable, it also adds `readonly`. This requires C# 10
  or later. Record structs supply equality members and also change `ToString()`
  to print member values.
- **Implement IEquatable:** adds `IEquatable<T>`, typed `Equals`, overrides of
  `Equals(object)` and `GetHashCode()`, and `==` and `!=` operators. It compares all
  instance fields and automatic properties using `EqualityComparer<T>.Default`.
  Computed properties are excluded. This action requires C# 7 or later,
  `System.HashCode`, and at most eight data members.
- **Implement IEquatable and make the struct readonly:** makes the same additions
  and adds `readonly` when the data is immutable. This requires C# 7.2 or later.

No fix is offered when the declaration already contains `Equals`, `GetHashCode`,
`==`, or `!=` members, has directives within its body, or contains pointer data or
fixed buffers. Fix All is not available.

Review which fields should count toward equality. Write the members yourself when
some data must be ignored, and make `Equals` and `GetHashCode` use the same data.
For a partial struct, the IEquatable action uses only the fields and automatic
properties in the declaration being fixed. Review the other parts too, and apply
record conversion consistently to all parts. Convert a struct with a primary
constructor by hand: the record action drops its constructor parameter list.

## Configuration

The default severity is `warning`. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1005.severity = warning
```

Use `error`, `suggestion`, or `silent` to change the severity, or `none` to disable
the rule.

## When to suppress

Suppress when the struct is never compared, or every comparison uses a deliberate
custom comparer. This can avoid adding equality behavior that has no useful meaning
for the type.
