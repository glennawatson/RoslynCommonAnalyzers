# PSH1006 — Use ConcurrentDictionary factory parameters

| Item | Value |
| --- | --- |
| Package | PerformanceSharp.Analyzers |
| Category | Allocations |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A lambda passed to `ConcurrentDictionary<TKey, TValue>.GetOrAdd` or `AddOrUpdate`
uses the outside key variable instead of its own key parameter. Capturing an outside
local or parameter can create a closure, an extra object that holds that value.
The dictionary already passes the key to each factory.

The rule checks calls where the first argument is a local or parameter name and a
later argument is a lambda with at least one parameter. It also checks derived
dictionary types and overloads with a state argument. Named key arguments, key
expressions such as `holder.Key`, and `delegate` anonymous methods are not checked.
Capturing a value other than the key does not trigger this rule.

## Example

Before:

```csharp
using System.Collections.Concurrent;

public class Cache
{
    public string Get(ConcurrentDictionary<string, string> map, string key)
        => map.GetOrAdd(key, k => key.ToUpperInvariant());
}
```

After:

```csharp
using System.Collections.Concurrent;

public class Cache
{
    public string Get(ConcurrentDictionary<string, string> map, string key)
        => map.GetOrAdd(key, static k => k.ToUpperInvariant());
}
```

## How to fix violations

There is no code fix.

Replace uses of the outside key inside the lambda with its first parameter. Add
`static` in C# 9 or later if the lambda captures nothing else. For additional data,
use a state argument when the framework offers that overload.

## Configuration

The default severity is `warning`. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1006.severity = warning
```

Use `error`, `suggestion`, or `silent` to change the severity, or `none` to disable
the rule.

## When to suppress

Suppress when the lambda deliberately reads or changes the outside variable and
must observe it separately from the key value passed to the dictionary.
