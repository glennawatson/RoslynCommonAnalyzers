# PSH1009 — Bound variable-length stackalloc with a constant guard

| Item | Value |
| --- | --- |
| Package | PerformanceSharp.Analyzers |
| Category | Allocations |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A `stackalloc` uses a variable length without a recognized limit. A large input
can exhaust the stack and terminate the process. Check the length against a small
constant and use an array or a pool for larger inputs.

The rule does not report constant lengths, `static readonly` field lengths, or
lengths returned by a method named `Min` or `Clamp`. It also accepts an enclosing
`if` or `?:` condition that compares against a constant, including patterns such as
`length is > 0 and <= 512`.

These accepted forms do not prove the allocation is safe. The rule does not check
that the comparison limits this length or that the allocation is in the smaller
branch. It also does not impose a maximum constant size. Check the actual limit,
the element size, and whether the input can be negative.

## Example

Before:

```csharp
using System;

public class BufferExample
{
    public int GetLength(int length)
    {
        Span<byte> buffer = stackalloc byte[length];
        return buffer.Length;
    }
}
```

After:

```csharp
using System;

public class BufferExample
{
    public int GetLength(int length)
    {
        if (length < 0)
        {
            throw new ArgumentOutOfRangeException(nameof(length));
        }

        Span<byte> buffer = length <= 512
            ? stackalloc byte[length]
            : new byte[length];
        return buffer.Length;
    }
}
```

## How to fix violations

There is no code fix. Choose a limit suitable for the element type and use a heap
array or rented buffer above that limit. A preceding check that returns or throws
is not recognized as a bound; place the allocation inside the bounded branch.

## Configuration

The default severity is `warning`. There is no option for the allocation limit;
write that limit in your code.

```ini
[*.cs]
dotnet_diagnostic.PSH1009.severity = warning
```

Use `error`, `suggestion`, or `silent` to change the severity, or `none` to disable
the rule.

## When to suppress

Suppress when a caller or earlier validation guarantees a small, nonnegative
length that the rule cannot recognize. Document that limit and check it remains
safe for the element type and any repeated allocations before the method returns.
