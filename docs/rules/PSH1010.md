# PSH1010 — Clear reference-typed arrays when returning them to the pool

| Item | Value |
| --- | --- |
| Package | PerformanceSharp.Analyzers |
| Category | Allocations |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

`ArrayPool<T>.Return` receives an array whose elements can hold object references,
and `clearArray` is omitted or a constant `false`. A pool can keep returned arrays
for reuse. References left in their elements keep other objects alive too.

The rule covers reference types, structs containing references, and generic type
parameters constrained with `class`. It skips element types with no references,
such as `byte`, `int`, and unmanaged structs. Generic parameters without a `class`
constraint are also skipped. A `clearArray` value decided at runtime is not reported.

## Example

Before:

```csharp
using System.Buffers;

public class Buffers
{
    public void Return(string[] rented)
    {
        ArrayPool<string>.Shared.Return(rented);
    }
}
```

After:

```csharp
using System.Buffers;

public class Buffers
{
    public void Return(string[] rented)
    {
        ArrayPool<string>.Shared.Return(rented, clearArray: true);
    }
}
```

The array must have been rented from that pool. Clearing resets every element to
its default value when the pool keeps the array for reuse.

## Code fix

The fix adds `clearArray: true` when the argument is missing. If it is present as
a constant false value, the fix replaces that expression with `true`, keeping its
argument name and surrounding comments. Fix All is supported.

## Configuration

The default severity is `warning`. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1010.severity = warning
```

Use `error`, `suggestion`, or `silent` to change the severity, or `none` to disable
the rule.

## When to suppress

Suppress when all elements have already been cleared and clearing them again adds
measured cost. The rule does not check earlier clearing. Clearing only the portion
you used can leave references elsewhere in the rented array.
