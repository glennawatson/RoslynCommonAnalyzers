# PSH1013 — Expose constant UTF-8 data as a ReadOnlySpan<byte> property

**Category:** Allocations
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

A private `static readonly byte[]` field copies a UTF-8 literal with
`"..."u8.ToArray()` or `[.. "..."u8]`. A `ReadOnlySpan<byte>` property can return
the same bytes without creating an array. A span is a view of existing data.

The field must be declared on its own. Its uses must be limited to `Length`, element
reads, `foreach`, or arguments to `ReadOnlySpan<byte>` parameters. Assigning an element,
passing the field to a `byte[]` parameter, and other uses prevent the report.
Fields in partial types are not reported.

UTF-8 literals require C# 11; the collection form requires C# 12. The project must
provide `System.ReadOnlySpan<T>`.

## Example

Before:

```csharp
using System;

public class Protocol
{
    private static readonly byte[] Prefix = "v1:"u8.ToArray();

    public bool Matches(ReadOnlySpan<byte> input) => input.StartsWith(Prefix);
}
```

After:

```csharp
using System;

public class Protocol
{
    private static ReadOnlySpan<byte> Prefix => "v1:"u8;

    public bool Matches(ReadOnlySpan<byte> input) => input.StartsWith(Prefix);
}
```

## Code fix

The fix replaces the field with a property that returns the literal using `=>`.
It keeps the name and modifiers except `readonly`, and uses the full span type name
when needed. It preserves comments before and after the declaration, but drops
field attributes and comments inside the declaration. Review these before accepting it.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1013.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress when reflection or another tool requires the member to remain a field,
or when a required field attribute cannot be carried over to a property.
