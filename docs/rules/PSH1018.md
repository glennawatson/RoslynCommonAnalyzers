# PSH1018 — Do not build an array for a params parameter

**Category:** Allocations
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

The last argument of a method call is an explicit array passed to a `params`
array parameter. Passing the elements directly calls the same method.

For a non-empty array, the compiler still builds the array. Removing the explicit
array mainly shortens the call. For an empty array, omitting the argument lets
the compiler use a shared empty array when the framework provides one.

The rule reports `new T[] { ... }`, `new[] { ... }`, `new T[0]`, and
`Array.Empty<T>()` when the array type matches the parameter type.

## Example

Before:

```csharp
public class Logger
{
    public void Log(params object[] args) { }

    public void Write(object first, object second) =>
        Log(new object[] { first, second });
}
```

After:

```csharp
public class Logger
{
    public void Log(params object[] args) { }

    public void Write(object first, object second) => Log(first, second);
}
```

## What is not reported

- Calls that would select a different overload after removing the array.
- A single element that would become the whole array, such as an array value or `null`.
- An array with a different type, such as `string[]` passed to `params object[]`.
- Array variables, non-empty arrays without initializers, and collection expressions such as `[a, b]`.
- Calls with any named argument, or calls reached through `?.`.
- Parameters without `params`, or C# 13 `params` collections such as `ReadOnlySpan<T>`.

## Code fix

The fix removes the array wrapper and passes its elements as separate arguments.
Earlier arguments stay in place. An empty array argument is removed entirely,
so `Log(new object[0])` and `Log(Array.Empty<object>())` become `Log()`.
The fix formats the argument list. Comments around the array wrapper, elements,
or commas can be lost.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1018.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress when the explicit array makes a long call easier to read and removing
it brings no allocation saving. Keep an explicit empty array when the callee
requires a distinct array instance.
