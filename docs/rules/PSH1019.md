# PSH1019 — Slice arrays with AsSpan instead of the range indexer

**Category:** Allocations
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

A range such as `data[1..5]` copies part of a one-dimensional array, then passes
that copy as a `ReadOnlySpan<T>` or `ReadOnlyMemory<T>`. The same applies to a
local assignment or a return with one of those types.

`AsSpan` and `AsMemory` create views of the original array without copying its
elements. The rule reports only when the matching range overload is available
and the extension method can be called at that location. Range syntax requires C# 8.

## Example

Before:

```csharp
using System;

public class Parser
{
    public int Read(byte[] data) => Count(data[1..5]);

    private static int Count(ReadOnlySpan<byte> bytes) => bytes.Length;
}
```

After:

```csharp
using System;

public class Parser
{
    public int Read(byte[] data) => Count(data.AsSpan(1..5));

    private static int Count(ReadOnlySpan<byte> bytes) => bytes.Length;
}
```

## What is not reported

A slice kept as an array is not reported. Neither is a slice converted to
`Span<T>` or `Memory<T>`: writing through a view would change the original array.
Ranges on strings or existing spans are also excluded.

## Code fix

The fix replaces `data[range]` with `data.AsSpan(range)` for a `ReadOnlySpan<T>`
destination, or `data.AsMemory(range)` for a `ReadOnlyMemory<T>` destination.
The range stays the same. Comments around the removed brackets or range can be lost.

The result shares the original array. Read-only access prevents writing through
the view, but changes made through another reference to the array remain visible.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1019.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress when the caller needs a snapshot that must not reflect later writes,
or when keeping a small slice would keep a much larger source array alive.
