# PSH1020 — Prefer a jagged array over a multidimensional one

**Category:** Allocations
**Severity:** Warning
**Code fix:** None

## Cause

An array declaration or creation has two or more dimensions, such as `int[,]`
or `int[,,]`. The rule recommends a jagged array, such as `int[][]`, for faster
indexing in loops. A jagged array is an array whose elements are separate row arrays.
Measure the difference on your target runtime before changing a large data structure.

Reported declarations include fields, locals, parameters, properties, and method
or delegate return types. Array creations include `new int[3, 4]` and
`new[,] { { 1, 2 }, { 3, 4 } }`.

One-dimensional and jagged arrays are not reported. Neither are multidimensional
types inside casts, `typeof`, or generic arguments such as `List<int[,]>`.
An array that mixes jagged and multidimensional parts can still be reported.

## Example

Before:

```csharp
public class Grid
{
    public int Read()
    {
        int[,] grid = new int[3, 4];
        return grid[0, 0];
    }
}
```

After:

```csharp
public class Grid
{
    public int Read()
    {
        int[][] grid = new int[3][];
        for (int row = 0; row < grid.Length; row++)
        {
            grid[row] = new int[4];
        }

        return grid[0][0];
    }
}
```

## Why there is no code fix

There is no automatic code fix. Changing the array requires edits to each
allocation, index operation, and caller. Every row must be allocated.
`grid.Length` becomes the row count, not the total element count;
use `grid[row].Length` for a row's length. Rows can have different lengths,
so code that needs a rectangle must keep them equal.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1020.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress when an API requires a multidimensional array, or measurements favor
the rectangular form. A jagged array creates an extra object for every row,
and its rows are not stored together. That cost can outweigh faster indexing
for a small or short-lived grid.
