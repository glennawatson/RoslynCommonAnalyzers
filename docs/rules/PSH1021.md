# PSH1021 — Do not force garbage collection

**Category:** Allocations
**Severity:** Warning
**Code fix:** None

## Cause

Code calls `System.GC.Collect` or `System.GC.WaitForPendingFinalizers`.
Calls written as `GC.Collect()` or `System.GC.Collect()` are reported,
including overloads with arguments. Calls on unrelated types named `GC` are excluded.

The runtime schedules garbage collection based on memory use. Forcing collections
can add pauses and reduce throughput. `WaitForPendingFinalizers` blocks the caller
until queued finalizers finish; finalizers are cleanup methods run by the runtime.

## Example

Before:

```csharp
using System;

public static class Worker
{
    public static void Run(Action work)
    {
        work();
        GC.Collect();
    }
}
```

After:

```csharp
using System;

public static class Worker
{
    public static void Run(Action work)
    {
        work();
    }
}
```

## What is not reported

A method that also calls `GC.GetAllocatedBytesForCurrentThread`,
`GC.GetTotalAllocatedBytes`, or `GC.GetTotalMemory` is treated as memory measurement
code and is not reported. This exception also applies within a local function,
constructor, operator, or property getter or setter that contains a sampling call.
A same-named sampling method on an unrelated type does not qualify.

Calls through a renamed type alias, or an unqualified call imported with
`using static System.GC`, are not reported.

## Why there is no code fix

There is no automatic code fix. Remove calls that serve no measured purpose.
Keep deliberate collections needed by a benchmark, leak test, or memory diagnostic.
The rule cannot decide whether those calls are part of the test's purpose.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1021.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress a deliberate collection or finalizer wait in a benchmark or diagnostic
that needs it and does not meet the sampling exception above. For application
code, keep a forced collection only when measurements justify its pauses.
