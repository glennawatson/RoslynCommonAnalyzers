# PSH1104 — Use TryGetValue instead of ContainsKey followed by an indexer read

| Item | Value |
| --- | --- |
| Package | PerformanceSharp.Analyzers |
| Category | Collections |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |
| Applies to | C# 7 or later |

## Cause

`ContainsKey(key)` guards a read of the same dictionary's `[key]`. This looks up
the key twice. `TryGetValue` checks for the key and retrieves its value in one call.

The check must be the whole `if` condition, the first part of an `&&` condition,
or the condition in `check ? value : fallback`. The dictionary and key must be
variables or simple member accesses; a key can also be a literal. Matching reads
must occur in the rest of the condition or the true branch. A matching indexer
write, increment, or `ref`/`out` use prevents a report.

The dictionary's type must expose an accessible `TryGetValue` method. This includes
dictionary interfaces and custom types with that method.

## Example

Reported:

```csharp
using System;
using System.Collections.Generic;

var map = new Dictionary<string, int> { ["size"] = 42 };
string key = "size";
if (map.ContainsKey(key))
{
    Console.WriteLine(map[key]);
}
```

Use:

```csharp
using System;
using System.Collections.Generic;

var map = new Dictionary<string, int> { ["size"] = 42 };
string key = "size";
if (map.TryGetValue(key, out var value))
{
    Console.WriteLine(value);
}
```

## Code fix

The fix changes the guard to `TryGetValue(key, out var value)` and replaces every
matching guarded indexer read with that variable. It chooses `dictValue` if
`value` already appears in the enclosing member. If that fallback also conflicts,
choose a different name by hand. Comments inside replaced indexer reads are lost.

## Configuration

Enabled by default at `warning`. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1104.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the key, dictionary, or stored value can change between the check
and a read, including changes made by a method called in the guarded code. The
replacement uses the value captured at the check. Also suppress for custom
dictionary methods or property getters whose effects must be preserved.
