# PSH1110 — Use the collection's own predicate methods over LINQ

**Category:** Collections
**Severity:** Warning, enabled by default
**Code fix:** Yes

## Cause

A LINQ `FirstOrDefault`, `Any`, or `All` call passes a lambda to a `List<T>`,
`ImmutableList<T>`, or one-dimensional array. These collections have dedicated
methods that search their contents directly.

The call must pass a lambda, such as `x => x > 1`, as its only argument.
Calls without a predicate, calls that pass a method name or delegate variable,
and collections declared as `IEnumerable<T>` are not reported. For arrays, the
array must be named directly, as in `values` or `this.Values`; calls such as
`GetValues().Any(x => x > 1)` are not reported.

## Example

```csharp
using System.Collections.Generic;
using System.Linq;

public class Example
{
    // Before
    public bool Before(List<int> values) => values.Any(x => x > 1);

    // After
    public bool After(List<int> values) => values.Exists(x => x > 1);
}
```

## How to fix violations

The code fix keeps the lambda and changes the method as follows:

| LINQ method | List method | Array method |
| --- | --- | --- |
| `FirstOrDefault` | `Find` | `System.Array.Find` |
| `Any` | `Exists` | `System.Array.Exists` |
| `All` | `TrueForAll` | `System.Array.TrueForAll` |

For an array, the fix moves the array into the first argument:
`values.Any(x => x > 1)` becomes `System.Array.Exists(values, x => x > 1)`.
Comments attached to the replaced array method call or argument edges can be
lost; review the preview if the call contains comments.

An equality test such as `list.Any(x => x == target)` is covered by
[PSH1111](PSH1111.md), which suggests `Contains`.

## Configuration

The rule is enabled at `warning` by default. In `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1110.severity = warning
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, or `none`.
There are no rule-specific options.

## When to suppress

Suppress when keeping the LINQ form makes nearby queries easier to read and
measurement shows no useful speed gain. If the lambda changes the collection,
check its behavior before switching search methods.
