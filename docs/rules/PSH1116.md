# PSH1116 — Probe string-keyed collections with a span through GetAlternateLookup

**Category:** Collections
**Severity:** Warning, enabled by default
**Code fix:** None

## Cause

A call to `ContainsKey`, `TryGetValue`, `Contains`, or `Remove` creates a string
from a `Span<char>` or `ReadOnlySpan<char>` for its first argument, using
`span.ToString()` or `new string(span)`. A span is a view of characters already
in memory. Creating a string copies those characters for a lookup that can
use them directly.

The collection must use string keys and provide `GetAlternateLookup`. This
requires .NET 9 or later for the standard dictionaries and sets. A string
stored in a variable before the call is not reported.

## Example

The corrected method requires C# 13 and .NET 9 or later, and a dictionary
comparer that supports span lookups.

```csharp
using System;
using System.Collections.Generic;

public class Example
{
    // Before
    public bool Before(Dictionary<string, int> map, ReadOnlySpan<char> name)
        => map.ContainsKey(name.ToString());

    // After
    public bool After(Dictionary<string, int> map, ReadOnlySpan<char> name)
    {
        var lookup = map.GetAlternateLookup<ReadOnlySpan<char>>();
        return lookup.ContainsKey(name);
    }
}
```

## How to fix violations

There is no code fix. Obtain an alternate lookup and pass the span to it;
reuse the lookup for repeated operations on the same collection.

The comparer must support alternate lookups. The standard ordinal string
comparers do. `GetAlternateLookup` throws for an unsupported comparer; the
diagnostic does not confirm comparer support. Use `TryGetAlternateLookup`
and keep the string-based fallback when support is uncertain at runtime.

## Configuration

The rule is enabled at `warning` by default. In `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1116.severity = warning
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, or `none`.
There are no rule-specific options.

## When to suppress

Suppress when the comparer cannot support span lookups, the code must compile
with an older language version, or a measured allocation saving does not
justify the extra lookup and fallback code.
