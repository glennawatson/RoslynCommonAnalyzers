# PSH1118 — Take the extreme element without sorting

**Category:** Collections
**Severity:** Warning, enabled by default
**Code fix:** Yes, including Fix All

## Cause

A LINQ `OrderBy` or `OrderByDescending` call is immediately followed by
`First()`, `Last()`, `FirstOrDefault()`, or `LastOrDefault()`. The sort uses one
lambda and no comparer. `Min`, `Max`, `MinBy`, and `MaxBy` select an extreme
element in one pass without needing a sorted result. The speed gain depends
on the runtime's optimization of the original chain.

The rule reports `First` and `Last` only for non-nullable value types, such as
`int`, so both versions throw on an empty sequence. It reports `FirstOrDefault`
and `LastOrDefault` only for reference or nullable element types, so both
versions return `null` on an empty sequence.

It does not report a chain containing `ThenBy`, a final call with arguments,
or a `Queryable` call. `MinBy` and `MaxBy` require .NET 6 or another reference
that provides them. The `Min` and `Max` replacements also work on older targets.

## Example

```csharp
using System.Collections.Generic;
using System.Linq;

public class Example
{
    // Before
    public (int Key, int Value) Before(List<(int Key, int Value)> items)
        => items.OrderBy(x => x.Key).First();

    // After
    public (int Key, int Value) After(List<(int Key, int Value)> items)
        => items.MinBy(x => x.Key);
}
```

## Code fix

The fix removes the sort and final call, replacing them with one call:

| Chain | Replacement |
| --- | --- |
| `OrderBy(k).First()` or `.FirstOrDefault()` | `MinBy(k)` |
| `OrderBy(k).Last()` or `.LastOrDefault()` | `MaxBy(k)` |
| `OrderByDescending(k).First()` or `.FirstOrDefault()` | `MaxBy(k)` |
| `OrderByDescending(k).Last()` or `.LastOrDefault()` | `MinBy(k)` |

Here, `k` is the original lambda. If it is `x => x`, the fix removes it and uses
`Min()` or `Max()`. The replacement is formatted. Comments in the removed
final call or identity lambda are lost.

## Configuration

The rule is enabled at `warning` by default. In `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1118.severity = warning
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, or `none`.
There are no rule-specific options.

## When to suppress

Suppress when the result depends on how ties or nulls are handled. `MinBy` and
`MaxBy` choose the first element with the winning key; a sorted `Last` chooses
the last tied element. `Min` and `MinBy` also skip null values or keys when a
non-null value or key is available, while an ascending sort places nulls first.
The diagnostic checks empty sequences, but it does not exclude these cases.
