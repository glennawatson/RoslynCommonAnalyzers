# PSH1119 — Check for elements without counting them all

**Category:** Collections
**Severity:** Warning, enabled by default
**Code fix:** Yes, including Fix All

## Cause

A LINQ `Count()` or `LongCount()` result is compared with zero or one only to
test whether elements exist. Counting a sequence can require reading every
element. `Any()` stops as soon as it can answer. With a predicate, `Any` stops
at the first match instead of counting every match.

Both operand orders are supported. Comparisons that need the actual count,
such as `== 1`, `>= 2`, or `> 5`, are not reported. Custom instance `Count`
methods and `Queryable` calls are also excluded.

Without a predicate, collections with a public integer `Count` or `Length`
property are excluded; [PSH1103](PSH1103.md) suggests that property instead.
With a predicate, the rule also applies to those collections.

## Example

```csharp
using System.Collections.Generic;
using System.Linq;

public class Example
{
    // Before
    public bool Before(IEnumerable<int> values) => values.Count(x => x > 2) != 0;

    // After
    public bool After(IEnumerable<int> values) => values.Any(x => x > 2);
}
```

## Code fix

The fix changes `Count` or `LongCount` to `Any`, keeps any predicate argument,
and removes the comparison:

| Comparison | Replacement |
| --- | --- |
| `Count() > 0`, `Count() >= 1`, `Count() != 0` | `Any()` |
| `Count() == 0`, `Count() < 1`, `Count() <= 0` | `!Any()` |

The same table applies to `LongCount` and predicate overloads. The replacement
is formatted. Comments attached to the removed method name, operator, or
numeric literal are not preserved.

## Configuration

The rule is enabled at `warning` by default. In `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1119.severity = warning
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, or `none`.
There are no rule-specific options.

## When to suppress

Suppress when reading the whole sequence or evaluating the predicate for every
element is required for its effects, such as validation or logging. `Any`
stops early and skips that later work. Prefer separating those effects from
the existence check when practical.
