# PSH1124 — Use a linked list's First and Last properties

**Category:** Collections  
**Default severity:** Warning  
**Code fix:** Yes, including Fix All

## Cause

You call LINQ's parameterless `First()` or `Last()` on a value declared as
`LinkedList<T>`. The list already holds both end nodes. Reading them avoids
starting an enumeration; `Last()` also walks the whole list.

Calls with a predicate, `FirstOrDefault()`, and `LastOrDefault()` are not reported.
Neither are lists declared as `IEnumerable<T>` or `ICollection<T>`, other collection
types, or `Queryable` calls.

## Example

Before:

```csharp
using System.Collections.Generic;
using System.Linq;

public class History
{
    public int Newest(LinkedList<int> values) => values.Last();
}
```

After, when the list is known to contain an item:

```csharp
using System.Collections.Generic;

public class History
{
    public int Newest(LinkedList<int> values) => values.Last.Value;
}
```

## Code fix

The fix changes `list.First()` to `list.First.Value`, or `list.Last()` to
`list.Last.Value`. The property returns a node; `.Value` reads its item. Explicit
type arguments are removed. Comments inside the removed parentheses or type
arguments are not kept.

On an empty list, the LINQ call throws `InvalidOperationException`. The fixed code
throws `NullReferenceException` because the end node is null. Check `Count` first
if an empty list is allowed. With nullable reference types enabled, the property
read can also need a null check.

## Configuration

The rule is enabled by default with warning severity. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1124.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.
Use `none` to disable the rule; `default` restores its warning severity.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when callers rely on `InvalidOperationException` for an empty list and
you must keep that contract. Otherwise, handle the empty case before reading the
node.
