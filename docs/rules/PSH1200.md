# PSH1200 — Compare strings without allocating case-converted copies

**Category:** Strings  
**Default severity:** Warning  
**Code fix:** Yes, including Fix All

## Cause

Both strings in a comparison call the same parameterless case-conversion method:
`ToLower`, `ToUpper`, `ToLowerInvariant`, or `ToUpperInvariant`. Converting strings
can create temporary copies. A case-insensitive comparison avoids those copies.

The rule covers `==`, `!=`, instance `Equals(string)`, and static
`string.Equals(string, string)`. It does not report a conversion on only one side,
different conversion methods on the two sides, or conversions with arguments.

## Example

Before:

```csharp
public class Names
{
    public bool Match(string left, string right)
        => left.ToLower() == right.ToLower();
}
```

After, for a comparison that should ignore culture:

```csharp
public class Names
{
    public bool Match(string left, string right)
        => string.Equals(left, right, System.StringComparison.OrdinalIgnoreCase);
}
```

## Code fix

The fix removes both conversions and calls `string.Equals` with a comparison
argument. For `!=`, it adds `!` before the call.

| Conversion on both sides | Comparison chosen by the fix |
| --- | --- |
| `ToLower()` or `ToUpper()` | `StringComparison.OrdinalIgnoreCase` |
| `ToLowerInvariant()` or `ToUpperInvariant()` | `StringComparison.InvariantCultureIgnoreCase` |

These choices can change the result for some characters and cultures. For example,
Turkish casing of `I` differs from an ordinal comparison, which ignores language
rules. The fix also accepts null operands; the conversion calls would throw.
Comments attached to the removed conversions or comparison can be lost.

## Configuration

The rule is enabled by default with warning severity. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1200.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.
Use `none` to disable the rule; `default` restores its warning severity.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when the exact case-conversion result or null exception is part of the
required behavior. If you need a language-aware comparison, choose the appropriate
`StringComparison` yourself and test the relevant characters.
