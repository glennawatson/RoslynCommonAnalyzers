# PSH1201 — Use the char overload for single-character strings

**Category:** Strings  
**Default severity:** Warning  
**Code fix:** Yes, including Fix All

## Cause

You pass a one-character string literal to a string search that can take a `char`.
The character overload avoids work needed for a general string search.

The following calls are reported when the matching character overload exists:

- `text.Contains("x")`.
- `StartsWith`, `EndsWith`, `IndexOf`, or `LastIndexOf` with `"x"` and an explicit
  `StringComparison.Ordinal` argument.

Only ordinary string literals qualify, including escaped characters such as
`"\n"`. Variables, verbatim strings, raw strings, and interpolated strings are
not reported.

## Example

Before:

```csharp
public class Search
{
    public bool HasX(string text) => text.Contains("x");
}
```

After:

```csharp
public class Search
{
    public bool HasX(string text) => text.Contains('x');
}
```

## Code fix

The fix changes the string literal to a character literal and escapes it as needed.
It also removes `StringComparison.Ordinal` when present. Comments on that removed
argument are not kept.

The reported calls compare characters without language rules. Bare calls such as
`text.StartsWith("x")` and `text.IndexOf("x")` use the current culture, so they
are not reported. Ignore-case and other culture comparisons are also left alone,
as is `Contains` with an explicit comparison argument.

## Configuration

The rule is enabled by default with warning severity. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1201.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.
Use `none` to disable the rule; `default` restores its warning severity.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when shared source must compile on a target that lacks the character
overload, even though the target being analyzed has it. Otherwise the reported
replacement keeps the comparison behavior.
