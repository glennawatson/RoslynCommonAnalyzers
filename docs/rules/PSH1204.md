# PSH1204 — Test for empty strings by length

**Category:** Strings  
**Default severity:** Warning  
**Code fix:** Yes, including Fix All; the pattern fix requires C# 9

## Cause

You compare a string with `""` or `string.Empty` using `==` or `!=`, with the empty
value on either side. A length check states the question directly and avoids a
string-equality call.

Custom equality operators are not reported. Neither are comparisons in expression
trees, such as lambdas assigned to `Expression<Func<string, bool>>`, which a query
provider may need to translate.

## Example

Before:

```csharp
public class Names
{
    public bool IsEmpty(string name) => name == "";
}
```

After:

```csharp
public class Names
{
    public bool IsEmpty(string name) => name is { Length: 0 };
}
```

## Code fix

The default fix uses `name is { Length: 0 }` for equality and
`name is not { Length: 0 }` for inequality. These preserve the result for null:
null is unequal to an empty string. The fix adds parentheses where needed and
normalizes spacing within the replaced expression. Comments on removed parts of
the comparison are not kept.

The `length` and `is_null_or_empty` styles are used only where nullable analysis
shows that the string cannot be null. Otherwise the fix uses `pattern`, including
in files without nullable analysis. This matters because `name.Length` throws on
null, while `string.IsNullOrEmpty(name)` returns true for null.

## Configuration

The rule is enabled by default with warning severity.

```ini
[*.cs]
dotnet_diagnostic.PSH1204.severity = warning
performancesharp.empty_string_style = pattern
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.
Use `none` to disable the rule; `default` restores its warning severity.

| Option key | Values | Default |
| --- | --- | --- |
| `performancesharp.empty_string_style` | `pattern`, `length`, `is_null_or_empty` | `pattern` |
| `performancesharp.PSH1204.empty_string_style` | Same values; overrides the general key | General key, then `pattern` |

Values are case-insensitive. An invalid or missing rule-specific value falls back
to the general key. If neither key has a valid value, the rule uses `pattern`.

| Style | Equality replacement | Inequality replacement |
| --- | --- | --- |
| `pattern` | `name is { Length: 0 }` | `name is not { Length: 0 }` |
| `length` | `name.Length == 0` | `name.Length != 0` |
| `is_null_or_empty` | `string.IsNullOrEmpty(name)` | `!string.IsNullOrEmpty(name)` |

See [Configuration](../CONFIGURATION.md) for shared settings.

## Language versions

The diagnostic can appear on any C# version. The pattern fix is offered only on
C# 9 or later, even for equality. Earlier versions can use the other styles where
the string is known not to be null.

## When to suppress

Suppress when your project prefers empty-string comparisons for readability, or
when an older C# version cannot use the null-safe pattern and the value may be null.
