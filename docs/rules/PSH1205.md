# PSH1205 — Remove interpolation that does no work

**Category:** Strings  
**Default severity:** Warning  
**Code fix:** Yes, including Fix All

## Cause

An interpolated string contains only text, or contains exactly one `{expression}`
whose value is already a string. There is no alignment, format, or surrounding
text. Using a literal or the value directly avoids unnecessary formatting work.

The rule applies only when the result is used as a `string`. It does not report
`FormattableString`, `IFormattable`, or custom interpolated-string handler targets.
Mixed text and values, non-string values, alignment, and format clauses are also
left alone.

## Example

Before:

```csharp
public class Messages
{
    public string Copy(string name) => $"{name}";
    public string Greeting() => $"hello";
}
```

After, when `name` cannot be null:

```csharp
public class Messages
{
    public string Copy(string name) => name;
    public string Greeting() => "hello";
}
```

## Code fix

For a single string value, the fix removes the interpolation and keeps the
expression, adding parentheses where needed. It does not add a null check.
Interpolation turns null into `""`; the fixed expression remains null. Use
`name ?? ""` manually if that conversion is required.

For text-only interpolation, the fix writes a regular string literal and converts
escaped braces such as `{{` and `}}` to single braces. Verbatim and raw strings
also become regular literals with escapes as needed. The fix collapses doubled
braces in raw text too; if those braces are literal content, write the replacement
manually to keep them. Comments around an expression inside `{...}` are not kept.

A value such as `$"{count.ToString()}"` becomes `count.ToString()`; this fix does
not remove the inner conversion.

## Configuration

The rule is enabled by default with warning severity. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1205.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.
Use `none` to disable the rule; `default` restores its warning severity.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when an interpolation must stay consistent with related message templates.
If only null handling or literal braces need preserving, make the equivalent
replacement manually instead.
