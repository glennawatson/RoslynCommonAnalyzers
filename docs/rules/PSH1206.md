# PSH1206 — Do not build strings by concatenation in loops

**Category:** Strings  
**Default severity:** Warning  
**Code fix:** None

## Cause

A `for`, `foreach`, `while`, or `do` loop appends to a string with `+=` or
`result = result + ...`. Each append can copy the accumulated text into a new
string. As the result grows, each copy does more work.

The string must be a local declared outside the loop, a parameter, a field, or a
property. A local declared inside the loop is not reported. Code inside a nested
lambda or local function is reported only if it has its own enclosing loop.

## Example

Before:

```csharp
public class Report
{
    public string Build(int count)
    {
        var result = string.Empty;
        for (var i = 0; i < count; i++)
        {
            result += i;
        }

        return result;
    }
}
```

After:

```csharp
using System.Text;

public class Report
{
    public string Build(int count)
    {
        var builder = new StringBuilder();
        for (var i = 0; i < count; i++)
        {
            builder.Append(i);
        }

        return builder.ToString();
    }
}
```

## How to fix violations

Create a `StringBuilder` before the loop, append each part, and call `ToString()`
after the loop. Include the string's initial content if it was not empty. If the
loop only joins a sequence of strings, consider `string.Concat` or `string.Join`.

There is no automatic code fix. You must decide where to create the builder and
where the completed string is needed. Check any code that reads the accumulating
string during the loop before changing when it is updated.

## Configuration

The rule is enabled by default with warning severity. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1206.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.
Use `none` to disable the rule; `default` restores its warning severity.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress for a small, bounded loop where measurements show no useful gain, or when
each iteration must expose the updated string and a builder would not avoid copies.
