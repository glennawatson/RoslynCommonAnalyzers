# PSH1207 — Specify StringComparison for culture-sensitive string operations

**Category:** Strings  
**Default severity:** Warning  
**Code fix:** Yes, including Fix All

## Cause

You call `StartsWith`, `EndsWith`, `IndexOf`, or `LastIndexOf` with one string
argument, or `string.Compare` with two string arguments. These calls use the
current culture's language rules. An explicit `StringComparison` makes that
choice clear; an ordinal comparison avoids language-specific comparison work.

Character overloads, `Contains(string)`, `Equals`, `==`, and calls with extra
arguments are not reported. The rule reports nothing if the target framework
lacks `StringComparison`.

## Example

Before:

```csharp
public class Paths
{
    public bool HasPrefix(string path, string prefix) => path.StartsWith(prefix);
}
```

After, when the prefix should match without language rules:

```csharp
public class Paths
{
    public bool HasPrefix(string path, string prefix)
        => path.StartsWith(prefix, System.StringComparison.Ordinal);
}
```

## Code fix

The fix appends `System.StringComparison.Ordinal` and keeps the existing arguments.
It changes the comparison from the current culture's rules to exact character
matching, so results can differ.

Use `StringComparison.CurrentCulture` manually to preserve the original comparison
basis. Choose an ignore-case value when the operation must ignore case. The code
fix's comparison choice is not configurable.

## Configuration

The rule is enabled by default with warning severity. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1207.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.
Use `none` to disable the rule; `default` restores its warning severity.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when a query provider cannot translate the overload with a
`StringComparison` argument. Otherwise, make the comparison explicit, including
`CurrentCulture` when language rules are required.
