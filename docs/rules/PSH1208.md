# PSH1208 — Encode constant strings with u8 literals

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

`Encoding.UTF8.GetBytes` encodes a constant string at run time and creates a
byte array. A `u8` literal stores the encoded bytes at compile time. It can be
read as a `ReadOnlySpan<byte>`: a read-only view of those bytes without a copy.

The rule also reports `Encoding.ASCII.GetBytes` when every character is ASCII.
It skips values that are not constant, non-ASCII text passed to the ASCII
encoder, and invalid Unicode text such as `"\uD800"`, which cannot be a `u8` literal.
It requires C# 11 or later and a framework that provides `ReadOnlySpan<T>`.

## Example

Bad:

```csharp
using System;
using System.Text;

public class Message
{
    public bool HasPrefix(ReadOnlySpan<byte> input)
    {
        ReadOnlySpan<byte> prefix = Encoding.UTF8.GetBytes("v1:");
        return input.StartsWith(prefix);
    }
}
```

Corrected:

```csharp
using System;

public class Message
{
    public bool HasPrefix(ReadOnlySpan<byte> input)
    {
        ReadOnlySpan<byte> prefix = "v1:"u8;
        return input.StartsWith(prefix);
    }
}
```

## Code fix

The fix replaces the whole `GetBytes` call with a `u8` literal. When the result
is used as `ReadOnlySpan<byte>`, it uses the literal alone. Otherwise it adds
`.ToArray()`. That form still creates a byte array but avoids encoding the
string at run time.

A named constant is replaced with its literal value. Comments inside the
removed call are not preserved.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1208.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when keeping a shared string constant as the single source of the text
matters more than avoiding encoding, such as a marker encoded once at startup.
