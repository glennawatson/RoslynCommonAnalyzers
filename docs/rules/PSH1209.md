# PSH1209 — Build transformed strings with string.Create

**Category:** Strings
**Severity:** Warning
**Code fix:** None

## Cause

A local array is created with `string.ToCharArray()`, its elements are assigned,
and it is passed to `new string(chars)` in the same block. The array is an extra
allocation between the input string and the result.

`string.Create` lets a callback fill the result string directly. Its writable
span is a view of the result's characters. The rule reports nothing when the
framework lacks `string.Create` or `System.Buffers.SpanAction<T, TArg>`.

An array that is only read, or changed without constructing a string, is not
reported.

## Example

Bad:

```csharp
public class TextTransform
{
    public string Uppercase(string input)
    {
        var chars = input.ToCharArray();
        for (var i = 0; i < chars.Length; i++)
        {
            chars[i] = char.ToUpperInvariant(chars[i]);
        }

        return new string(chars);
    }
}
```

Corrected:

```csharp
public class TextTransform
{
    public string Uppercase(string input)
    {
        return string.Create(input.Length, input, (buffer, source) =>
        {
            for (var i = 0; i < buffer.Length; i++)
            {
                buffer[i] = char.ToUpperInvariant(source[i]);
            }
        });
    }
}
```

## How to fix violations

There is no code fix. Move the transformation into the `string.Create` callback
and supply the result length. Write every result character. If only part of the
string changes, copy the input into the buffer before changing that part.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1209.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when another operation needs the mutable array, or when moving the work
into a callback would make rarely run code harder to maintain. The rule does
not check whether the array has other uses.
