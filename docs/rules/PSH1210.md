# PSH1210 — Compare UTF-8 bytes without decoding them

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

`Encoding.UTF8.GetString(bytes)` is compared with a constant string using `==`
or `!=`. The constant can be on either side. Decoding creates a temporary
string; `SequenceEqual` compares the bytes directly with a `u8` literal.

The rule requires C# 11 or later and `System.MemoryExtensions.SequenceEqual`.
It skips nonconstant strings and invalid Unicode constants. It also skips
constants containing `�` (U+FFFD): invalid UTF-8 bytes can decode to that
replacement character, so comparing the bytes could give a different answer.

## Example

Bad:

```csharp
using System;
using System.Text;

public class Response
{
    public bool IsOk(byte[] payload) => Encoding.UTF8.GetString(payload) == "ok";
}
```

Corrected:

```csharp
using System;

public class Response
{
    public bool IsOk(byte[] payload) => payload.AsSpan().SequenceEqual("ok"u8);
}
```

## Code fix

The fix replaces the whole comparison with `SequenceEqual` against a `u8`
literal. It adds `AsSpan()` for an array and adds `!` for `!=`.
Without a `System` import, it uses a fully qualified
`global::System.MemoryExtensions.SequenceEqual` call instead.

Named constants become literal values. Comments around the removed decoding
call or comparison can be lost.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1210.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress if the call must reject a null byte array and you cannot add an
explicit null check. `GetString` throws for null; the replacement treats a
null array as an empty sequence.
