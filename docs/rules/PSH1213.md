# PSH1213 — Probe repeated character sets through SearchValues

**Category:** Strings
**Severity:** Warning
**Code fix:** None

## Cause

A string or span search receives an inline array or collection expression
made entirely of character literals, such as `new[] { ';', ',', '|' }` or
`[';', ',']`. The set must contain at least one character.

The rule covers `IndexOfAny`, `LastIndexOfAny`, `IndexOfAnyExcept`,
`LastIndexOfAnyExcept`, `ContainsAny`, and `ContainsAnyExcept` calls with one
argument. It requires `System.Buffers.SearchValues`, available in .NET 8 or later.

Caching `SearchValues<char>` prepares the search set once and avoids creating
an inline array on each call. The rule does not measure how often the call
runs. Sets held in variables or fields, and sets containing values other
than character literals, are not reported.

## Example

Bad:

```csharp
public class TextSearch
{
    public int FindSeparator(string value) => value.IndexOfAny(new[] { ';', ',', '|' });
}
```

Corrected:

```csharp
using System;
using System.Buffers;

public class TextSearch
{
    private static readonly SearchValues<char> Separators = SearchValues.Create(";,|");

    public int FindSeparator(string value) => value.AsSpan().IndexOfAny(Separators);
}
```

## How to fix violations

There is no code fix. Add a `static readonly SearchValues<char>` field and
reuse it in the search. For a string receiver, call `AsSpan()` to use the
search overload that accepts the field. Keep the `SearchValues.Create` call
out of the method that runs each search.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1213.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress for a search that runs once, or when measurements show that caching
the set does not help. A small, rarely used set may not justify a static field.
