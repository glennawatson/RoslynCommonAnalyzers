# PSH1214 — Append the parts, not a concatenated whole

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

`StringBuilder.Append` or `AppendLine` receives one string argument built with
`+`. Joining the parts first creates a temporary string. Separate append
calls write the parts directly into the builder.

Constant expressions such as `"a" + "b"` are not reported because the compiler
joins them at compile time. Custom `+` operators and append overloads with
more than one argument are also skipped.

## Example

Bad:

```csharp
using System.Text;

public class Output
{
    public void Write(StringBuilder builder, string a, string b)
        => builder.AppendLine(a + b);
}
```

Corrected:

```csharp
using System.Text;

public class Output
{
    public void Write(StringBuilder builder, string a, string b)
        => builder.Append(a).AppendLine(b);
}
```

## Code fix

The fix turns the concatenation into chained appends in the same order.
For `AppendLine`, only the last call is `AppendLine`, so it adds one newline.
Arithmetic stays together: `Append(i + j + text)` becomes
`Append(i + j).Append(text)`. Parenthesized groups and constant groups stay
together too.

The fix reformats the chain and can remove comments beside the `+` operators
or the parts being appended. For `AppendLine(text + number)` with an `int`
value, it produces `Append(text).AppendLine(number)`. Change the last argument
to `number.ToString()` manually: `AppendLine` has no integer overload.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1214.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when a later part reads or changes the same builder, or when the
builder must stay unchanged if evaluating a part throws. Separate appends
change the builder before all parts have been evaluated.

Also suppress when a non-string part would produce different text. For example,
`Append(char[])` writes the array's characters, while string concatenation
uses the array's `ToString()` result.
