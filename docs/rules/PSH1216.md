# PSH1216 — Ask for equality, not ordering

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

A string comparison result is tested with `== 0` or `!= 0`, with the literal
zero on either side. `string.Equals` asks whether the strings match without
requesting their sort order.

The rule covers `string.Compare` with two strings and an optional
`StringComparison` or literal `true`/`false` flag, `string.CompareOrdinal`
with two strings, and `string.CompareTo(string)`. It skips ordering tests
such as `> 0`, calls with a variable `ignoreCase` flag, and comparisons on
other types. It requires `System.StringComparison`.

## Example

Bad:

```csharp
public class TextMatch
{
    public bool Matches(string left, string right) => string.Compare(left, right) == 0;
}
```

Corrected:

```csharp
public class TextMatch
{
    public bool Matches(string left, string right)
        => string.Equals(left, right, System.StringComparison.CurrentCulture);
}
```

## Code fix

The fix replaces the test with `string.Equals`, adding `!` for `!= 0`.
It preserves the comparison's culture and case settings:

| Original call | `StringComparison` passed to `Equals` |
| --- | --- |
| `string.Compare(a, b)` | `CurrentCulture` |
| `string.Compare(a, b, comparison)` | The existing `comparison` argument |
| `string.Compare(a, b, true)` | `CurrentCultureIgnoreCase` |
| `string.Compare(a, b, false)` | `CurrentCulture` |
| `string.CompareOrdinal(a, b)` | `Ordinal` |
| `a.CompareTo(b)` | `CurrentCulture` |

Culture-based comparisons use language-specific rules. Ordinal comparisons
compare character values. Keep the comparison argument: `string.Equals(a, b)`
alone uses ordinal comparison.

The fix writes `System.StringComparison` for options it adds and normalizes
spacing between arguments. Comments around the removed call, arguments, or
comparison operator can be lost.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1216.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when a `CompareTo` call must throw for a null receiver and an explicit
null check is not suitable. The replacement accepts null strings, so that
exception behavior changes.
