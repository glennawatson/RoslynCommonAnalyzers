# PSH1217 — Read a sequence without copying it to an array

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

`string.ToCharArray()` or `ReadOnlySpan<T>.ToArray()` creates an array that is
immediately used for an operation the original string or span can perform.
Reading the original avoids allocating and copying the array.

The rule reports these uses:

- A `foreach` over `string.ToCharArray()`.
- Reading `.Length` or a single element, such as `[i]`, from either copy.
- Passing either copy directly to a method where removing it selects a
  matching overload that accepts `string` or `ReadOnlySpan<T>`.

## Example

Bad:

```csharp
public class TextReader
{
    public char Read(string value, int index) => value.ToCharArray()[index];
}
```

Corrected:

```csharp
public class TextReader
{
    public char Read(string value, int index) => value[index];
}
```

## What is not reported

Copies stored in a local or field, assigned, returned, changed, or passed to
a method that requires an array are skipped. So are range slices such as
`value.ToCharArray()[1..]`, named arguments, calls through `?.`, and LINQ's
`ToArray()`.

`foreach` over a span's `ToArray()` is always skipped. A loop over the span
itself cannot keep its position across `await` or `yield`, while an array
loop can.

For method arguments, the replacement must select a string or span overload
with the same return type and matching other parameter types. Selecting an
`object` overload does not qualify.

## Code fix

The fix removes `.ToCharArray()` or `.ToArray()` and leaves the original
string or span in its place. It does not add `AsSpan()`. Comments attached
to the removed copy call can be lost.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1217.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when the array-taking and sequence-taking overloads do different
work, or when reading a span requires a stable copy because other code can
change its underlying data during the operation.
