# PSH1218 — Slice with AsSpan instead of allocating a substring to search it

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

`Substring(start)` is immediately searched with `IndexOf`, `LastIndexOf`,
`Contains`, `StartsWith`, or `EndsWith`. `AsSpan(start)` gives the search a
view of the same characters without creating a substring.

The rule reports character searches, `Contains(string)`, and searches with
an explicit `StringComparison`, provided the equivalent span call is
available. The span methods must be in scope, usually through `using System;`.
For example, the span overloads for `StartsWith(char)` and `EndsWith(char)`
require .NET 10 or later.

## Example

Bad:

```csharp
using System;

public class TextSearch
{
    public int Find(string text, int start) => text.Substring(start).IndexOf('a');
}
```

Corrected:

```csharp
using System;

public class TextSearch
{
    public int Find(string text, int start) => text.AsSpan(start).IndexOf('a');
}
```

## Code fix

The fix changes only `Substring` to `AsSpan`. It keeps the start argument,
search arguments, comments, and spacing. An explicit `StringComparison`
keeps the same culture and case rules.

The returned index stays relative to the slice, and a failed search still
returns `-1`. This matters when the result is used as an index. Replacing the
call with `text.IndexOf(value, start)` would return an index into the whole
string. `text.LastIndexOf(value, start)` would also search a different region:
backward from `start` toward the beginning.

## What is not reported

- Searches such as `IndexOf("ab")` or `StartsWith("ab")` with implicit culture
  rules, because the default span search compares character values instead.
- `Substring(start, length)` or `Substring(startIndex: start)`.
- A substring stored before searching it, or a search reached through `?.`.
- Calls inside expression trees (`Expression<TDelegate>`), which cannot
  contain spans.
- Calls without a matching span search on the target framework.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1218.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when the existing exception behavior is part of your contract and
cannot be replaced with explicit input checks. For example, a null string
with start index zero throws with `Substring` but becomes an empty span
with `AsSpan`.

## Related rules

searches. [PSH1212](PSH1212.md) covers `Substring` results passed as arguments
