# PSH1219 — Ask whether a string is blank without trimming it

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

A string is trimmed only to check whether it is empty. `Trim()` scans the
string and can create a copy. `string.IsNullOrWhiteSpace` checks the original
string, stops at the first character that is not white space, and creates
no copy.

The rule reports these tests. For comparisons, `!=` and either operand order
are also reported.

| Reported test | Replacement |
| --- | --- |
| `text.Trim().Length == 0` | `string.IsNullOrWhiteSpace(text)` |
| `text.Trim() == ""` | `string.IsNullOrWhiteSpace(text)` |
| `text.Trim() == string.Empty` | `string.IsNullOrWhiteSpace(text)` |
| `string.IsNullOrEmpty(text.Trim())` | `string.IsNullOrWhiteSpace(text)` |

The length test also accepts an integer constant whose value is zero.
The rule requires the framework to provide `string.IsNullOrWhiteSpace`.

## Example

Bad:

```csharp
public class TextCheck
{
    public bool IsBlank(string text) => text.Trim().Length == 0;
}
```

Corrected:

```csharp
public class TextCheck
{
    public bool IsBlank(string text) => string.IsNullOrWhiteSpace(text);
}
```

## How to fix violations

The code fix replaces the whole test with `string.IsNullOrWhiteSpace(text)`.
For `!=`, it adds `!`. An existing `!` around `string.IsNullOrEmpty` stays
in place. The fix reformats the replacement and can drop comments inside
the removed test.

Check the null contract before accepting the fix. `text.Trim()` throws
`NullReferenceException` when `text` is null. `string.IsNullOrWhiteSpace(null)`
returns `true`; the negated test returns `false`. Add an explicit null check
if null must be rejected.

## What is not reported

- `Trim` calls with arguments, such as `Trim(',')` or `Trim(trimChars)`.
- A trimmed value stored before it is tested or used for other work.
- Other length comparisons, such as `text.Trim().Length > 0`.
- Tests inside expression trees (`Expression<TDelegate>`), such as queries
  translated by a database provider.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.
Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PSH1219.severity = warning
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when the existing null exception is required and you cannot add an
explicit check. Empty strings and strings containing only white space give
the same answer with either test.
