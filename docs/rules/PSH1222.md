# PSH1222 — Concatenate slices without materializing them

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

`string.Concat` joins two to four string arguments, and at least one is a
`Substring` call. The substring creates a temporary string whose characters are
then copied into the result.

`AsSpan` gives a view of the characters without copying them. Passing these views
to `Concat` avoids the temporary strings. The rule reports only when `AsSpan` is
available in the file and the project has a matching span-based `Concat` overload.
These overloads are absent on .NET Framework and .NET Standard 2.0.

## Example

Before:

```csharp
using System;

public class TextJoiner
{
    public string Join(string a, string b) => string.Concat(a.Substring(1), b);
}
```

After:

```csharp
using System;

public class TextJoiner
{
    public string Join(string a, string b) => string.Concat(a.AsSpan(1), b.AsSpan());
}
```

## Code fix

The fix changes each `Substring` to `AsSpan`, keeping its start and length arguments.
It adds `AsSpan()` to every other string argument, including string literals.
It rebuilds the argument spacing and can drop comments around arguments or on the
replaced method names.

A null string passed directly to `Concat` still contributes no characters. Check
null handling for a string being sliced: `Substring` throws on null, while
`AsSpan(0)` returns an empty view.

## What is not reported

- `Concat` without a substring argument.
- Calls using object arguments, an argument array, or named arguments.
- Concatenation written with `+`.
- Code stored in an `Expression<...>` for a query provider.

## Configuration

Enabled by default at `warning` severity. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1222.severity = warning
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`.
See [configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress when the call is rare and keeping the string-based code is clearer, or
when the original null exception is part of the method's contract.
