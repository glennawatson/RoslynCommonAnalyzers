# PSH1223 — Parse a reused format string once

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (no Fix All)

## Cause

`string.Format` receives a constant format string containing a placeholder such as
`{0}`. It reads the placeholders on each call. A `CompositeFormat` field stores the
parsed format so repeated calls can reuse it.

The rule requires `CompositeFormat` and a matching `string.Format` overload,
available in .NET 8 and later. It can report a call even if that call runs only once.

## Example

Before:

```csharp
using System.Globalization;
using System.Text;

public class Greeter
{
    public string Greet(string name) => string.Format("Hello, {0}!", name);
}
```

After:

```csharp
using System.Globalization;
using System.Text;

public class Greeter
{
    private static readonly CompositeFormat GreetFormat = CompositeFormat.Parse("Hello, {0}!");

    public string Greet(string name) => string.Format(CultureInfo.CurrentCulture, GreetFormat, name);
}
```

## Code fix

The fix inserts a `private static readonly CompositeFormat` field first in the
containing class, struct, or record. It changes the call to use that field. An
existing format provider stays in place; a call without one gains
`CultureInfo.CurrentCulture`.

For a method named `Greet`, the field is named `GreetFormat`, with a number if that
name is taken. A constant field remains a reference; a constant local becomes a string
literal in the new field. Fully qualified type names are used when needed.

The fix adds a blank line after the field and rebuilds argument spacing. Comments
around arguments or on the removed format expression can be lost. Fix All is not
available. There is no fix for an interface, top-level code, a record without a
body, or a type with preprocessor directives inside its body.

## What is not reported

- A format that can change at runtime.
- A format without placeholders, or one with malformed placeholders.
- Named arguments.
- Code stored in an `Expression<...>` for a query provider.

## Configuration

Enabled by default at `warning` severity. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1223.severity = warning
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`.
See [configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress for a one-off call when retaining a parsed format field adds complexity
without useful savings.
