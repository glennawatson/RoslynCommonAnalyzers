# PSH1226 — Iterate a string without copying it to a char array

**Category:** Strings
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

A local variable stores `text.ToCharArray()`, but its only uses are `foreach`,
`Length`, or reading characters by index. The array copies the string's characters
even though a string already supports these operations.

The declaration must use `var` or `char[]`, declare one variable, and be inside a
block. At least one use is required.

## Example

Before:

```csharp
public class CharacterCounter
{
    public int Count(string text)
    {
        char[] chars = text.ToCharArray();
        int count = 0;
        foreach (char c in chars)
        {
            if (c == 'a') count++;
        }

        return count;
    }
}
```

After:

```csharp
public class CharacterCounter
{
    public int Count(string text)
    {
        string chars = text;
        int count = 0;
        foreach (char c in chars)
        {
            if (c == 'a') count++;
        }

        return count;
    }
}
```

## How to fix violations

The code fix removes `ToCharArray()`. It changes an explicit `char[]` type to
`string`; `var` stays `var` and holds a string. The local name and its uses stay in
place. Comments inside the removed call or array type can be lost.

## What is not reported

- An array that is modified, reassigned, returned, or passed to another method.
- Other array operations, such as `Clone()`.
- `ToCharArray(start, length)`.
- A copy used directly, such as `foreach (char c in text.ToCharArray())`, without
  storing it in a local first.

## Configuration

Enabled by default at `warning` severity. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1226.severity = warning
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`.
See [configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress when a copy is intentional for measuring or testing array allocation.
Code that needs a mutable array is already excluded.
