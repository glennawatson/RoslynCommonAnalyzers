# PSH1227 — Use the purpose-built call

**Category:** Strings
**Severity:** Info (suggestion)
**Code fix:** Yes (supports Fix All)

## Cause

A call selects behavior that another method provides directly:

- `string.Compare(a, b, StringComparison.Ordinal)` compares character values
  without culture rules. `string.CompareOrdinal(a, b)` names that operation directly.
- `Debug.Assert(false, message)` always fails. `Debug.Fail(message)` expresses that
  intent without a condition. The overload with a detail message is also covered.

These replacements avoid selecting a comparison mode or checking a fixed condition.

## Example

Before:

```csharp
using System;
using System.Diagnostics;

public class Checks
{
    public int Order(string a, string b) => string.Compare(a, b, StringComparison.Ordinal);
    public void Report(string message) => Debug.Assert(false, message);
}
```

After:

```csharp
using System;
using System.Diagnostics;

public class Checks
{
    public int Order(string a, string b) => string.CompareOrdinal(a, b);
    public void Report(string message) => Debug.Fail(message);
}
```

## How to fix violations

The code fix renames `Compare` to `CompareOrdinal` and removes the comparison
argument, or renames `Assert` to `Fail` and removes `false`. It keeps the other
arguments, including a detail message, and the type name you used for the call.
It resets spacing between arguments and can discard comments around them or on
the replaced method name.

## What is not reported

- `Compare` results checked with `== 0` or `!= 0`; [PSH1216](PSH1216.md) covers
  those equality checks.
- Case-insensitive or culture-sensitive comparisons, or a comparison mode that
  is not constant.
- Assertions whose first argument is not the literal `false`.
- `Debug.Assert(false)` without a message, or overloads that format a message.

## Configuration

Enabled by default at `suggestion` severity. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1227.severity = suggestion
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`.
See [configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress when keeping one comparison API across related code makes it easier to
maintain and the small extra cost is acceptable.
