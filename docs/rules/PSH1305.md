# PSH1305 — Enumerate a ConcurrentDictionary directly instead of a Keys or Values snapshot

**Category:** Concurrency
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

A `foreach` loop reads `Keys` or `Values` directly from a
`ConcurrentDictionary<TKey, TValue>`. Each property locks the dictionary while
copying its keys or values into a separate collection. Enumerating the dictionary
avoids that copy.

Other uses of those properties and loops over an ordinary `Dictionary` are not
reported.

## Example

Before:

```csharp
using System.Collections.Concurrent;

class Counter
{
    public int Total(ConcurrentDictionary<string, int> map)
    {
        int total = 0;
        foreach (var value in map.Values)
        {
            total += value;
        }

        return total;
    }
}
```

After:

```csharp
using System.Collections.Concurrent;

class Counter
{
    public int Total(ConcurrentDictionary<string, int> map)
    {
        int total = 0;
        foreach (var (_, value) in map)
        {
            total += value;
        }

        return total;
    }
}
```

## Code fix

The fix changes a values loop to `foreach (var (_, value) in map)` and a keys
loop to `foreach (var (key, _) in map)`. The underscore discards the unused part
of each pair. It keeps the variable name and loop body.

The fix requires a `var` loop variable and a framework with
`KeyValuePair.Deconstruct` (.NET Core 2.0+ or .NET Standard 2.1+). Explicitly typed
variables and loops that already split their elements into several variables
need a manual rewrite. Comments attached to the replaced variable declaration
or the removed `Keys`/`Values` access can be lost; check the preview.

Direct enumeration can observe changes made while the loop runs. It does not
provide the fixed set of keys or values that the copied collection provides.

## Configuration

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1305.severity = warning
```

Enabled as a warning by default. There are
no rule-specific options. Severity values are `none`, `silent`, `suggestion`,
`warning`, and `error`. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the loop needs a fixed snapshot while other threads change the
dictionary. Keep the copy in that case.
