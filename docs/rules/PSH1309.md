# PSH1309 — Register cancellation callbacks without flowing the execution context

**Category:** Concurrency
**Severity:** Warning (disabled by default)
**Code fix:** Yes (supports Fix All)

## Cause

A call to `CancellationToken.Register` passes a callback and an explicit state
object. `Register` saves values tied to the current async operation, such as data
in `AsyncLocal<T>`, and makes them available when the callback runs. These values
are part of the execution context. `UnsafeRegister` skips the work of saving and
restoring that context.

Only the two-argument callback-and-state overloads are reported. Calls without
a state object, or with a `useSynchronizationContext` argument that controls
where the callback runs, are not reported. The rule requires
`CancellationToken.UnsafeRegister` to be available.

## Example

Before:

```csharp
using System;
using System.Threading;

class Registration
{
    public CancellationTokenRegistration Attach(
        CancellationToken token, IDisposable resource)
        => token.Register(static state => ((IDisposable)state!).Dispose(), resource);
}
```

After:

```csharp
using System;
using System.Threading;

class Registration
{
    public CancellationTokenRegistration Attach(
        CancellationToken token, IDisposable resource)
        => token.UnsafeRegister(static state => ((IDisposable)state!).Dispose(), resource);
}
```

## Code fix

The fix changes `Register` to `UnsafeRegister`. It keeps the callback, state
argument, and comments. The callback runs without restoring the context captured
at registration. A `static` callback can still read values such as `AsyncLocal<T>`
data. Check what it and the methods it calls depend on before accepting the fix.

## Configuration

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1309.severity = warning
```

Disabled by default. The setting above enables the rule as a warning. There are
no rule-specific options. Severity values are `none`, `silent`, `suggestion`,
`warning`, and `error`. See [Configuration](../CONFIGURATION.md).

## When to suppress

Leave the rule disabled, or suppress a registration, when its callback needs
the registering caller's context, such as request data stored in
`AsyncLocal<T>`. Enable it where callbacks rely on their explicit state instead.
