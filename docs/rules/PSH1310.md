# PSH1310 — Dispose asynchronously in async code

**Category:** Concurrency
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

An `async` method, local function, or lambda uses a synchronous `using` for a
resource that implements `IAsyncDisposable`. Cleanup such as flushing a stream
can block the thread. `await using` lets asynchronous cleanup finish without
holding that thread while it waits.

Both `using (...)` statements and `using var` declarations are covered. For a
declaration with several resources, every initializer must produce an
asynchronously disposable resource. Synchronous functions, including those
inside an async method, are not reported. The rule requires C# 8 or later and
`System.IAsyncDisposable` in the project.

## Example

Before:

```csharp
using System.IO;
using System.Threading.Tasks;

class Writer
{
    public async Task SaveAsync(Stream destination, string line)
    {
        using var writer = new StreamWriter(destination);
        await writer.WriteLineAsync(line);
    }
}
```

After:

```csharp
using System.IO;
using System.Threading.Tasks;

class Writer
{
    public async Task SaveAsync(Stream destination, string line)
    {
        await using var writer = new StreamWriter(destination);
        await writer.WriteLineAsync(line);
    }
}
```

## Code fix

The fix inserts `await` before `using`, keeps leading comments, and formats the
statement. The resource is disposed at the same end of scope, through
`DisposeAsync` instead of `Dispose`.

If an explicit variable type hides `IAsyncDisposable`, change it to `var` or a
type that supports asynchronous disposal too. The fix only inserts the keyword;
it does not change that variable's type.

## Configuration

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1310.severity = warning
```

Enabled as a warning by default. There are
no rule-specific options. Severity values are `none`, `silent`, `suggestion`,
`warning`, and `error`. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the resource's synchronous disposal is deliberately required, or
when you have measured that it finishes immediately and asynchronous disposal
adds cost without benefit. Check the resource's disposal contract first.
