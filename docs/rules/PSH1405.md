# PSH1405 - Use direct Environment APIs

| Item | Value |
| --- | --- |
| Category | ApiSelection |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

Code reads process or thread information through one of these chains when the
matching `Environment` property exists in the target framework:

| Reported expression | Replacement |
| --- | --- |
| `Process.GetCurrentProcess().Id` | `Environment.ProcessId` |
| `Process.GetCurrentProcess().MainModule.FileName` | `Environment.ProcessPath` |
| `Thread.CurrentThread.ManagedThreadId` | `Environment.CurrentManagedThreadId` |

The direct properties avoid obtaining process or thread objects for a single
value. Reads from saved objects, such as `process.Id`, and chains using `?.` are
not reported.

## Example

Bad:

```csharp
using System.Diagnostics;

public class ProcessInfo
{
    public int GetId() => Process.GetCurrentProcess().Id;
}
```

Corrected:

```csharp
public class ProcessInfo
{
    public int GetId() => System.Environment.ProcessId;
}
```

## Code fix

The code fix replaces the whole reported chain with
`System.Environment.ProcessId`, `System.Environment.ProcessPath`, or
`System.Environment.CurrentManagedThreadId`. It keeps comments around the chain,
but comments inside it can be lost. It leaves existing `using` directives in
place. Fix All applies the same replacements to eligible reads.

`Environment.ProcessPath` can return `null` when the executable path is unavailable.
Handle that result if the rest of the code requires a non-null path.

## Configuration

The default and recommended severity is `warning`. There are no rule-specific
options.

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1405.severity = warning
```

Other severity values are `none`, `silent`, `suggestion`, and `error`. Use `none`
to disable the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress a specific path lookup when you need its existing failure behavior
instead of a possible `null` result. If you already need a `Process` object for
other work, save and reuse it; reads from that saved object are excluded.
