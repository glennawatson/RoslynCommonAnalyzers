# PSH1406 - Ask Regex for the answer directly

| Item | Value |
| --- | --- |
| Category | ApiSelection |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

Code reads `.Success` directly from `Regex.Match(...)`, or `.Count` directly from
`Regex.Matches(...)`. Static calls and calls on a `Regex` instance are both
reported. Count suggestions require the `Regex.Count` API in the target framework
(.NET 7 or later).

`IsMatch` answers whether a match exists without creating a match result for you.
`Count` counts matches without building a collection of match results. Reads from
a saved match or collection are not reported.

## Example

Bad:

```csharp
using System.Text.RegularExpressions;

public class Matcher
{
    public bool HasMatch(Regex regex, string input) => regex.Match(input).Success;
    public int CountMatches(Regex regex, string input) => regex.Matches(input).Count;
}
```

Corrected (.NET 7 or later):

```csharp
using System.Text.RegularExpressions;

public class Matcher
{
    public bool HasMatch(Regex regex, string input) => regex.IsMatch(input);
    public int CountMatches(Regex regex, string input) => regex.Count(input);
}
```

## How to fix violations

There is no code fix. Replace `Match(...).Success` with `IsMatch(...)`, or
`Matches(...).Count` with `Count(...)`.

Check the overload before changing a call with a start position or a search
length. The replacement must search the same part of the input and keep the same
options and timeout. The rule can report a call even when the replacement does
not accept the exact same arguments.

## Configuration

The default and recommended severity is `warning`. There are no rule-specific
options.

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1406.severity = warning
```

Other severity values are `none`, `silent`, `suggestion`, and `error`. Use `none`
to disable the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress a specific call when no direct query preserves its search range or
other behavior. If you also need the matched text or groups, save the match or
collection and read its properties; that form is excluded.
