# PSH1408 - Measure elapsed time with Stopwatch timestamps

| Item | Value |
| --- | --- |
| Category | ApiSelection |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A local is initialized with `Stopwatch.StartNew()` and used only to read `Elapsed`,
`ElapsedMilliseconds`, or `ElapsedTicks`, with optional `Stop()` calls. At least
one elapsed-time read is required. The declaration must contain one variable
inside a method, accessor, lambda, or local function; top-level declarations are
excluded.

`Stopwatch.GetTimestamp()` records a timer value in a `long` without creating a
`Stopwatch` object. `Stopwatch.GetElapsedTime(...)` converts the difference to a
`TimeSpan`. The rule requires `GetElapsedTime`, available from .NET 7.

Other uses, such as `Restart()`, `Reset()`, `IsRunning`, passing the stopwatch to
another method, or returning it, are not reported.

## Example

Bad:

```csharp
using System;
using System.Diagnostics;

public class Timer
{
    public TimeSpan Measure(Action work)
    {
        var stopwatch = Stopwatch.StartNew();
        work();
        stopwatch.Stop();
        return stopwatch.Elapsed;
    }
}
```

Corrected:

```csharp
using System;
using System.Diagnostics;

public class Timer
{
    public TimeSpan Measure(Action work)
    {
        long start = Stopwatch.GetTimestamp();
        work();
        long end = Stopwatch.GetTimestamp();
        return Stopwatch.GetElapsedTime(start, end);
    }
}
```

## How to fix violations

There is no code fix. Replace `StartNew()` with `GetTimestamp()`. If the stopwatch
keeps running, replace each `Elapsed` read with `Stopwatch.GetElapsedTime(start)`.
If it is stopped, capture an end timestamp at the first `Stop()` and use that same
end value for later reads, as in the example. Otherwise, later reads would include
time after the stop.

For whole elapsed milliseconds, use `(long)elapsed.TotalMilliseconds`, where
`elapsed` is the returned `TimeSpan`. For `ElapsedTicks`, subtract the start
timestamp from the end timestamp. Stopwatch ticks and `TimeSpan.Ticks` use
different units; they are not interchangeable.

## Configuration

The default and recommended severity is `warning`. There are no rule-specific
options.

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1408.severity = warning
```

Other severity values are `none`, `silent`, `suggestion`, and `error`. Use `none`
to disable the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress a specific declaration when retaining a `Stopwatch` makes several timing
reads or stop paths easier to understand and avoiding one object is not useful.
Stopwatches that are restarted, reset, or passed elsewhere are already excluded.
