# PSH1410 — Mark trivial forwarders for aggressive inlining

**Category:** ApiSelection
**Severity:** Warning (disabled by default)
**Code fix:** Yes (supports Fix All)

## Cause

A method or operator uses `=>` for a short body. It returns a value, reads a
member or indexer, calls another member, uses `?.`, or creates an object with
`new TypeName(...)`.

The rule suggests `MethodImplOptions.AggressiveInlining`. This attribute asks
the runtime to put the method's code where it is called. The runtime may ignore
it, and it does not promise faster code.

Block bodies, interface members, and members marked `virtual`, `abstract`,
`override`, `async`, `extern`, or `partial` are excluded. Members with a
`MethodImpl` attribute, including `NoInlining`, and members inside an `#if`
region are also excluded. The rule skips tests and setup or cleanup methods
marked by NUnit, xUnit, or MSTest attributes. The rule stays silent when the
target framework does not provide `AggressiveInlining`.

## Example

Before:

```csharp
public class Counter
{
    private readonly int _value;

    public Counter(int value) => _value = value;

    public int GetValue() => _value;
}
```

After:

```csharp
using System.Runtime.CompilerServices;

public class Counter
{
    private readonly int _value;

    public Counter(int value) => _value = value;

    [MethodImpl(MethodImplOptions.AggressiveInlining)]
    public int GetValue() => _value;
}
```

## Code fix

The fix adds the attribute above other attributes. It keeps the member's
documentation and leading comments above it. It adds
`using System.Runtime.CompilerServices;` when missing, placing it among the
file's imports in name order, with `System` imports first.

No fix is offered when directives such as `#region` or `#if` are attached to
the file's `using` directives. Conditional code elsewhere in the file does not
prevent a fix for a member outside that conditional region.

## Configuration

The rule is disabled by default and has no rule-specific options. Enable it with:

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1410.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Leave the rule disabled unless measurements show these hints help. Suppress
a report when the hint does not improve performance or makes debugging harder.
Adding it to many methods can make the compiled program larger.
