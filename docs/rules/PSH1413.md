# PSH1413 — Read the Unix epoch from the framework

**Category:** ApiSelection
**Severity:** Warning
**Code fix:** Yes (supports Fix All)

## Cause

Code constructs midnight on 1 January 1970 using `new DateTime(...)` or
`new DateTimeOffset(...)`, and the matching `UnixEpoch` field is available.
Numeric date components must be constants, with every time component zero.

For `DateTime`, the kind must be omitted or written as `DateTimeKind.Utc`.
For `DateTimeOffset`, the offset must be `TimeSpan.Zero`. Named arguments,
target-typed `new(...)`, object initializers, and constructors taking a calendar,
tick count, or existing date are not reported.

## Example

Before:

```csharp
using System;

public class Clock
{
    public DateTime Epoch() => new DateTime(1970, 1, 1, 0, 0, 0, DateTimeKind.Utc);
}
```

After:

```csharp
using System;

public class Clock
{
    public DateTime Epoch() => DateTime.UnixEpoch;
}
```

## Code fix

The fix replaces the constructor call with `DateTime.UnixEpoch` or
`DateTimeOffset.UnixEpoch`. It keeps the written type qualification, so
`new System.DateTime(...)` becomes `System.DateTime.UnixEpoch`. Comments inside
the removed call can be lost; surrounding comments are kept.

**Replacing a `DateTime` constructor that omits the kind changes `Kind` from
`Unspecified` to `Utc`.** This can change conversions and serialization.
For example, `ToUniversalTime()` treats an unspecified value as local time.
Review that behavior before accepting the fix. An explicitly written
`DateTimeKind.Local` or `DateTimeKind.Unspecified` is not reported.

The rule reports nothing for a date type whose framework lacks `UnixEpoch`.

## Configuration

The rule is enabled at `warning` by default. It has no rule-specific options.

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1413.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress when the date must retain `DateTimeKind.Unspecified`, or spell that
kind explicitly. Also suppress in shared source that must compile on a framework
without `UnixEpoch`.
