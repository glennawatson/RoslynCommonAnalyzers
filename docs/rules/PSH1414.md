# PSH1414 — Mark members that do not touch instance state as static

**Category:** ApiSelection
**Severity:** Warning
**Code fix:** Private members only (supports Fix All)

## Cause

A method or computed property explicitly marked `private` or `internal` does
not use instance state. Making it `static` removes the need to pass an object
instance when calling it.

The rule excludes members that use `this`, `base`, a primary constructor
parameter, or an instance member of their own class or a base class. An
unqualified recursive call does not exclude a method.

## Example

Before:

```csharp
public class Calculator
{
    public int Sum(int a, int b) => this.Add(a, b);

    private int Add(int a, int b) => a + b;
}
```

After:

```csharp
public class Calculator
{
    public int Sum(int a, int b) => Add(a, b);

    private static int Add(int a, int b) => a + b;
}
```

## What is not reported

- Public or protected members, and members marked `static`, `virtual`,
  `abstract`, `override`, `extern`, or `partial`.
- Auto-properties and properties using the compiler-provided `field` value.
- Members with recognized test, benchmark, setup, cleanup, or serialization
  callback attributes. Members of recognized test fixture and benchmark host
  types are also excluded. Unrelated attributes such as `[Obsolete]` do not
  exclude a member.

## Code fix

For a private member, the fix adds `static` and changes references such as
`this.Add(...)` to `Add(...)`. The containing type must have a single declaration.
If a reference in that type uses another receiver, such as `other.Add(...)`,
no fix is offered. Internal members are reported without a fix; update their
callers when making the change by hand.

The editor formats the changed member and references. Surrounding comments are
kept, but comments between `this`, the dot, and the member name can be lost when
that qualification is removed.

## Configuration

The rule is enabled at `warning` by default. It has no rule-specific options.

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1414.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress when reflection or a framework requires an instance member and its
convention is not recognized. Keep an internal member as an instance member
when a friend assembly or other consumer depends on that contract.
