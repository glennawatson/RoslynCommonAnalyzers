# PSH1417 — Do not compute an expensive argument for an assertion

**Category:** ApiSelection
**Severity:** Warning
**Code fix:** None — wrapping the work in `#if DEBUG`, or restructuring so the cost is only paid on failure, is a design choice.

`Debug.Assert` carries `[Conditional("DEBUG")]`, so in a release build the whole
call is removed **including its arguments** — nothing they would have done is
paid for. What this rule is about is the debug build, where the message argument
is built on *every* call, including the overwhelming majority that pass and throw
it straight away.

## Example

```csharp
Debug.Assert(items.Count > 0, string.Join(",", items));   // PSH1417 — joined on every passing call
Debug.Assert(items.Count > 0, $"bad batch: {items.Count}"); // clean — deferred until the check fails
Debug.Assert(items.All(IsValid));                          // clean — the condition has to run
Debug.Assert(count >= 0, "count must not be negative");    // clean — a constant
```

## What is reported

A **message** argument whose value has to be computed. The condition is never
reported: a release build removes it along with everything else, and a debug build
has to evaluate it for the assertion to mean anything.

An **interpolated** message is not reported where the framework can defer it. The
`Debug.Assert(bool, AssertInterpolatedStringHandler)` overload hands the runtime a
handler that only builds the string once the condition has already failed, so a
passing assertion pays nothing. That overload is probed in the compilation rather
than assumed: on a target framework without it — .NET Framework and
netstandard2.0 — interpolation runs eagerly like any other argument, and an
interpolated message is reported there too.

## How to fix violations

Move the message to an interpolated string, which defers the work to the failing
call:

```csharp
// before
Debug.Assert(items.Count > 0, string.Join(",", items));

// after
Debug.Assert(items.Count > 0, $"{string.Join(",", items)}");
```

## Silent shapes

Anything the compiler folds to a **constant** is free and is never reported.
That is what keeps `nameof(x)` clean — an invocation in syntax only, with a
constant value — along with constant messages and constant interpolated strings.
