# PSH1418 — Reuse a shared client instead of constructing one per call

**Category:** ApiSelection
**Severity:** Warning
**Code fix:** None.

## Cause

Code constructs a supported client directly in a `using` or `await using`
declaration or statement, or immediately accesses a member on the new client,
such as `new HttpClient().GetStringAsync(url)`.

Repeatedly creating and disposing `HttpClient` can prevent connection reuse and
exhaust available ports under load. Creating service clients repeatedly can
also repeat connection, authentication, and cache setup.

## What is reported

| Client | Namespace |
| --- | --- |
| `HttpClient` | `System.Net.Http` |
| `BlobServiceClient` | `Azure.Storage.Blobs` |
| `QueueServiceClient` | `Azure.Storage.Queues` |
| `ShareServiceClient` | `Azure.Storage.Files.Shares` |
| `DataLakeServiceClient` | `Azure.Storage.Files.DataLake` |
| `TableServiceClient` | `Azure.Data.Tables` |
| `ServiceBusClient` | `Azure.Messaging.ServiceBus` |
| `EventHubProducerClient` | `Azure.Messaging.EventHubs.Producer` |
| `EventGridPublisherClient` | `Azure.Messaging.EventGrid` |
| `CosmosClient` | `Microsoft.Azure.Cosmos` |
| `SecretClient` | `Azure.Security.KeyVault.Secrets` |
| `KeyClient` | `Azure.Security.KeyVault.Keys` |
| `CertificateClient` | `Azure.Security.KeyVault.Certificates` |

Only the listed types are covered, not a type of your own with the same short
name. The project must reference `HttpClient` and the client type being reported.

## Example

Before:

```csharp
using System.Net.Http;
using System.Threading.Tasks;

public class Downloader
{
    public async Task<string> Fetch(string url)
    {
        using var client = new HttpClient();
        return await client.GetStringAsync(url);
    }
}
```

After:

```csharp
using System.Net.Http;
using System.Threading.Tasks;

public class Downloader
{
    private static readonly HttpClient Client = new HttpClient();

    public Task<string> Fetch(string url) => Client.GetStringAsync(url);
}
```

## What is not reported

Construction stored directly in a field, property initializer, or ordinary local
is excluded, as is construction returned from a factory or passed as an argument.
Construction in the program's entry point is also excluded. Absence of a report
does not establish that a client is shared.

## How to fix violations

Reuse a client for multiple operations. For `HttpClient`, either use a long-lived
instance or obtain clients from an injected `IHttpClientFactory`, which manages
and reuses the underlying connections. Do not dispose a shared client after each
request. For a long-lived client, set `SocketsHttpHandler.PooledConnectionLifetime`
when connections need to refresh after DNS changes.

For the listed service clients, keep a shared instance or register one instance
with your dependency injection container. There is no automatic code fix.

## Configuration

The rule is enabled at `warning` by default. It has no rule-specific options.

```editorconfig
[*.cs]
dotnet_diagnostic.PSH1418.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress for a test or benchmark that deliberately measures construction or
disposal. Also suppress when a client has a deliberately isolated lifetime,
or uses an externally managed shared handler, and its connection cost is understood.
