# PSH1421 — Hold a Regex in a cached instance instead of calling the static overload

| Item | Value |
| --- | --- |
| Package | PerformanceSharp.Analyzers |
| Category | ApiSelection |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A static `Regex` call takes a pattern that can be reused. The rule reports:

- A call with a constant pattern, including calls outside loops.
- A call inside a `for`, `foreach`, `while`, or `do` loop when the pattern does not read a variable declared or written by that loop.

Static regex calls look up the pattern in a shared cache each time. Reusing a `Regex` instance avoids that lookup and keeps the pattern available if the shared cache fills up.

## Example

This call uses the same pattern on every pass:

```csharp
using System.Text.RegularExpressions;

public static class TextCleaner
{
    public static void RemoveDigits(string[] values)
    {
        for (var i = 0; i < values.Length; i++)
        {
            values[i] = Regex.Replace(values[i], "[0-9]", "");
        }
    }
}
```

Create the regex once and reuse it:

```csharp
using System.Text.RegularExpressions;

public static class TextCleaner
{
    private static readonly Regex Digits = new Regex("[0-9]");

    public static void RemoveDigits(string[] values)
    {
        for (var i = 0; i < values.Length; i++)
        {
            values[i] = Digits.Replace(values[i], "");
        }
    }
}
```

## What is not reported

Instance calls, `Regex.Escape`, and `Regex.Unescape` are excluded. A pattern built at run time outside a loop is also excluded. Inside a loop, patterns that read the iteration variable or a variable written by the loop are excluded.

A lambda or local function inside a loop is checked separately: a constant pattern still reports, but a run-time pattern does not report because of the surrounding loop.

## How to fix violations

Use a cached field for a fixed pattern. If the pattern is built at run time and stays the same throughout the loop, create a local `Regex` before the loop. Keep the original options and timeout. On .NET 7 or later, a `[GeneratedRegex]` partial method is another option for a constant pattern.

There is no automatic code fix.

## Configuration

The default severity is `warning`, also used by the recommended preset. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1421.severity = warning
```

Allowed severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable the rule for matching files. See [docs/CONFIGURATION.md](../CONFIGURATION.md).

## When to suppress

Suppress when the call runs rarely and keeping a regex instance adds complexity without a measured benefit.
