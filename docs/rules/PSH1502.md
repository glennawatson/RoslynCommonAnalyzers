# PSH1502 — Route handler returns a deferred sequence

| Item | Value |
| --- | --- |
| Package | PerformanceSharp.Analyzers |
| Category | AspNetCore |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A route handler returns `IEnumerable<T>`, `Task<IEnumerable<T>>`, or `ValueTask<IEnumerable<T>>`, and its returned value is a query whose work waits until the items are read. This is called a deferred sequence.

The rule checks lambdas passed to ASP.NET Core `MapGet`, `MapPost`, `MapPut`, `MapDelete`, `MapPatch`, or `Map`, and public instance methods on `ControllerBase` subclasses. It reports an `IQueryable` value or a returned LINQ call to `Where`, `Select`, `SelectMany`, `OrderBy`, `OrderByDescending`, `ThenBy`, or `ThenByDescending`.

The response serializer reads these items synchronously. A database query can therefore block a request thread while the response is written. In-memory filtering also runs during serialization.

## Example

This action leaves filtering until serialization:

```csharp
using System.Collections.Generic;
using System.Linq;
using Microsoft.AspNetCore.Mvc;

public sealed class NumbersController : ControllerBase
{
    private readonly List<int> _items = new List<int> { -1, 1, 2 };

    [HttpGet]
    public IEnumerable<int> Get() => _items.Where(item => item > 0);
}
```

For an in-memory collection, finish the query before returning:

```csharp
using System.Collections.Generic;
using System.Linq;
using Microsoft.AspNetCore.Mvc;

public sealed class NumbersController : ControllerBase
{
    private readonly List<int> _items = new List<int> { -1, 1, 2 };

    [HttpGet]
    public IEnumerable<int> Get() => _items.Where(item => item > 0).ToList();
}
```

## How to fix violations

For database queries, use and await the provider's `ToListAsync` or `ToArrayAsync` method. Another option is an `IAsyncEnumerable<T>` response that reads the data asynchronously. Check that your framework and response formatter support streaming it.

For in-memory data, `ToList` or `ToArray` moves the work into the handler. It still runs synchronously and stores all results in memory; it does not make the computation asynchronous.

There is no automatic code fix.

## What is not reported

The rule skips already-built collections, `IAsyncEnumerable<T>` results, and return types such as `List<T>`, arrays, and `IReadOnlyList<T>`. It also skips private or static controller methods, methods marked `[NonAction]`, and route handlers supplied as method names instead of lambdas.

Minimal API checks require `WebApplication`; controller checks require `ControllerBase`. The rule does not trace arbitrary helper calls or local variables to prove that their contents are deferred.

## Configuration

The default severity is `warning`, also used by the recommended preset. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.PSH1502.severity = warning
```

Allowed severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable the rule for matching files. See [docs/CONFIGURATION.md](../CONFIGURATION.md).

## When to suppress

Suppress for a small, cheap in-memory sequence when creating a list would cost more than reading the sequence during serialization. Do not suppress to leave synchronous database access on the response-writing path.
