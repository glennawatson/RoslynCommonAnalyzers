# SES1004 — A secret must not be produced from Guid.NewGuid()

**Category:** Cryptography  
**Severity:** Warning  
**Code fix:** None.

## Cause

A value from `Guid.NewGuid()`, with or without `.ToString(...)`, is assigned or
passed directly to something named like a secret. A GUID is intended as an
identifier. Use `RandomNumberGenerator` when you need an unpredictable secret with
a chosen size.

The rule checks local variables, fields, properties, assignments, arguments, and
values returned from named methods or properties. It recognizes these words in
names, ignoring case:

- `token`, `secret`, `password`, `passwd`, `pwd`, `nonce`, `salt`, and `otp`.
- `apiKey`, `sessionId`, `sessionKey`, `verificationCode`, and `resetToken`,
  including forms such as `api_key` and `APIKEY`.

Words must be separate parts of the name: `tokenizer` and `correlationId` do not
match. The rule does not follow values through intermediate variables,
conditionals, or values returned by lambdas. It reports nothing when
`RandomNumberGenerator` is unavailable.

## How to fix violations

Bad:

```csharp
using System;

public static class Tokens
{
    public static string CreateToken() => Guid.NewGuid().ToString();
}
```

Generate random bytes and encode them for storage or transport:

```csharp
using System;
using System.Security.Cryptography;

public static class Tokens
{
    public static string CreateToken() =>
        Convert.ToHexString(RandomNumberGenerator.GetBytes(32));
}
```

This example creates 32 random bytes represented by 64 hexadecimal characters.
Check that consumers and storage accept the new length. On frameworks without the
static `GetBytes(int)` helper, use `RandomNumberGenerator.Create()` and fill a byte
array with its `GetBytes` method.

There is no automatic code fix because the required size and format depend on how
the secret is used.

## Configuration

The rule is enabled at `warning` by default. The recognized names cannot be
configured.

```ini
[*.cs]
dotnet_diagnostic.SES1004.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.

## When to suppress

Suppress when the value is only an identifier and its name happens to match, such
as a token used to track work rather than authorize access. Do not suppress for a
value whose possession grants access to an account or resource.
