# SES1010 — Do not implement AES key wrapping by hand

**Category:** Cryptography  
**Severity:** Warning  
**Code fix:** None.

## Cause

Code contains the numeric literal `0xA6A6A6A6A6A6A6A6`, or an array initializer
with exactly eight constant `byte` or `int` values equal to `0xA6`. This is the
initial check value used by AES key wrapping, which encrypts one key using another
key. Hand-written wrapping code can accept damaged or forged input if its checks
are wrong.

The rule checks the constant, not how it is used. Test data and unrelated uses of
the same value can therefore be reported. Shorter arrays and different values are
not reported. The rule reports nothing when the project's framework lacks
`Aes.EncryptKeyWrap`.

## How to fix violations

Bad: a hand-written wrapper defines the AES key-wrap check value.

```csharp
public static class KeyWrap
{
    private const ulong InitialValue = 0xA6A6A6A6A6A6A6A6;

    public static ulong ReadInitialValue() => InitialValue;
}
```

Replace the wrapping routine with the platform API, using an `Aes` instance whose
`Key` is the key-encryption key:

```csharp
using System.Security.Cryptography;

public static class KeyWrap
{
    public static byte[] Wrap(Aes aes, byte[] keyToProtect) =>
        aes.EncryptKeyWrap(keyToProtect);
}
```

Use `Aes.DecryptKeyWrap` for unwrapping and remove the hand-written algorithm and
its check constant. Confirm that the selected API supports your existing wrapping
format and key lengths before migrating stored keys. There is no automatic code
fix because the constant alone does not identify the routines and callers to
replace.

## Configuration

The rule is enabled at `warning` by default. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SES1010.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.

## When to suppress

Suppress for published test vectors or unrelated data with the same value. A
specialist cryptography library may need the constant in a reviewed implementation
of a format the platform API does not support; document that requirement locally.
