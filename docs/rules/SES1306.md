# SES1306 — Do not compile or execute non-constant C# via the scripting API

**Category:** Injection  
**Severity:** Warning  
**Default:** Enabled

## Cause

A non-constant string is passed as the `code` argument to
`Microsoft.CodeAnalysis.CSharp.Scripting.CSharpScript.EvaluateAsync`, `RunAsync`,
or `Create`. This includes variables, parameters, method results, and strings
built with runtime values. Named `code:` arguments are checked too.

When the script runs, it has the host application's privileges. Anyone who
controls its source can choose code to execute. `Create` prepares a script for
later compilation or execution; it does not run it immediately.

## Example

Bad:

```csharp
using System.Threading.Tasks;
using Microsoft.CodeAnalysis.CSharp.Scripting;

public class Calculator
{
    public Task<int> EvaluateAsync(string userInput) =>
        CSharpScript.EvaluateAsync<int>(userInput);
}
```

Corrected, for a fixed calculation:

```csharp
using System.Threading.Tasks;
using Microsoft.CodeAnalysis.CSharp.Scripting;

public class Calculator
{
    public Task<int> EvaluateAsync() => CSharpScript.EvaluateAsync<int>("1 + 1");
}
```

If users need to choose an operation, select from a fixed set of operations and
pass their values as data. Do not insert request text into C# source. A constant
script must still be reviewed for what it does.

No code fix is available; choose the permitted operations and how to supply their data.

## What is not reported

String literals, `const` references, and expressions made entirely from constants
are accepted. `Create` overloads that take a `Stream` are outside this rule.
A local variable holding constant text is still reported when passed as `code`
unless the variable is declared `const`.

The rule reports nothing when the C# scripting API is not referenced by the project.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SES1306.severity = warning
```

The default is `warning`. Allowed severities are `error`, `warning`, `suggestion`,
`silent`, and `none`. There are no rule-specific options.

## When to suppress

Suppress a call in an application whose purpose is to run scripts from authors
trusted with the host's privileges. Document who can supply or modify the source.
If scripts are untrusted, run them in a separate process with restricted access;
the scripting API itself does not provide that isolation.
