# SES1309 — Do not load an XSLT stylesheet with script execution enabled

| Item | Value |
| --- | --- |
| Package | SecuritySharp.Analyzers |
| Category | Injection |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

`XslCompiledTransform.Load` receives settings written directly in the call that
enable embedded script. The rule reports:

- `new XsltSettings { EnableScript = true }`.
- A constructor whose `enableScript` argument is the constant `true`.
- `XsltSettings.TrustedXslt`.

Where script execution is supported, a stylesheet can run code with the
application's permissions. Do not enable it for stylesheets that others can change.

## Example

Reported:

```csharp
using System.Xml.Xsl;

public static class Stylesheets
{
    public static void Load(XslCompiledTransform transform) =>
        transform.Load("style.xslt", XsltSettings.TrustedXslt, null);
}
```

Load with script disabled:

```csharp
using System.Xml.Xsl;

public static class Stylesheets
{
    public static void Load(XslCompiledTransform transform) =>
        transform.Load("style.xslt", XsltSettings.Default, null);
}
```

## How to fix violations

There is no automatic code fix.

Use `XsltSettings.Default` or settings with script disabled. `Default` also disables
the `document()` function; if your stylesheet needs that function, configure it
separately while leaving `EnableScript` false.

Embedded script is supported on .NET Framework. It is not supported on .NET Core
or .NET 5 and later, where enabling it can make stylesheet loading fail.

## What is not reported

Settings with script disabled, settings enabling only `document()`, and calls
without a settings argument are not reported. Settings passed through a variable
are not checked, even if that variable holds script-enabled settings.

The rule reports nothing when `XslCompiledTransform` or `XsltSettings` is unavailable.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SES1309.severity = warning
```

The rule is enabled by default as a warning. There are no
rule-specific options. Severity values are `none`, `silent`, `suggestion`, `warning`,
and `error`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress only when a .NET Framework application requires script in a stylesheet it
fully controls, and untrusted users cannot supply or alter that stylesheet.
