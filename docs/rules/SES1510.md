# SES1510 — An MVC controller must not redirect to a non-constant URL

**Category:** WebHardening
**Severity:** Warning
**Code fix:** No code fix is available.

## Cause

A call to `Redirect`, `RedirectPermanent`, `RedirectPreserveMethod`, or
`RedirectPermanentPreserveMethod` passes one URL argument that is not a
compile-time constant. The method must belong to ASP.NET Core `ControllerBase`
or a class derived from it.

If an attacker controls the URL, the redirect can send a visitor to a malicious
site. This is an open redirect.

## Example

Bad:

```csharp
using Microsoft.AspNetCore.Mvc;

public class HomeController : ControllerBase
{
    public IActionResult Go(string url) => Redirect(url);
}
```

Corrected:

```csharp
using Microsoft.AspNetCore.Mvc;

public class HomeController : ControllerBase
{
    public IActionResult Go(string url) => LocalRedirect(url);
}
```

`LocalRedirect` rejects a URL outside the application by throwing when the
result executes. Use the matching `LocalRedirectPermanent`,
`LocalRedirectPreserveMethod`, or `LocalRedirectPermanentPreserveMethod` variant
when you need to preserve the original redirect behavior.

## What is not reported

Literal URLs and `const` values are not reported. Neither are the
`LocalRedirect` family, `RedirectToAction`, `RedirectToRoute`, or
`RedirectToPage`.

The rule still reports a runtime URL built from trusted values or checked
earlier in the method. For example, an interpolated local path is nonconstant.
It does not examine how the URL was obtained or validated.

## Configuration

Enabled by default. The package default and recommended profile use `warning`.
There are no rule-specific options.

```editorconfig
[*.cs]
dotnet_diagnostic.SES1510.severity = warning
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, `none`, or `default`.
See [Configuration](../CONFIGURATION.md) for details.

## When to suppress

Suppress when external redirects are required and the complete destination is
checked against an explicit list of permitted destinations before redirecting.
A runtime target from configuration also needs protection from untrusted changes.
Prefer `LocalRedirect` for destinations within the application.
