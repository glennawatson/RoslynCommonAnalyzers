# SES1511 — The forwarded-headers trust boundary must not be removed

**Category:** WebHardening
**Severity:** Warning
**Code fix:** No code fix is available.

## Cause

The rule reports either of these changes to ASP.NET Core
`ForwardedHeadersOptions`:

- Calling `.Clear()` directly on `KnownProxies`, `KnownNetworks`, or
  `KnownIPNetworks`.
- Assigning the literal `null` to `ForwardLimit`, directly or in an object
  initializer.

Forwarded headers tell an application behind a proxy about the original client
address, host, and use of HTTPS. Trusting these headers from arbitrary clients
lets those clients supply false values. Keep the trusted proxy and network lists
configured for your deployment, and limit how many proxy hops are accepted.

## Example

Bad:

```csharp
using Microsoft.AspNetCore.Builder;

var options = new ForwardedHeadersOptions();
options.KnownProxies.Clear();
options.ForwardLimit = null;
```

Corrected for a deployment with a trusted proxy at `10.0.0.4`:

```csharp
using System.Net;
using Microsoft.AspNetCore.Builder;

var options = new ForwardedHeadersOptions();
options.KnownProxies.Add(IPAddress.Parse("10.0.0.4"));
options.ForwardLimit = 2;
```

Use your deployment's proxy addresses and hop count. Adding trusted entries and
setting a finite `ForwardLimit` are not reported.

A report on one `Clear()` call does not mean all trusted lists are empty. The
rule does not check other lists or entries added later. Likewise,
`ForwardLimit = null` removes the hop limit; it does not clear the trusted lists.

## Configuration

Enabled by default. The package default and recommended profile use `warning`.
There are no rule-specific options.

```editorconfig
[*.cs]
dotnet_diagnostic.SES1511.severity = warning
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, `none`, or `default`.
See [Configuration](../CONFIGURATION.md) for details.

## When to suppress

Suppress a `Clear()` call when it is part of replacing defaults with explicit
trusted entries before requests are processed. Suppress an unlimited hop count
only when trusted proxy restrictions remain enforced and the deployment requires
it. Record the network restriction that makes the configuration safe.
