# SES1606 — Fetch weights over HTTPS

## Cause

A string literal starts with `http://`, names a host other than a recognized
loopback host, and has a path ending in `.onnx`, `.gguf`, `.safetensors`, `.pt`,
`.pth`, or `.ckpt`. The scheme and extension ignore letter case. Query strings
and fragments do not affect the extension check.

The rule reports the literal in fields, constants, local declarations, and
arguments to loading APIs. An unencrypted download lets someone on the network
replace the weights file, changing the results produced when it is loaded.

## How to fix violations

Use an HTTPS endpoint that serves the intended file:

```csharp
public static class Downloads
{
    // Before: the download is unencrypted.
    public const string Before = "http://weights.example.com/checkpoint.ckpt";

    // After: the download uses HTTPS.
    public const string After = "https://weights.example.com/checkpoint.ckpt";
}
```

Before loading the file, also verify its signature or compare its hash with a
digest obtained from a trusted publisher. HTTPS protects the transfer; it does
not establish that the file itself is trustworthy.

There is no automatic code fix.

## What is not reported

- HTTPS URLs and paths with other extensions, including `.bin`.
- `localhost`, hosts ending in `.localhost`, `127.0.0.1`, and `[::1]`.
- Paths where the extension is not at the end, such as `weights.onnx/download`.
- A complete URL assembled by interpolation, concatenation, or a runtime value.
  A literal within that expression can still trigger the rule on its own.

Storing a matching literal in a variable still reports its declaration. Using
that variable later does not produce another diagnostic from this rule.

## Related rules

[SES1106](SES1106.md) checks cleartext URLs used by `HttpClient`. This rule skips
literals passed directly to its request methods, including through `new Uri(...)`,
and literals in `new Uri(...)` assigned to `HttpClient.BaseAddress`. A matching
literal declared separately is still reported here.

## Configuration

Enabled by default as a warning. The extension and loopback lists cannot be
configured.

```ini
[*.cs]
dotnet_diagnostic.SES1606.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.

## When to suppress

Suppress a literal that is only test data, or a download whose authenticity is
verified before use through a trusted signature or digest when HTTPS is
unavailable. Document that verification at the download site.
