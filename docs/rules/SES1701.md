# SES1701 — Raw HTML is rendered from a non-constant value

## Cause

A non-constant value is passed to `new MarkupString(value)`, cast with
`(MarkupString)value`, or passed as the markup argument of
`RenderTreeBuilder.AddMarkupContent`. These Blazor APIs render raw HTML instead
of encoding text. Untrusted markup can contain event handlers or other content
that runs script in the reader's browser.

String literals and other compile-time constants are accepted. A direct call
to a configured sanitizer is also accepted. An HTML sanitizer removes unsafe
markup while preserving the tags your application allows.

## How to fix violations

Render ordinary text when markup is not required. With `RenderTreeBuilder`,
use `AddContent` with a string:

```csharp
using Microsoft.AspNetCore.Components.Rendering;

public static class CommentRenderer
{
    // Before: treats the comment as HTML.
    public static void Before(RenderTreeBuilder builder, string comment) =>
        builder.AddMarkupContent(0, comment);

    // After: renders the comment as text.
    public static void After(RenderTreeBuilder builder, string comment) =>
        builder.AddContent(0, comment);
}
```

In Razor, render the string as `@comment` instead of `@((MarkupString)comment)`.
If HTML is required, pass it through a trusted sanitizer and configure its
method name. Call it directly in the raw HTML argument, for example
`new MarkupString(sanitizer.SanitizeHtml(comment))`. A result stored in a local
variable is still reported.

There is no automatic code fix.

## Configuration

Enabled by default as a warning.

```ini
[*.cs]
dotnet_diagnostic.SES1701.severity = warning
securitysharp.SES1701.sanitizers = SanitizeHtml
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.

`securitysharp.SES1701.sanitizers` accepts comma-separated method names and
defaults to an empty list. If it is absent, `securitysharp.sanitizers` supplies
the project-wide list, also empty by default. An explicit rule-specific value,
including an empty one, overrides the project-wide list.

Names are case-sensitive and match only the method name: `SanitizeHtml(x)` and
`helper.SanitizeHtml(x)` both match. Adding a name does not check its implementation;
list only methods that actually make the HTML safe. See
[configuration guidance](../CONFIGURATION.md).

## When to suppress

Suppress a specific use when the markup comes only from application-owned
content, or when sanitization happens elsewhere and cannot be expressed as a
direct configured call. Document where that guarantee is enforced.
