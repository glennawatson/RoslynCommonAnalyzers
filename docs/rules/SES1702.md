# SES1702 — A JavaScript interop call targets a script-evaluation primitive

## Cause

An `InvokeAsync` or `InvokeVoidAsync` call on `IJSRuntime`, `IJSObjectReference`,
or an implementation of either interface uses one of these constant function
names:

- `eval` or `Function`, which turn strings into JavaScript code.
- `document.write` or `document.writeln`, which write raw HTML.
- `setTimeout` or `setInterval`, when the next C# argument has type `string`.

Names are case-sensitive. A `const string` function name also counts. The rule
reports the function name even when the supplied script is fixed text.

## How to fix violations

Define a JavaScript function that performs the required work and pass data to it
as arguments:

```csharp
using System.Threading.Tasks;
using Microsoft.JSInterop;

public static class ScriptCalls
{
    // Before: evaluates the argument as JavaScript.
    public static ValueTask Before(IJSRuntime js, string data) =>
        js.InvokeVoidAsync("eval", "app.render(" + data + ")");

    // After: passes a string to the named function.
    public static ValueTask After(IJSRuntime js, string data) =>
        js.InvokeVoidAsync("app.render", data);
}
```

Define `app.render` in your JavaScript and use `textContent` to display its
argument as text. For timers, put the scheduling inside a named JavaScript
function and pass a function callback to the timer.

There is no automatic code fix.

## What is not reported

Other function names and names computed at runtime are ignored. Timer calls
are not reported when the next C# argument is absent or has a type other than
`string`, including `object` or an argument array. These are limits of the
check; they do not prove the value is a function or that the call is safe.

## Configuration

Enabled by default as a warning. There are no rule-specific options or allowed
function lists.

```ini
[*.cs]
dotnet_diagnostic.SES1702.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`.

## When to suppress

Suppress a specific call only when evaluating code is required and every part
of that code is controlled by the application owner. Document why a named
function cannot serve the same purpose.
