# SST0002 — Method declaration parameters should be on unique lines

The diagnostic for this check is [SST1151](SST1151.md). Use that ID for configuration and suppression.

| Item | Value |
| --- | --- |
| Category | Readability |
| Default severity | Warning, enabled |
| Code fix | Yes |

## Cause

A method declaration has two or more parameters whose layout mixes shared lines and line breaks. Keep the opening `(` and all parameter starts on one line, or start every parameter on a separate line below the opening `(`.

The opening `(` counts: putting all parameters together on a line below it is reported, as is keeping the first parameter beside it and wrapping the rest. Lists with zero or one parameter are not reported. Local functions and lambda parameters are not covered by this check.

## How to fix violations

Put each parameter on its own line below the opening `(`, or move the opening `(` and all parameters onto one line.

Bad:

```csharp
public class Example
{
    public void M(int a,
        int b) { }
}
```

Corrected:

```csharp
public class Example
{
    public void M(
        int a,
        int b) { }
}
```

## Code fix

The fix moves every parameter to its own indented line, including the first, and places `)` after the last parameter. It supports Fix All.

The fix replaces spacing and line breaks around the list. It can discard comments before parameters, after commas or the opening `(`, and around the closing `)`. Review the preview when the list contains comments; move those comments yourself if needed.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1151.severity = warning
```

There are no rule-specific layout options. Severity accepts `default`, `none`, `silent`, `suggestion`, `warning`, or `error`. The default is `warning`, with the rule enabled.

## When to suppress

Suppress when grouping related parameters on the same line makes a long list easier to read, or when a file must follow an external formatting convention. Set the severity to `none` for the relevant files if that convention applies throughout them.
