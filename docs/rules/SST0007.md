# SST0007 — Element access expression arguments should be on unique lines

The diagnostic for this check is [SST1156](SST1156.md). Use that ID for configuration and suppression.

| Item | Value |
| --- | --- |
| Category | Readability |
| Default severity | Warning, enabled |
| Code fix | Yes |

## Cause

An array or indexer access has two or more arguments whose layout mixes shared lines and line breaks. Keep the opening `[` and all argument starts on one line, or start every argument on a separate line below the opening `[`.

The opening `[` counts: putting all arguments together on a line below it is reported, as is keeping the first argument beside it and wrapping the rest. Lists with zero or one argument are not reported. This checks access expressions such as `grid[row, column]`, not indexer declarations.

## How to fix violations

Put each argument on its own line below the opening `[`, or move the opening `[` and all arguments onto one line.

Bad:

```csharp
public class Example
{
    public int this[int a, int b] => 0;

    public int Read() => this[
        1, 2];
}
```

Corrected:

```csharp
public class Example
{
    public int this[int a, int b] => 0;

    public int Read() => this[
        1,
        2];
}
```

## Code fix

The fix moves every argument to its own indented line, including the first, and places `]` after the last argument. It supports Fix All.

The fix replaces spacing and line breaks around the list. It can discard comments before arguments, after commas or the opening `[`, and around the closing `]`. Review the preview when the list contains comments; move those comments yourself if needed.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1156.severity = warning
```

There are no rule-specific layout options. Severity accepts `default`, `none`, `silent`, `suggestion`, `warning`, or `error`. The default is `warning`, with the rule enabled.

## When to suppress

Suppress when grouping related arguments on the same line makes a long list easier to read, or when a file must follow an external formatting convention. Set the severity to `none` for the relevant files if that convention applies throughout them.
