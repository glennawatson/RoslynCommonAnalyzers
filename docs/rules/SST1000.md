# SST1000 — Keywords should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning (enabled) |
| Code fix | Yes |

## Cause

The opening `(` touches one of these keywords: `if`, `while`, `for`, `foreach`, `switch`,
`lock`, `using`, `fixed`, or `catch`. A space, tab, or line break between them is accepted.
This rule does not require a space after other keywords, such as `typeof`.

## Example

Bad:

```csharp
class C
{
    void M(bool enabled)
    {
        if(enabled)
        {
        }
    }
}
```

Corrected:

```csharp
class C
{
    void M(bool enabled)
    {
        if (enabled)
        {
        }
    }
}
```

## How to fix violations

The **Fix spacing** code fix inserts one space after the keyword.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1000.severity = warning
```

The default is `warning`. The other values are `error`, `suggestion`, `silent`, and `none`.
There are no spacing options. See [configuration](../CONFIGURATION.md) for file-specific settings.

## When to suppress

Use `none` for files that must follow a formatting convention without spaces after these keywords.
