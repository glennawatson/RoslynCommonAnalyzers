# SST1003 — Symbols should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning (enabled) |
| Code fix | Yes |

## Cause

A binary operator, such as `+`, `==`, or `&&`, touches an operand without a separating
space. The rule also checks assignment expressions such as `total= value` and
`total+= value`. A space, tab, or line break is accepted on either side.

The `=` in a variable declaration, such as `int total= 0;`, is not checked by this rule.
Unary signs are covered by [SST1021](SST1021.md) and [SST1022](SST1022.md); generic
brackets are covered by [SST1014](SST1014.md) and [SST1015](SST1015.md).

## Example

Bad:

```csharp
class C
{
    int Add(int a, int b) => a+ b;
}
```

Corrected:

```csharp
class C
{
    int Add(int a, int b) => a + b;
}
```

## How to fix violations

The **Fix spacing** code fix inserts one space on the reported side of the operator.
Use Fix All when both sides need spaces.

For code such as `total =+ value`, check whether you meant `total += value` before changing
the spacing. [SST2417](SST2417.md) checks that mistake; this rule leaves the gap after `=` alone.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1003.severity = warning
```

The default is `warning`. The other values are `error`, `suggestion`, `silent`, and `none`.
There are no spacing options. See [configuration](../CONFIGURATION.md) for file-specific settings.

## When to suppress

Use `none` where a required notation keeps operators tight, such as compact mathematical formulas.
