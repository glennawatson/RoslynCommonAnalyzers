# SST1004 — Documentation lines should begin with a single space

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning (enabled) |
| Code fix | Yes |

## Cause

A documentation comment line has text immediately after `///` with no separating space.
Each line is checked. A space, tab, or empty documentation line is accepted; the rule does
not require exactly one space. Comments starting with `////` are not documentation comments
and are excluded.

## Example

Bad:

```csharp
class C
{
    ///<summary>Does something.</summary>
    public void M() { }
}
```

Corrected:

```csharp
class C
{
    /// <summary>Does something.</summary>
    public void M() { }
}
```

## How to fix violations

The **Fix spacing** code fix inserts one space after `///` on the reported line. It keeps
the documentation text and its line breaks. Use Fix All to correct several lines.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1004.severity = warning
```

The default is `warning`. The other values are `error`, `suggestion`, `silent`, and `none`.
There are no spacing options. See [configuration](../CONFIGURATION.md) for file-specific settings.

## When to suppress

Use `none` for imported documentation whose source layout must be preserved.
