# SST1005 — Single-line comments should begin with a single space

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning (enabled) |
| Code fix | Yes |

## Cause

A single-line comment has a character other than a space or another `/` immediately after
`//`. A tab immediately after `//` is reported. An empty `//`, comments starting with extra
slashes, and comments starting with one or more spaces are accepted.

Documentation comments are covered by [SST1004](SST1004.md).

## Example

Bad:

```csharp
class C
{
    //comment
    public int Value;
}
```

Corrected:

```csharp
class C
{
    // comment
    public int Value;
}
```

## How to fix violations

The **Fix spacing** code fix inserts one space after `//`. It keeps the rest of the comment,
including any tab that follows the inserted space. Use Fix All to correct several comments.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1005.severity = warning
```

The default is `warning`. The other values are `error`, `suggestion`, `silent`, and `none`.
There are no spacing options. See [configuration](../CONFIGURATION.md) for file-specific settings.

## When to suppress

Suppress a comment when another tool requires an exact marker with no space after `//`.
Use `none` for files that must preserve such markers throughout.
