# SST1006 — Preprocessor keywords should not be preceded by a space

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning (enabled) |
| Code fix | Yes |

## Cause

A directive keyword is separated from its leading `#` by whitespace, as in `# if`.
The rule checks directives such as `#if`, `#else`, `#endif`, `#region`, `#endregion`,
`#nullable`, and `#pragma`. Indentation before `#` is not reported by this rule.

## Example

Bad:

```csharp
# if true
class C
{
}
#endif
```

Corrected:

```csharp
#if true
class C
{
}
#endif
```

## How to fix violations

The **Fix spacing** code fix removes spaces and tabs between `#` and the keyword. It keeps
the directive's condition or other text and the indentation before `#`.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1006.severity = warning
```

The default is `warning`. The other values are `error`, `suggestion`, `silent`, and `none`.
There are no spacing options. See [configuration](../CONFIGURATION.md) for file-specific settings.

## When to suppress

Use `none` for files that use spaces after `#` to show the nesting of directives.
