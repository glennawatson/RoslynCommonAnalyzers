# SST1007 — Operator keyword should be followed by a space

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning (enabled) |
| Code fix | Yes |

## Cause

The `operator` keyword touches what follows it without a separating space, as in `operator+`.
A space, tab, or line break is accepted. The rule checks operator declarations, not the
spacing of expressions that use those operators.

## Example

Bad:

```csharp
class C
{
    public static C operator+(C a, C b) => a;
}
```

Corrected:

```csharp
class C
{
    public static C operator +(C a, C b) => a;
}
```

## How to fix violations

The **Fix spacing** code fix inserts one space after `operator`. It keeps the operator
symbol, parameters, and body.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1007.severity = warning
```

The default is `warning`. The other values are `error`, `suggestion`, `silent`, and `none`.
There are no spacing options. See [configuration](../CONFIGURATION.md) for file-specific settings.

## When to suppress

Use `none` for files whose required style writes operator declarations without this space.
