# SST1008 — Opening parenthesis should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning (enabled) |
| Code fix | Yes |

## Cause

An opening `(` is followed by spaces or tabs on the same line. This includes empty
parentheses written as `( )`. A comment between `(` and the next item also triggers the
rule. A line break after `(` is accepted.

The space before `(` after a control-flow keyword is covered by [SST1000](SST1000.md).

## Example

Bad:

```csharp
class C
{
    static int N(int x) => x;
    int M(int x) => N( x);
}
```

Corrected:

```csharp
class C
{
    static int N(int x) => x;
    int M(int x) => N(x);
}
```

## How to fix violations

The **Fix spacing** code fix removes spaces and tabs immediately before the item following
`(`, or before `)` for empty parentheses. It keeps comments and line breaks. A comment
between `(` and the next item still triggers the rule after the fix. Move the comment
outside the parentheses or put the next item on a new line.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1008.severity = warning
```

The default is `warning`. The other values are `error`, `suggestion`, `silent`, and `none`.
There are no spacing options. See [configuration](../CONFIGURATION.md) for file-specific settings.

## When to suppress

Use `none` for files whose required style puts spaces inside parentheses.
