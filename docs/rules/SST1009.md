# SST1009 — Closing parenthesis should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

A space or tab appears before `)` on the same line. This applies to calls,
parameter lists, conditions, and other parenthesized expressions. A line break
before `)` is allowed. Spaces in empty parentheses, such as `( )`, are handled
by [SST1008](SST1008.md).

## Example

Reported:

```csharp
System.Console.WriteLine(1 );
```

Corrected:

```csharp
System.Console.WriteLine(1);
```

## How to fix violations

Choose **Fix spacing** to remove spaces and tabs immediately before `)`.
The fix preserves comments and line breaks. A comment between the expression
and `)` can also trigger the rule; move that comment if the warning remains.

## Configuration

The default severity is `warning`. To treat violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1009.severity = error
```

Severity can be `error`, `warning`, `suggestion`, `silent`, or `none`. There are
no rule-specific options.

## When to suppress

Disable the rule if your team's format requires spaces inside parentheses.
Suppress an individual warning if a comment must stay before the closing parenthesis.
