# SST1010 — Opening square brackets should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning (disabled by default) |
| Code fix | Yes |

## Cause

A space or tab appears before or after `[` in an array type or an access such as
`items[0]`. For collection expressions (`[1, 2]`) and list patterns (`items is [1, 2]`),
spacing after `[` must match the configured style. Line breaks are allowed.

Spaces before a collection expression, list pattern, or indexed initializer such
as `{ ["a"] = 1 }` are allowed. Attribute brackets are handled by
[SST1016](SST1016.md). Spaces between `new` or `stackalloc` and `[` are handled by
[SST1026](SST1026.md).

## Example

Reported when the rule is enabled:

```csharp
int[] items = { 1, 2 };
int first = items [0];
```

Corrected:

```csharp
int[] items = { 1, 2 };
int first = items[0];
```

## How to fix violations

Choose **Fix spacing** to remove spaces and tabs beside `[` or add a space after
it, as the configured style requires. The fix preserves comments and line breaks.
A comment beside `[` can keep a warning active when spaces are forbidden; move
that comment if needed.

## Configuration

The rule is disabled by default. Enable it with:

```ini
[*.cs]
dotnet_diagnostic.SST1010.severity = warning
stylesharp.collection_expression_spacing = none
```

Severity can be `error`, `warning`, `suggestion`, `silent`, or `none`.

[`stylesharp.collection_expression_spacing`](../CONFIGURATION.md#collection-expression-spacing)
controls collection expressions and list patterns:

| Value | Spacing inside non-empty brackets |
| --- | --- |
| `none` (default) | No padding: `[1, 2]` |
| `space` | Padding required: `[ 1, 2 ]` |

The option also controls [SST1011](SST1011.md) at the closing bracket. Empty `[]`
is accepted with either setting; `space` also accepts `[ ]`. Array, element-access,
and indexed-initializer brackets always use no inner padding.

## When to suppress

Leave the rule disabled if your team's format requires spaces around array or
element-access brackets. For padded collections, choose `space` instead. Suppress
an individual warning if a comment beside `[` must stay in place.
