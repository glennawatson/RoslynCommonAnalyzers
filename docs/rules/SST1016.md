# SST1016 — Opening attribute brackets should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

A space or tab appears after `[` on the same line in an attribute list, such as
`[Obsolete]`. A line break after `[` is allowed. Array and collection brackets
are handled by [SST1010](SST1010.md).

## Example

Reported:

```csharp
[ System.Obsolete]
class Legacy { }
```

Corrected:

```csharp
[System.Obsolete]
class Legacy { }
```

## How to fix violations

Choose **Fix spacing** to remove the spaces and tabs before the first item inside
`[`. The fix preserves comments and line breaks. A comment after `[` can also
trigger the rule; move it if the warning remains.

## Configuration

The default severity is `warning`. To treat violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1016.severity = error
```

Severity can be `error`, `warning`, `suggestion`, `silent`, or `none`. There are
no rule-specific options.

## When to suppress

Disable the rule if your team's format requires spaces inside attribute brackets.
Suppress an individual warning if a comment after `[` must stay in place.
