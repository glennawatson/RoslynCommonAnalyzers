# SST1017 — Closing attribute brackets should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

A space or tab appears before `]` on the same line in an attribute list, such as
`[Obsolete]`. A line break before `]` is allowed. Array and collection brackets
are handled by [SST1011](SST1011.md).

## Example

Reported:

```csharp
[System.Obsolete ]
class Legacy { }
```

Corrected:

```csharp
[System.Obsolete]
class Legacy { }
```

## How to fix violations

Choose **Fix spacing** to remove spaces and tabs immediately before `]`.
The fix preserves comments and line breaks. A comment before `]` can also
trigger the rule; move it if the warning remains.

## Configuration

The default severity is `warning`. To treat violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1017.severity = error
```

Severity can be `error`, `warning`, `suggestion`, `silent`, or `none`. There are
no rule-specific options.

## When to suppress

Disable the rule if your team's format requires spaces inside attribute brackets.
Suppress an individual warning if a comment before `]` must stay in place.
