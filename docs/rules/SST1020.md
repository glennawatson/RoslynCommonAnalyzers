# SST1020 — Increment and decrement symbols should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

A space or tab separates `++` or `--` from the value it changes on the same line.
This applies when the operator is before the value (`++count`) or after it
(`count++`). A line break between them is allowed.

## Example

Reported:

```csharp
int count = 0;
count ++;
-- count;
```

Corrected:

```csharp
int count = 0;
count++;
--count;
```

## How to fix violations

Choose **Fix spacing** to remove spaces and tabs between the operator and the
value. The fix keeps the operator on the same side of the value and preserves
comments and line breaks. A comment in the gap can also trigger the rule; move it
if the warning remains.

## Configuration

The default severity is `warning`. To treat violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1020.severity = error
```

Severity can be `error`, `warning`, `suggestion`, `silent`, or `none`. There are
no rule-specific options.

## When to suppress

Disable the rule if your team's format requires a space beside `++` or `--`.
Suppress an individual warning if a comment between the operator and value must stay in place.
