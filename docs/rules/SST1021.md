# SST1021 — Negative signs should be spaced correctly

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

A `-` used to negate a value is separated from that value on the same line.
Write `-value`, with no space after the sign.

Subtraction such as `a - b` is not reported. A line break after the sign is
allowed. Assignments such as `x =- 1` are handled by [SST2417](SST2417.md): check
whether you meant `x -= 1` before changing the spacing.

## Example

Before:

```csharp
class C
{
    int Negate(int value) => - value;
}
```

After:

```csharp
class C
{
    int Negate(int value) => -value;
}
```

## How to fix violations

The code fix removes spaces and tabs immediately before the value. It keeps
comments and line breaks. If a comment separates the sign from the value, move
the comment by hand.

## Configuration

The default severity is `warning`. There are no rule-specific options. To report
violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1021.severity = error
```

Other severity values are `warning`, `suggestion`, `silent`, and `none`.

## When to suppress

Disable the rule with `none` if your team deliberately puts a space after
negative signs. Otherwise, remove the space.
