# SST1025 — Code should not contain multiple whitespace characters in a row

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

Two or more spaces follow code on a line, before more code or a comment.
Use a single space between code elements.

Leading indentation and spaces inside strings or comments are not reported.
Whitespace containing tabs is handled by [SST1027](SST1027.md). Whitespace at
the end of a line is handled by [SST1028](SST1028.md).

## Example

Before:

```csharp
class C
{
    private  int GetValue() => 1;
}
```

After:

```csharp
class C
{
    private int GetValue() => 1;
}
```

## How to fix violations

The code fix replaces the reported run of spaces with one space. This removes
extra spaces used to align code or comments in columns. It keeps indentation,
line breaks, and comment text.

## Configuration

The default severity is `warning`. There are no options to allow alignment or
change the number of spaces. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1025.severity = error
```

Other severity values are `warning`, `suggestion`, `silent`, and `none`.

## When to suppress

Suppress the rule for a block where column alignment makes related values
easier to compare. Set the severity to `none` if this alignment is your team's
standard style.
