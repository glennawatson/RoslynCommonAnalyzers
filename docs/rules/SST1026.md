# SST1026 — Implicit array creation should not contain a space before the bracket

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

There is a gap on the same line between `new` or `stackalloc` and `[` when the
element type is inferred. Write `new[]` or `stackalloc[]`.

Arrays with an explicit type, such as `new int[3]`, are not reported by this
rule. A line break before `[` is allowed.

## Example

Before:

```csharp
class C
{
    int[] Create() => new [] { 1 };
}
```

After:

```csharp
class C
{
    int[] Create() => new[] { 1 };
}
```

## How to fix violations

The code fix removes spaces and tabs immediately before `[`. It keeps comments
and line breaks. If a comment separates the keyword from `[`, move the comment
by hand.

## Configuration

The default severity is `warning`. There are no rule-specific options. To report
violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1026.severity = error
```

Other severity values are `warning`, `suggestion`, `silent`, and `none`.

## When to suppress

Disable the rule with `none` if your team deliberately writes `new []` or
`stackalloc []`. Otherwise, remove the space.
