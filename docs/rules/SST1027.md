# SST1027 — Use spaces rather than tabs

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

A tab appears in indentation or between code elements. Use spaces instead.

Tabs inside strings or comments are not reported. Tabs at the end of a line
are handled by [SST1028](SST1028.md).

## Example

Before, the method is indented with one tab:

```csharp
class C
{
	private int GetValue() => 1;
}
```

After, the method is indented with four spaces:

```csharp
class C
{
    private int GetValue() => 1;
}
```

## How to fix violations

The code fix replaces each reported tab with exactly four spaces and keeps any
existing spaces. It does not calculate tab stops. Alignment can change if your
editor displays tabs at a different width or a tab follows existing spaces.

## Configuration

The default severity is `warning`. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1027.severity = error
```

Other severity values are `warning`, `suggestion`, `silent`, and `none`.
The rule does not read `indent_style`, `indent_size`, or `tab_width`. There is
no option to change the fix's four-space replacement.

## When to suppress

Set the severity to `none` if your team uses tabs. Setting `indent_style = tab`
alone does not disable this rule.
