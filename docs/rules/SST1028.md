# SST1028 — Code should not contain trailing whitespace

| Item | Value |
| --- | --- |
| Category | Spacing |
| Default severity | Warning |
| Code fix | Yes |

## Cause

Spaces or tabs appear after code at the end of a line, on an otherwise blank
line, or at the end of the file.

Whitespace inside strings or comment text is not reported, including spaces
at the end of a `//` comment.

## Example

Before, there is one trailing space after `C`:

```csharp
class C 
{
}
```

After:

```csharp
class C
{
}
```

## How to fix violations

The code fix deletes the reported spaces and tabs. It keeps the line break,
so an empty line stays empty rather than being removed. It does not trim string
values or comment text.

## Configuration

The default severity is `warning`. There are no rule-specific options. To report
violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1028.severity = error
```

Other severity values are `warning`, `suggestion`, `silent`, and `none`.

## When to suppress

Suppress the rule when a file must preserve exact whitespace for an external
tool or comparison. Otherwise, remove the trailing whitespace.
