# SST1114 — Parameter list should follow the declaration

| Item | Value |
| --- | --- |
| Category | Readability |
| Default severity | Warning |
| Code fix | No |

## Cause

The first parameter or argument starts more than one line after the opening `(` or `[`. This
applies to declarations, calls, indexers, array access, and attribute arguments.

The first item must start on the opening character's line or the next line. Intervening comment
lines also count as a gap. Empty lists are not reported by this rule.

## Example

Bad:

```csharp
class Example
{
    public void Set(

        int x) => _ = x;
}
```

Corrected:

```csharp
class Example
{
    public void Set(
        int x) => _ = x;
}
```

## How to fix violations

Remove blank lines before the first item. Move any intervening comment above the declaration
or call, or onto the item's line. There is no code fix.

## Configuration

The rule is enabled as a warning by default. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1114.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none` (disabled).

## When to suppress

Suppress when a comment immediately before the first item is clearer than placing it elsewhere.
Remove gaps that do not explain the item.
