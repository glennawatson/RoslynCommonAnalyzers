# SST1116 - Prefer the shortest symbol-equivalent name

Qualified type and namespace names should be shortened when the shorter spelling resolves to the
same symbol. The analyzer first looks for a qualified-name shape and then asks Roslyn whether the
short name binds to the same type or namespace, so it avoids reporting names that would become
ambiguous.

## Example

```csharp
using System.Text;

public int Count(System.Text.StringBuilder builder) => builder.Length;
```

Use:

```csharp
using System.Text;

public int Count(StringBuilder builder) => builder.Length;
```

## What is not reported

A name that more than one thing in scope answers to. Two imported namespaces declaring the same
type name make the short spelling ambiguous, so both stay qualified:

```csharp
using System.Text.Json;
using Newtonsoft.Json;

// not reported — bare 'JsonException' is CS0104
public void Handle(System.Text.Json.JsonException error)
{
}
```

The short name has to be the *only* answer at that position, not merely one of them — a nearer
declaration of the same name would capture it instead. Candidates are compared at the arity the name
is used with, so `Task` and `Task<TResult>` do not shadow each other.

## Notes

This rule intentionally skips namespace declarations and using directives. Its hot path is a
syntax-kind filter; semantic speculative binding only runs after a candidate qualified name is
found.
