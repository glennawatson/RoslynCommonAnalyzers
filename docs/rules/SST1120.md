# SST1120 — Comments should contain text

| Item | Value |
| --- | --- |
| Category | Readability |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An ordinary `//` or `/* */` comment contains only whitespace or no content at all. Extra slashes in `////` count as content. Documentation comments (`///` and `/** */`) are handled by [SST1659](SST1659.md).

```csharp
class Counter
{
    //
    public int Value;
}
```

## How to fix violations

Remove the empty comment, or replace it with useful text:

```csharp
class Counter
{
    public int Value;
}
```

The code fix removes the comment. If the comment occupies its own line or lines, it removes those lines too. If the comment shares a line with code, it removes the comment and the spaces or tabs immediately before it.

## Configuration

Enabled by default as a warning. There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1120.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none` (disable), and `default` (restore the default).

## When to suppress

Suppress when an external tool requires an empty comment as a marker. For visual spacing, use a blank line instead.
