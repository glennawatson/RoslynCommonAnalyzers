# SST1124 — Do not use regions

| Item | Value |
| --- | --- |
| Category | Readability |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A `#region` directive appears in the file. The rule applies to regions around types or members and to regions inside method bodies.

```csharp
class Counter
{
    #region Fields
    public int Value;
    #endregion
}
```

## How to fix violations

Remove the matching `#region` and `#endregion` directives:

```csharp
class Counter
{
    public int Value;
}
```

There is no code fix. If a file needs many named groups, consider splitting it into smaller types or partial class files.

## Configuration

Enabled by default as a warning. There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1124.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none` (disable), and `default` (restore the default).

## When to suppress

Suppress regions required by a tool or retained to navigate a large interface implementation. If your team permits regions around members but forbids them inside methods, disable this rule and use [SST1123](SST1123.md).
