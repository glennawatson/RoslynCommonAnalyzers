# SST1138 — A free-standing block that declares nothing should be removed

| Item | Value |
| --- | --- |
| Category | Readability |
| Default severity | Warning |
| Code fix | Yes, except around directives |
| Default | Enabled |

## Cause

A pair of braces sits directly inside another block without declaring a name that needs those
braces. Removing it reduces nesting while keeping the statements in the same order.

Blocks that declare locals, local functions, or labels are left alone. So are blocks that introduce
named variables through patterns, `out var`, or deconstruction into that block's scope: the part of
the code where a name can be used. This includes variables introduced in an `if`, `switch`, or `lock`
condition. Variables belonging only to a nested loop or `using (...)` statement do not protect the
surrounding braces.

Method bodies and loop bodies are not free-standing blocks. A comment-only block is also left alone,
as is a block with a comment directly after its opening brace or directly before its closing brace.

## Example

Bad:

```csharp
public class Output
{
    public void Write()
    {
        {
            System.Console.WriteLine("a");
            System.Console.WriteLine("b");
        }
    }
}
```

Corrected:

```csharp
public class Output
{
    public void Write()
    {
        System.Console.WriteLine("a");
        System.Console.WriteLine("b");
    }
}
```

## How to fix violations

The code fix removes the inner braces, moves the statements into the enclosing block, and formats
the moved statements. An empty block is removed entirely. Comments attached to the removed braces
can be lost; move them onto retained statements first.

The diagnostic can appear without a fix when the block contains or carries directives such as
`#if` or `#region`. Remove the braces by hand while preserving those directives.

## Configuration

There are no rule-specific options. To treat violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1138.severity = error
```

Severity values are `error`, `warning` (default), `suggestion`, `silent`, and `none`.

See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when the extra braces deliberately group a distinct step and that grouping is useful to readers.
