# SST1146 — An if statement should start on a new line

| Item | Value |
| --- | --- |
| Category | Readability |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An independent `if` follows a closing `}` on the same line. Starting it on a new
line makes the two statements easier to distinguish. Normal `else if` clauses are
not reported.

## Example

Bad:

```csharp
public class Example
{
    public void Check(bool first, bool second)
    {
        if (first) { } if (second) { }
    }
}
```

Good:

```csharp
public class Example
{
    public void Check(bool first, bool second)
    {
        if (first) { }
        if (second) { }
    }
}
```

## Code fix

The fix replaces everything between `}` and `if` with a newline and the original
line's indentation. It follows the file's newline style. A comment between the
brace and `if` is deleted, so move that comment before accepting the fix.

## Configuration

The rule is enabled at warning severity and has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1146.severity = warning
```

Set the severity to `none` to disable it. See [configuration](../CONFIGURATION.md)
for severity and file-specific settings.

## When to suppress

Suppress this rule in a small, deliberately compact example where keeping both
statements on one line helps the reader compare them.
