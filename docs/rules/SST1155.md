# SST1155 — Object creation arguments should be on unique lines

| Item | Value |
| --- | --- |
| Package | StyleSharp.Analyzers |
| Category | Readability |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A `new Type(...)` expression with at least two arguments mixes shared and separate
lines. Keep all arguments on the opening `(` line, or start every argument on
its own line after `(`. A wrapped list is reported even when only the first
argument shares the opening line.

Empty lists and lists with one argument are not reported. The rule checks where
each argument starts; it does not require a long argument to fit on one line.

The `new(...)` form that omits the type name is covered by [SST1163](SST1163.md).

## Example

Bad:

```csharp
public class Target
{
    public Target(int first, int second) { }
}

public class Example
{
    public Target Create() => new Target(
        1, 2);
}
```

Good:

```csharp
public class Target
{
    public Target(int first, int second) { }
}

public class Example
{
    public Target Create() => new Target(
        1,
        2);
}
```

## Code fix

The fix starts every argument on a separate line after `(`, indents the list
by four spaces, and puts `)` after the last argument. It follows the file's
newline style. It can discard comments before arguments, around commas, or beside
the opening and closing brackets. Move those comments before accepting the fix,
or adjust the line breaks by hand. Keeping a short list on the opening line also
satisfies the rule.

## Configuration

The rule is enabled at warning severity and has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1155.severity = warning
```

Set the severity to `none` to disable it. See [configuration](../CONFIGURATION.md)
for severity and file-specific settings.

## When to suppress

Suppress this rule when a constructor call deliberately groups related arguments
on the same line, such as coordinates or rows of test data.
Use a file-specific severity setting when the whole file follows that layout.
