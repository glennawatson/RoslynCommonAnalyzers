# SST1174 - Redundant jump statements should be removed

| Item | Value |
| --- | --- |
| Package | StyleSharp.Analyzers |
| Category | Readability |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A `return;` is the last statement directly inside a method, local function,
constructor, destructor, accessor or anonymous function body. A `continue;` is
the last statement directly inside a `for`, `foreach`, `while` or `do` loop body.
In these positions, execution already goes to the same place without the jump.

A return with a value is not reported. Neither jump is reported inside a nested
`if`, `try`, `switch` or other inner block. The loop body must use braces;
`foreach` loops that unpack elements into several variables are not checked.

## Example

Reported:

```csharp
public class Logger
{
    public void Log(int count)
    {
        for (int i = 0; i < count; i++)
        {
            System.Console.WriteLine(i);
            continue;
        }

        return;
    }
}
```

Corrected:

```csharp
public class Logger
{
    public void Log(int count)
    {
        for (int i = 0; i < count; i++)
        {
            System.Console.WriteLine(i);
        }
    }
}
```

## How to fix violations

The code fix deletes the reported statement. It can also delete comments directly
above it or on the same line. Move any useful comments before accepting the fix.

## Configuration

The rule is enabled by default with warning severity. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1174.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none` and
`default`. Use `none` to disable the rule or `default` to use its declared
default. See [Configuration](../CONFIGURATION.md) for settings that apply to specific files.

## When to suppress

Suppress when an explicit final jump is required by your team's coding convention. Early exits and jumps inside nested blocks do not need suppression.
