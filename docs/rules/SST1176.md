# SST1176 - Members should not be initialized to their default value

| Item | Value |
| --- | --- |
| Package | StyleSharp.Analyzers |
| Category | Readability |
| Severity | Warning |
| Code fix | Yes |
| Default | Disabled (opt-in) |

## Cause

A field, event or auto-property has an initializer written as numeric
zero, `false`, `null`, `'\0'`, `default` or `default(T)`. For ordinary members with
that default value, the initializer repeats the value they receive automatically.

The rule is off by default because explicit initial values can help readers.
`const` fields, local variables and named values such as a zero-valued enum member
are not reported.

## Example

Reported when the rule is enabled:

```csharp
public class State
{
    public int Count = 0;

    public bool Ready { get; set; } = false;
}
```

Corrected:

```csharp
public class State
{
    public int Count;

    public bool Ready { get; set; }
}
```

## How to fix violations

The code fix removes the initializer and keeps the member. For an auto-property,
it also removes the trailing semicolon. Field and event declarations keep their
semicolons. Comments inside the initializer can be lost; move them before
accepting the fix.

## Configuration

The rule is disabled by default. Set its severity to `warning` to enable it. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1176.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none` and
`default`. Use `none` to disable the rule or `default` to use its declared
default. See [Configuration](../CONFIGURATION.md) for settings that apply to specific files.

## When to suppress

Leave the rule disabled, or suppress it locally, when explicit initial values improve readability.

Keep the initializer and suppress the diagnostic when the value differs from the member's actual default. For example, an `int?` field initialized to `0` changes to `null` if the initializer is removed. The same issue applies to `false` assigned to `bool?`, or a literal passed through a custom conversion.
