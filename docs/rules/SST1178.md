# SST1178 - Redundant base constructor calls should be removed

| Item | Value |
| --- | --- |
| Package | StyleSharp.Analyzers |
| Category | Readability |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A constructor explicitly calls `: base()` without arguments. C# makes the same
base-constructor call when this is omitted.

Calls that pass arguments, such as `: base(value)`, are not reported. Neither are
`: this(...)` calls, which select another constructor in the same class.

## Example

Reported:

```csharp
public class Widget
{
    public Widget()
        : base()
    {
    }
}
```

Corrected:

```csharp
public class Widget
{
    public Widget()
    {
    }
}
```

## How to fix violations

The code fix deletes `: base()` and leaves the constructor body in place. The base
constructor still runs. Comments attached to the removed call can be lost; move
them before accepting the fix.

## Configuration

The rule is enabled by default with warning severity. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1178.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none` and
`default`. Use `none` to disable the rule or `default` to use its declared
default. See [Configuration](../CONFIGURATION.md) for settings that apply to specific files.

## When to suppress

Suppress when your team's convention requires every constructor to show its base-constructor call explicitly.
