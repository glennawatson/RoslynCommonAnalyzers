# SST1180 — Empty else clauses should be removed

| Item | Value |
| --- | --- |
| Category | Readability |
| Default severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An `else` body is an empty block or a lone semicolon. A block containing only comments is also reported. An `else if` branch is not reported as an empty `else`.

## Example

Bad:

```csharp
public class Example
{
    public void Print(bool ready)
    {
        if (ready)
        {
            System.Console.WriteLine("Ready");
        }
        else
        {
        }
    }
}
```

Good:

```csharp
public class Example
{
    public void Print(bool ready)
    {
        if (ready)
        {
            System.Console.WriteLine("Ready");
        }
    }
}
```

## Code fix

The fix deletes the whole `else` clause, including comments inside it. Move any useful explanation above the `if` before accepting the fix.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1180.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an explicit empty branch is required to show that a case was considered, such as code that must follow a written decision table. Explain why the branch does nothing.
