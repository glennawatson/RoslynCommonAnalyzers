# SST1189 — Variables should not be self-assigned

| Item | Value |
| --- | --- |
| Category | Readability |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |
| Analyzer | `ExpressionSimplificationAnalyzer` |

## Cause

An assignment copies a value onto itself (`x = x`), which has no effect.

```csharp
// 👎 reported
_value = _value;

// 👍 — remove it, or correct the intended target or source
```

## Rule description

A simple assignment is reported when its left and right sides name the same thing and the target is
side-effect-free (an identifier, `this`, or a member-access chain of those). It usually signals a typo
where a different field, parameter, or local was meant. Assignments involving an indexer or method
call are left alone.

Sides spelled differently are compared by what they bind to, so the `this`-qualified spelling is
reported — but only when the unqualified side really is the same member:

```csharp
// 👎 reported — both sides are the field
public void M() => this._value = _value;

// 👍 not reported — the right side is the parameter, so the assignment does real work
public C(int _value) => this._value = _value;
```

A tuple assignment is judged one element at a time, because it is redundant per element rather than
as a whole:

```csharp
// 👎 reported on x only — the y element still moves a value
(x, y) = (x, z);
```

An assignment inside an **object or `with` initializer** is not reported. There the left side names a
member of the object being built and the right side reads the enclosing instance, so two identical
names are two different members of two different objects:

```csharp
// 👍 not reported — copies this instance's Name onto the new one
public C Clone() => new() { Name = Name };
```

## How to fix violations

Remove the self-assignment, or correct the target or source. The provided code fix deletes the
statement. A tuple element is reported on its own and has no fix: deleting the statement would also
drop the elements that still move a value, and only the author knows which side was meant to differ.
