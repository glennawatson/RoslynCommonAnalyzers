# SST1195 — Write null fallback with ??

| Item | Value |
| --- | --- |
| Category | Readability |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A `?:` expression compares a local variable or parameter with `null`, returns a fallback when it
is null, and returns the same variable otherwise. Both `== null` and `!= null` forms are reported,
including comparisons with `null` on the left.

Fields, properties, method calls, and `is null` checks are not reported.

## Example

Reported:

```csharp
public class C
{
    public string Choose(string value, string fallback)
        => value == null ? fallback : value;
}
```

Corrected:

```csharp
public class C
{
    public string Choose(string value, string fallback)
        => value ?? fallback;
}
```

`??` returns its left value unless that value is null. It evaluates the fallback only when needed.

## Code fix

The code fix replaces the whole `?:` expression with `value ?? fallback`. The repeated variable
must be written the same way in both places; different parentheses can prevent the fix from being
offered. Comments in the removed comparison or repeated value can be lost.

## Configuration

The default is an enabled warning. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1195.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`; `none` disables the rule.
There are no other options.

## When to suppress

Suppress when the type defines its own `==` or `!=` behavior and replacing that comparison with
a null check would change the result.
