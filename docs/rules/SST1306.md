# SST1306 — Field names should begin with a lower-case letter

| Item | Value |
| --- | --- |
| Category | Naming |
| Severity | Warning (disabled by default) |
| Code fix | No |

## Cause

A field name starts with an upper-case letter. This includes fields of any
accessibility, `const` fields, and `static readonly` fields.

Names starting with an underscore, such as `_value` or `_Value`, are not reported.
Only the first character is checked.

## How to fix violations

Rename the field and its uses to start with a lower-case letter.
There is no automatic code fix.

Reported when enabled:

```csharp
internal class C
{
    private int Field;
}
```

Corrected:

```csharp
internal class C
{
    private int field;
}
```

## Configuration

The rule is disabled by default. To enable it in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1306.severity = warning
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, or `none` (disabled).
There are no naming options. See [configuration](../CONFIGURATION.md).

## When to suppress

Leave this rule disabled if your style uses PascalCase for accessible fields or
constants. Those names are required by other field naming rules.

The `_camelCase` style required by [SST1309](SST1309.md) is accepted here. If you
choose plain `camelCase` for private fields instead, disable that rule.
