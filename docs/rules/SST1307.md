# SST1307 — Accessible fields should be PascalCase

| Item | Value |
| --- | --- |
| Category | Naming |
| Severity | Warning |
| Code fix | Yes (rename) |

## Cause

A `public`, `internal`, `protected`, or `protected internal` mutable field does
not start with an upper-case letter. Both instance and static fields are checked.

Private fields, including `private protected` fields, are handled by
[SST1309](SST1309.md). Constants and readonly fields have separate naming rules.
Names made entirely of underscores are ignored. Only the first character is checked.

## How to fix violations

Rename the field to PascalCase: start with a capital letter, as in `Value`.

Reported:

```csharp
public class C
{
    internal int value;
}
```

Corrected:

```csharp
public class C
{
    internal int Value;
}
```

## Code fix

The rename fix removes a leading `m_`, `s_`, or `t_` prefix and leading
underscores, then capitalizes the first remaining letter. It updates the field
declaration and its references across the solution. The rest of the name keeps
its spelling.

## Configuration

The default severity is `warning`. Set it in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1307.severity = warning
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, or `none` (disabled).
There are no naming options. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress a field whose name must stay compatible with existing callers or code
that looks it up by name. The rename fix cannot update callers outside the solution.
