# SST1315 — Union member names should match the configured casing

| Item | Value |
| --- | --- |
| Category | Naming |
| Severity | Warning |
| Code fix | Yes (rename) |
| Default | PascalCase |

## Cause

A union type or case has the wrong first-letter casing. PascalCase, which starts
with a capital letter, is the default. You can choose camelCase instead.

This rule checks types that implement `System.Runtime.CompilerServices.IUnion`,
including types that inherit that interface through a base class. It reports
nothing when that interface is absent from the project and its references.
Names made entirely of underscores are ignored. Later letters are not checked.

## How to fix violations

Rename the type to match the configured casing. These examples include a minimal
`IUnion` interface to show the required type relationship.

Reported with the default setting:

```csharp
namespace System.Runtime.CompilerServices
{
    public interface IUnion { }
}

public abstract class Shape : System.Runtime.CompilerServices.IUnion { }
public sealed class circle : Shape { }
```

Corrected:

```csharp
namespace System.Runtime.CompilerServices
{
    public interface IUnion { }
}

public abstract class Shape : System.Runtime.CompilerServices.IUnion { }
public sealed class Circle : Shape { }
```

## Code fix

The rename fix removes a leading `m_`, `s_`, or `t_` prefix and leading
underscores, then changes the first remaining letter to the configured casing.
It updates the type declaration and references across the solution, keeping the
rest of the name's spelling.

## Configuration

The default severity is `warning`. Set the severity and casing in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1315.severity = warning
stylesharp.union_member_naming = pascal_case
# Optional rule-specific override:
stylesharp.SST1315.union_member_naming = pascal_case
```

Both casing keys accept `pascal_case` (the default) or `camel_case`, ignoring
case. A recognized rule-specific value takes priority. A missing or invalid
value falls back to the general key, then to `pascal_case`.

Severity accepts `error`, `warning`, `suggestion`, `silent`, or `none` (disabled).
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress a type whose name must stay compatible with existing callers or code
that looks it up by name.

[SST1300](SST1300.md) also checks type names and requires an upper-case start.
If you choose `camel_case` for union types, suppress that rule for those types
or disable it.
