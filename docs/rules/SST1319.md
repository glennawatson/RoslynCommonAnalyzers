# SST1319 — Enumeration names should be PascalCase

| Item | Value |
| --- | --- |
| Category | Naming |
| Severity | Warning |
| Code fix | Yes (rename) |
| Default | Enabled |

## Cause

An enum type name starts with an uppercase letter but contains an underscore or an
all-capital abbreviation longer than two letters. Use PascalCase: join words without
underscores and capitalize the first letter of each word, as in `LogLevel`.

Two-letter abbreviations such as `IO` may stay uppercase: `IOMode` and `MyIO` are
allowed. Single letters such as `A` and `MyA` are also allowed.

This rule checks the enum's type name, not its members. Names starting with a
lowercase letter are covered by [SST1300](SST1300.md).

## Example

Bad:

```csharp
public enum Log_Level { Debug, Info }
public enum HTTPStatus { Ok, NotFound }
```

Corrected:

```csharp
public enum LogLevel { Debug, Info }
public enum HttpStatus { Ok, NotFound }
```

## Code fix

The fix renames the enum and updates references across the solution. It removes
underscores and capitalizes the following word. It changes long capital abbreviations
to words: `HTTPStatus` becomes `HttpStatus`, and `MyENUM` becomes `MyEnum`.

## Configuration

There are no rule-specific options. The rule is enabled as a warning by default.

```editorconfig
[*.cs]
dotnet_diagnostic.SST1319.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.

## When to suppress

Suppress when the name is part of a published API or an external contract that
cannot change. Renaming a public enum requires updates in consumers outside the solution.
