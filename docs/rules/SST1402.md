# SST1402 — File should contain a single type

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Severity | Warning |
| Code fix | Yes (move type to its own file) |
| Default | Enabled |

## Cause

A file declares more than one top-level class, struct, interface, enum, or record.
The first type is allowed; each additional distinct type is reported. Declarations
with the same name and number of type parameters count once, including partial
declarations. Nested types and delegates are not counted.

Keeping each type in its own file makes it easier to find.

## Example

Bad — both types in `First.cs`:

```csharp
public class First { }
public class Second { }
```

Corrected — `First.cs`:

```csharp
public class First { }
```

`Second.cs`:

```csharp
public class Second { }
```

## Code fix

The fix removes the flagged type declaration from the original file and creates a
file named after it in the same project folder. The new file keeps the namespace,
using directives, and comments on the moved type. A header attached directly to a
different type is not copied into the new file; check the header when reviewing the edit.

The fix removes extra blank lines, including blank lines next to braces, and keeps
the original line endings and final-newline choice. Linked copies in other projects,
such as other target frameworks, receive the move too.

“Fix all” moves all flagged declarations in the selected scope. The individual
lightbulb fix is not offered for a file containing `#if`, `#elif`, `#else`, or `#endif`.
Move those types manually and keep the required conditions around them.

## Configuration

The rule is enabled as a warning by default.

```editorconfig
[*.cs]
dotnet_diagnostic.SST1402.severity = warning
stylesharp.file_naming_convention = braces
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.

The file naming option affects the code fix for generic types:

| Key | Values | Default |
| --- | --- | --- |
| `stylesharp.file_naming_convention` | `braces`: `Widget{T}.cs`; `metadata`: ``Widget`1.cs`` | `braces` |
| `stylesharp.SST1402.file_naming_convention` | Same values; overrides the general key for this fix | Uses the general key |

The number after the backtick is the number of type parameters. These settings do
not change which declarations are reported. See [CONFIGURATION](../CONFIGURATION.md).

## When to suppress

Suppress when a small group of related types is intentionally kept together, or when a file must remain intact to match externally maintained source.
