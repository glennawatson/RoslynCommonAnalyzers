# SST1403 — File should contain a single namespace

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A file contains more than one namespace declaration. Every declaration after the
first is reported, including nested namespace blocks and repeated declarations of
the same namespace. A single block namespace or file-scoped namespace is allowed.

## Example

Bad — both namespaces in one file:

```csharp
namespace Widgets { }
namespace Gadgets { }
```

Corrected — one file:

```csharp
namespace Widgets { }
```

A separate file:

```csharp
namespace Gadgets { }
```

## How to fix violations

Move each extra namespace into its own file, or merge repeated blocks of the same
namespace. Replace nested blocks such as `namespace A { namespace B { } }` with
`namespace A.B { }` when only the inner namespace contains code.

There is no automatic code fix.

## Configuration

There are no rule-specific options. The rule is enabled as a warning by default.

```editorconfig
[*.cs]
dotnet_diagnostic.SST1403.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.

## When to suppress

Suppress when a file must contain several namespaces, such as a source file distributed for consumers to include directly.
