# SST1410 — Remove delegate parenthesis when possible

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Default severity | Warning |
| Code fix | Yes |

## Cause

An anonymous method uses `delegate()` with an empty parameter list. The list can
be omitted when the method does not need named parameters. Anonymous methods with
parameters and lambda expressions such as `() => { }` are not reported.

## Example

Reported:

```csharp
public class C
{
    public System.Action CreateAction() => delegate() { };
}
```

Corrected:

```csharp
public class C
{
    public System.Action CreateAction() => delegate { };
}
```

## How to fix violations

The **Remove empty parentheses** code fix removes `()` and puts one space after
`delegate`. It drops comments inside the parentheses or between `delegate` and
`(`. Move those comments before applying the fix.

## Configuration

The default severity is `warning`. There are no rule-specific options. To report
violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1410.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Keep `()` if it is needed to select an overload. An anonymous method without a
parameter list can match delegates that take arguments, so removing the list can
make an overloaded call ambiguous. Suppress also when your team's style requires
the explicit empty list.
