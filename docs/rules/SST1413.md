# SST1413 — Use a trailing comma in multi-line initializers

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Default severity | Warning |
| Code fix | Yes |

## Cause

The last entry in an object, collection, array or anonymous-object initializer,
or an enum, has no trailing comma and its opening and closing braces are on
different lines. A trailing comma lets you add or reorder entries without editing
the preceding entry.

Empty lists and lists whose braces are on the same line are not reported.
Collection expressions using `[...]` are not checked.

## Example

Reported:

```csharp
public class C
{
    public int[] Values = new[]
    {
        1,
        2
    };
}
```

Corrected:

```csharp
public class C
{
    public int[] Values = new[]
    {
        1,
        2,
    };
}
```

## How to fix violations

The **Add trailing comma** code fix inserts a comma directly after the last
entry, before any following comment. It leaves the existing spacing and line
breaks in place. Fix All adds commas to every reported list.

## Configuration

The default severity is `warning`. There are no rule-specific options. To report
violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1413.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when your team's style omits trailing commas. This is a formatting choice
and does not change the values in the list.
