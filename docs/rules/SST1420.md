# SST1420 — Trivial properties should be auto-implemented

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Default severity | Warning |
| Code fix | Yes, except across member directives |

## Cause

A property's getter reads a private field, and each `set` or `init` accessor, if
present, assigns `value` to that same field. The field is not used by another
member. A property written as `Value => _value` also qualifies.

The field must be declared alone, without attributes, `const` or `volatile`.
The field and property must either both be static or both be instance members.
Properties without a getter and properties in a `partial` type are not reported.

## Example

Reported:

```csharp
public class C
{
    private int _value = 5;

    public int Value { get => _value; set => _value = value; }
}
```

Corrected:

```csharp
public class C
{
    public int Value { get; set; } = 5;
}
```

## How to fix violations

The **Convert to auto-property** code fix replaces accessor bodies with
semicolons, deletes the backing field and moves its initializer to the property.
It keeps accessor attributes and access modifiers. An expression-bodied property
becomes a property with `{ get; }`. The fix also collapses a leading blank line
left by the field removal.

Comments on the deleted field or inside removed accessor bodies are discarded.
Move useful comments before applying the fix. No fix is offered when directives
such as `#region` separate members of the containing type.

The check also accepts compound assignments such as `_value += value`. Keep that
logic: replacing it with `set;` would change the property's behavior. Moving an
initializer to the property's position can also change initialization order;
review initializers that call methods or depend on other static fields.

Get-only auto-properties and auto-property initializers require C# 6 or later.

## Configuration

The default severity is `warning`. There are no rule-specific options. To report
violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1420.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when reflection or serialization needs the explicit field name, when
the reported accessor does more than store the assigned value, or when preserving
initialization order requires the field. Keep the explicit field if your language
version cannot express the equivalent auto-property.
