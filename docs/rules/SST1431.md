# SST1431 — Static members of a generic type should use a type parameter

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A static member of a generic type is declared `public`, `internal`, or `protected`
but does not use a type parameter. Callers must supply a type argument to reach
the member even though it does not need that argument.

The rule checks methods, properties, single-field declarations, and single-event
declarations without custom `add` and `remove` accessors. Private members are
excluded. A type parameter counts as used anywhere in the declaration, including
attributes, initializers, accessors, and method bodies. Parameters from outer
generic types count too.

Using a type nested in the generic type also counts, even when the parameter name
is not written out. For example, `new Entry()` inside `Cache<T>` can create a
`Cache<T>.Entry`.

## How to fix violations

Move a member that does not depend on the type argument to a non-generic type and
update its callers. If the member should use the type parameter, change it to do
so as part of its real work. There is no automatic code fix.

## Example

Bad:

```csharp
public class Calculator<T>
{
    public static int Add(int a, int b) => a + b;
}
```

Corrected:

```csharp
public static class Calculator
{
    public static int Add(int a, int b) => a + b;
}
```

## Configuration

The rule is enabled as a warning by default. This example reports it as an error
and adds a framework type to the exemptions:

```ini
[*.cs]
dotnet_diagnostic.SST1431.severity = error
stylesharp.SST1431.additional_per_owner_types = Custom.Framework.PropertyKey
```

The general key is `stylesharp.additional_per_owner_types`. Both keys accept
fully qualified type names separated by commas, semicolons, spaces, or tabs.
Names are case-sensitive and omit generic type arguments. Both lists are added
to the built-in list; neither overrides the other. By default, no extra types
are added. See [configuration details](../CONFIGURATION.md#sst1431).

The exemption applies to static fields and properties whose declared type is a
listed type or derives from one. The built-in list includes MAUI
`BindableProperty`, WPF and WinUI `DependencyProperty`, and Avalonia
`AvaloniaProperty`, `StyledProperty<>`, `DirectProperty<,>`, and
`AttachedProperty<>`. These types hold framework property registrations that
belong to each constructed generic type.

## When to suppress

Suppress when each type argument intentionally needs separate static state, or
moving a published member would break callers. Moving a static field off a
generic type combines the separate values held for types such as `Cache<int>`
and `Cache<string>`; check that this is intended. For custom framework property
registrations, configure the registration type instead of suppressing each member.
