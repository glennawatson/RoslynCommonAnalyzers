# SST1433 — Redundant constructors should be removed

## Cause

A public, parameterless constructor has an empty block body and repeats the constructor C# supplies automatically.

The rule checks declarations with exactly one instance constructor. It skips constructors with attributes or a `base(...)` or `this(...)` initializer. It also skips structs and record structs with instance field or property initializers, because they require an explicit constructor.

## Example

Before:

```csharp
public sealed class Widget
{
    public Widget()
    {
    }
}
```

After:

```csharp
public sealed class Widget
{
}
```

## Code fix

**Remove the redundant constructor** deletes the whole constructor. Fix All is supported. Comments inside or attached to the constructor are deleted too; move any documentation you need before accepting the fix.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1433.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an explicit constructor must remain for a source-processing tool. For a partial type, check its other declarations before deleting the constructor: the rule counts constructors only in the declaration it reports.
