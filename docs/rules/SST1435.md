# SST1435 — Empty namespace declarations should be removed

## Cause

A namespace declaration contains no types or nested namespaces. This applies to both block namespaces and file-scoped namespaces. Comments and `using` directives do not make a namespace nonempty.

## Example

Before:

```csharp
namespace Empty
{
}

public class Widget
{
    public int Value { get; set; }
}
```

After:

```csharp
public class Widget
{
    public int Value { get; set; }
}
```

## Code fix

**Remove the empty namespace** deletes the whole declaration, including any `using` directives and comments inside it. Comments attached to the declaration are deleted too. Fix All is supported. Move any documentation you need before accepting the fix.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1435.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when a source-processing tool needs the empty declaration. Otherwise, delete it; an empty namespace does not reserve a name or create a runtime type.
