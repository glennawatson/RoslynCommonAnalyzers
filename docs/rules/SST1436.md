# SST1436 — Empty types should not be declared

## Cause

A class, struct, record class, or record struct declares no members, has no base type or interfaces, and has no primary-constructor parameter list. Even an empty parameter list excludes the declaration.

Comments and attributes do not prevent a report. Each part of a partial type is checked separately.

## Example

Before, with the rule enabled:

```csharp
public class Settings
{
}
```

After, with the intended data added:

```csharp
public class Settings
{
    public int Value { get; set; }
}
```

## How to fix violations

Add the intended members, or delete the type if nothing needs it. There is no automatic code fix.

## Configuration

Disabled by default. Enable it as a warning with:

```ini
[*.cs]
dotnet_diagnostic.SST1436.severity = warning
```

There are no rule-specific options. Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress for a deliberate marker type, an empty data object required by an API, or an empty partial declaration whose members are supplied elsewhere. Do not add meaningless members to satisfy the rule.
