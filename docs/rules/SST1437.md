# SST1437 — Empty interfaces should not be declared

## Cause

An interface declares no members and has no base interfaces. It gives implementing types no methods or properties to provide. Comments and attributes do not prevent a report. Each partial declaration is checked separately.

## Example

Before, with the rule enabled:

```csharp
public interface IWork
{
}
```

After, with the intended method added:

```csharp
public interface IWork
{
    void Run();
}
```

## How to fix violations

Add the intended members or inherit the interfaces that define the required behavior. Delete an unused interface. There is no automatic code fix.

## Configuration

Disabled by default. Enable it as a warning with:

```ini
[*.cs]
dotnet_diagnostic.SST1437.severity = warning
```

There are no rule-specific options. Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress for a marker interface used to identify a group of types, such as in a generic constraint or a type check. Also suppress for an empty partial declaration whose members are supplied elsewhere. Replacing a marker interface with an attribute can break callers that depend on that interface.
