# SST1440 — Remove private members with no local use

## Cause

A member marked `private` is not used elsewhere in its type. The rule checks
fields, properties, methods, and events without custom `add` and `remove` bodies.
A method that only calls itself has no outside caller.

Calls to private extension methods count as use. Both `value.Method()` and
`Method(value)` keep the method.

Uses in other parts of a partial type count, including generated code.
The rule skips members with attributes, constants, partial and extern methods,
and the program's entry point. A field or property that is set but never read
is covered by [SST1441](SST1441.md).

`nameof(Cases)` also counts as use. If several methods share that name,
all are kept. This includes methods named by test attributes.

## Example

Before:

```csharp
public class Worker
{
    private void Unused()
    {
    }

    public int Run() => 1;
}
```

After:

```csharp
public class Worker
{
    public int Run() => 1;
}
```

## Code fix

**Remove unused private member** deletes the member. In a combined field or event declaration, it removes only the reported variable. Fix All is supported.

The fix deletes the member's starting value and attached comments. In a combined
declaration, it can also remove comments and spacing around other variables.
Review the preview. If setting a starting value, reading a property, or setting
a property does useful work, move that work before deleting the member.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1440.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when a framework finds the member by name while the program runs,
and no attribute marks that use. This can happen with reflection or when
saving and loading objects. State which framework needs the member.
