# SST1440 — Remove private members with no local use

## Cause

A member declared with `private` is never used elsewhere in its declaring type. The rule checks fields, properties, methods, and events declared without custom `add` and `remove` bodies. A method that only calls itself still has no outside caller.

References in other partial declarations, including generated declarations, count as use. Members with attributes, constants, partial and extern methods, and the program's entry point are excluded. A field or property assigned elsewhere but never read is covered by [SST1441](SST1441.md).

## Example

Before:

```csharp
public class Worker
{
    private void Unused()
    {
    }

    public int Run() => 1;
}
```

After:

```csharp
public class Worker
{
    public int Run() => 1;
}
```

## Code fix

**Remove unused private member** deletes the member. In a combined field or event declaration, it removes only the reported variable. Fix All is supported.

The fix deletes the member's initializer and attached comments. In a combined declaration it can also discard comments and spacing around the remaining variables. Review the preview. If an initializer calls a method that performs needed work, preserve that call separately before deleting the field.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1440.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when a framework finds the member by name at runtime, such as through reflection or serialization, and no attribute marks that use. Document which framework requires it.
