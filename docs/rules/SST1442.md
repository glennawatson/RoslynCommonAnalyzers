# SST1442 — Functions should keep branching complexity low

## Cause

A function's branching score exceeds the configured maximum, which defaults to 10. The rule checks methods, constructors, finalizers, operators, local functions, accessors, and expression-bodied properties.

The score starts at 1. Each `if`, loop, `?:`, `??`, `??=`, conditional access (`?.` or `?[]`), `&&`, `||`, and pattern `and` or `or` adds 1. A whole `switch` statement or expression adds 1, regardless of its number of cases or arms. Decisions inside those cases still count.

Nested local functions are checked separately. Lambda and anonymous-method bodies do not contribute to the enclosing function's score.

## Example

With `stylesharp.SST1442.max_cyclomatic_complexity = 3`, these three decisions produce a score of 4:

```csharp
public class Classifier
{
    public int Match(int value)
    {
        var result = 0;
        if (value == 0) result++;
        if (value == 1) result++;
        if (value == 2) result++;
        return result;
    }
}
```

After, with the same result and a score of 2:

```csharp
public class Classifier
{
    public int Match(int value) => value switch
    {
        0 => 1,
        1 => 1,
        2 => 1,
        _ => 0
    };
}
```

## How to fix violations

Split separate tasks into named helper methods, or use a switch when the code maps inputs to results. Flattening nested `if` statements alone does not reduce this score. There is no automatic code fix.

## Configuration

Enabled by default as a warning.

```ini
[*.cs]
dotnet_diagnostic.SST1442.severity = warning
stylesharp.max_cyclomatic_complexity = 10
stylesharp.SST1442.max_cyclomatic_complexity = 10
```

Both limit keys accept positive integers. A valid rule-specific value wins; otherwise the general value is used, then the default of 10. Zero, negative, and invalid values are ignored. A score equal to the limit is allowed.

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress for a cohesive decision table or algorithm when splitting it would make the code harder to follow. Raise the limit for selected files if that structure is common there.
