# SST1443 — Functions should keep nested flow easy to follow

## Cause

A function's nested-flow score exceeds its configured limit. The default is 15 for methods, constructors, finalizers, operators, and local functions, and 3 for accessors and expression-bodied properties.

An `if`, loop, `switch` statement, `catch`, `?:`, or `goto` adds 1 plus its nesting depth. An `else` adds 1; an `else if` does not add another nesting level. Logical `&&` and `||` chains and pattern `and` and `or` chains also add points. A call written with the current method's name and argument count adds a point for possible recursion.

Switch expressions and individual switch cases add no points themselves, though logic inside them can. Nested local functions are checked separately. Lambda and anonymous-method bodies do not contribute to the enclosing function's score.

## Example

With `stylesharp.SST1443.max_cognitive_complexity = 3`, three nested conditions score 6:

```csharp
public class Classifier
{
    public int Match(int value)
    {
        if (value > 0)
        {
            if (value > 1)
            {
                if (value > 2)
                {
                    return value;
                }
            }
        }

        return 0;
    }
}
```

After, with the same result and a score of 1:

```csharp
public class Classifier
{
    public int Match(int value)
    {
        if (value <= 2)
        {
            return 0;
        }

        return value;
    }
}
```

## How to fix violations

Return early for exceptional cases, combine redundant conditions, or move a distinct task into a named helper. There is no automatic code fix.

## Configuration

Enabled by default as a warning.

```ini
[*.cs]
dotnet_diagnostic.SST1443.severity = warning
stylesharp.max_cognitive_complexity = 15
stylesharp.SST1443.max_cognitive_complexity = 15
stylesharp.max_property_cognitive_complexity = 3
stylesharp.SST1443.max_property_cognitive_complexity = 3
```

Limits accept positive integers. For each pair, a valid rule-specific value wins; otherwise the general value is used, then the default of 15 or 3. Zero, negative, and invalid values are ignored. A score equal to the limit is allowed.

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the nesting reflects a clear algorithm and extracting pieces would hide how it works. Consider a higher limit for selected files when that structure is common there.
