# SST1445 — Remove unnecessary using directives

## Cause

A `using` directive imports a namespace, static type, or alias that the file does not use. Directives inside namespaces are checked too.

Uses through extension methods and C# 14 extension members, query expressions, `foreach`, deconstruction, collection initializers, and `await` count. So do attributes, `nameof`, and XML documentation references such as `<see cref="StringBuilder"/>`.

The rule leaves `global using` directives alone. It reports nothing in files with source text inside an inactive `#if` branch, because that text may need the imports in another build.

## Example

Before:

```csharp
using System;
using System.Text;

public class Worker
{
    public void Run() => Console.WriteLine("x");
}
```

After:

```csharp
using System;

public class Worker
{
    public void Run() => Console.WriteLine("x");
}
```

## Code fix

**Remove unnecessary using directive** deletes the directive and its line. Fix All is supported. The fix preserves leading comments, including file headers, and keeps preprocessor directives needed to match directives elsewhere in the file. A trailing comment on the removed line is deleted.

## Configuration

Enabled by default as a warning. There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1445.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. See [docs/CONFIGURATION.md](../CONFIGURATION.md).

## When to suppress

Suppress when a source-processing tool needs an import that ordinary C# code does not reference. Otherwise, remove the unused directive.
