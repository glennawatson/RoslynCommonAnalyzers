# SST1446 — Inheritance chains should stay shallow

**Category:** Maintainability
**Severity:** Warning
**Code fix:** None

## Cause

A class has more base classes than the configured maximum, which defaults to
**5**. A long chain makes it harder to find the code that controls its behavior.

Only base classes in the same assembly count by default. Base classes from
referenced libraries count when `count_external_types` is `true`. `object`
never counts. Interfaces, structs, and static classes are not reported.

## Example

This class has six base classes, so it exceeds the default limit:

```csharp
public class C0 { }
public class C1 : C0 { }
public class C2 : C1 { }
public class C3 : C2 { }
public class C4 : C3 { }
public class C5 : C4 { }
public class C6 : C5 { } // Reported: six base classes.
```

Remove an unnecessary layer when its behavior can be combined with another:

```csharp
public class C0 { }
public class C1 : C0 { }
public class C2 : C1 { }
public class C3 : C2 { }
public class C4 : C3 { }
public class C6 : C4 { } // Five base classes.
```

Review inherited members before changing a real hierarchy. Another option is
to store a helper object in a field instead of inheriting its behavior.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1446.severity = warning
stylesharp.SST1446.max_inheritance_depth = 5
stylesharp.SST1446.count_external_types = false
```

`max_inheritance_depth` accepts a positive integer. `count_external_types`
accepts `true` or `false`. The values above are the defaults. The general keys
`stylesharp.max_inheritance_depth` and `stylesharp.count_external_types` also
work; a valid rule-specific value takes precedence over the general value.
Invalid values fall back to the general setting, then the default.

Severity accepts `none`, `silent`, `suggestion`, `warning`, or `error`.
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress for a hierarchy required by a framework or a public API that cannot
change without breaking callers. Raise the limit when deeper inheritance is
an agreed project convention.
