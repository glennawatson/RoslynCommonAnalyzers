# SST1448 — Let the compiler supply caller-info arguments

**Category:** Maintainability
**Severity:** Warning
**Code fix:** Removes the explicit argument in supported cases

## Cause

A method or constructor call supplies an optional caller-info argument:

- For `[CallerMemberName]`, a constant string or `nameof` supplies the same
  member name that the compiler would insert.
- For `[CallerFilePath]` or `[CallerLineNumber]`, the call supplies an explicit
  value. It need not match the actual file or line.

These attributes let the compiler provide the calling member, file, or line
when the argument is omitted. Passing a caller-info parameter directly to
another call is allowed, so wrappers can preserve the original caller.
Different member names and `[CallerArgumentExpression]` are not reported.

## Example

The caller name repeats the method name:

```csharp
using System.Runtime.CompilerServices;

public class C
{
    public void Log(string message, [CallerMemberName] string caller = "") { }

    public void M() => Log("text", "M");
}
```

Omit it and the compiler supplies `"M"`:

```csharp
using System.Runtime.CompilerServices;

public class C
{
    public void Log(string message, [CallerMemberName] string caller = "") { }

    public void M() => Log("text");
}
```

## Code fix

**Let the compiler supply the caller info** deletes the reported argument
and its separating comma. It is offered when the argument is named or is the
last argument in the list. Other positional arguments must be removed or
rearranged by hand.

Comments attached to the removed argument are deleted too. The fix leaves
other arguments as written. Check calls with overloads or positional
arguments after a named argument: the fix does not check whether the shorter
call selects the same method or passes values to the same parameters.
Removing an explicit file path or line number changes it to the compiler's
value for the call site.

## Configuration

There are no rule-specific options. The default severity is `warning`:

```ini
[*.cs]
dotnet_diagnostic.SST1448.severity = warning
```

Severity accepts `none`, `silent`, `suggestion`, `warning`, or `error`.
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when tests or logging adapters need a fixed file path or line number,
or when omitting an argument would select a different overload. Direct
forwarding of a caller-info parameter needs no suppression.
