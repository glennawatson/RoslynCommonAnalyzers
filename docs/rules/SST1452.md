# SST1452 — Remove unused type parameters

**Category:** Maintainability
**Severity:** Warning
**Code fix:** None

## Cause

A generic type, method, or local function declares a type parameter that is
not used elsewhere in that declaration. Callers must supply a type argument
that does not affect the code.

Using the parameter in a signature, body, base type, or another parameter's
constraint counts as use. Writing only `where T : class` does not use `T`.
Comments and documentation do not count as use.

Declarations marked `partial`, `override`, `virtual`, or `abstract`, and
explicit interface implementations, are skipped. Implicit interface
implementations are checked, so review the interface before removing a
parameter from an implementing method.

## Example

`T` is not used:

```csharp
public class C
{
    public void M<T>(int value) { }
}
```

Remove it and update calls such as `M<string>(1)` to `M(1)`:

```csharp
public class C
{
    public void M(int value) { }
}
```

Remove any constraints for the deleted parameter too. Changing the number
of type parameters breaks existing callers of a public API.

## Configuration

There are no rule-specific options. The default severity is `warning`:

```ini
[*.cs]
dotnet_diagnostic.SST1452.severity = warning
```

Severity accepts `none`, `silent`, `suggestion`, `warning`, or `error`.
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an interface or public API requires the parameter, or when
a type argument deliberately distinguishes otherwise identical types for
callers. Keep the reason close to the declaration.
