# SST1459 - Remove non-grouping parentheses

**Category:** Maintainability
**Severity:** Warning
**Code fix:** None

## Cause

Parentheses wrap a simple value where they do not affect the result.
This includes a return or throw value, an expression after `=>`, an argument,
an initializer, or the right side of an assignment.

The wrapped value can be a name, a field or property access, an array or indexer
access, a method call, an object creation, or a literal. Parentheses around
calculations such as `(left + right)` are not reported, even when they could be
removed. Parentheses used by `if` or `while` are not reported.

## Example

Before:

```csharp
public sealed class C
{
    public int M(int value) => (value);
}
```

After:

```csharp
public sealed class C
{
    public int M(int value) => value;
}
```

There is no automatic code fix. Remove the reported pair of parentheses.

## Configuration

Enabled by default as a warning. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1459.severity = error
```

Severity accepts `error`, `warning` (the default), `suggestion`, `silent`,
`none`, or `default` to restore the default severity.

There are no rule-specific options.

See [docs/CONFIGURATION.md](../CONFIGURATION.md) for configuration and
suppression syntax.

## When to suppress

Suppress when extra parentheses make a group of similar expressions easier to
compare or are required by your team's formatting convention.
