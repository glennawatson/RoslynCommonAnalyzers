# SST1465 - Collapse an else block that only wraps an if

**Category:** Maintainability
**Severity:** Warning
**Code fix:** Collapse to else if (supports Fix All)

## Cause

An `else` block contains exactly one statement, and that statement is an `if`.
Write `else if` to remove a level of nesting while keeping the same order of
conditions. The inner `if` may have its own `else` branches.

An existing `else if`, a block with more than one statement, or a block holding
another kind of statement is not reported.

## Example

Before:

```csharp
public sealed class C
{
    public void M(bool first, bool second)
    {
        if (first)
        {
            System.Console.WriteLine("First");
        }
        else
        {
            if (second)
            {
                System.Console.WriteLine("Second");
            }
        }
    }
}
```

After:

```csharp
public sealed class C
{
    public void M(bool first, bool second)
    {
        if (first)
        {
            System.Console.WriteLine("First");
        }
        else if (second)
        {
            System.Console.WriteLine("Second");
        }
    }
}
```

## Code fix

The fix removes the outer `else` block's braces and puts the inner `if` after
`else`. It keeps the inner branches, moves comments around the removed braces
onto the `if`, and adjusts indentation and line breaks. It supports Fix All.

The diagnostic is still reported when directives such as `#if` or `#region`
surround the braces or the inner `if`, but no fix is offered in those cases.

## Configuration

Enabled by default as a warning. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST1465.severity = error
```

Severity accepts `error`, `warning` (the default), `suggestion`, `silent`,
`none`, or `default` to restore the default severity.

There are no rule-specific options.

See [docs/CONFIGURATION.md](../CONFIGURATION.md) for configuration and
suppression syntax.

## When to suppress

Suppress when the extra block groups a separate decision for readers, or when
conditional compilation needs the braces to remain.
