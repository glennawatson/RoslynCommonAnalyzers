# SST1476 — Conditional branches should not have identical bodies

**Category:** Maintainability  
**Default severity:** Warning  
**Enabled by default:** Yes  
**Code fix:** No

## Cause

Every branch of a conditional has the same code. The condition selects a branch but does
not select different work. Check whether one branch was meant to differ.

The rule checks:

- `if`/`else` chains with a final `else`.
- Conditional expressions using `? :`.
- Switch statements with at least two sections and a `default` label.
- Switch expressions with at least two arms that cover all possible inputs. A switch over `bool` can cover every input with `true` and `false`, without a discard arm.

Whitespace and comments do not make bodies different. Braces around a single `if` branch
statement do not make it different from the same statement without braces.

## Example

Before:

```csharp
public class Selector
{
    public int Pick(bool flag) => flag ? 4 : 4;
}
```

After, if the false case should return a different value:

```csharp
public class Selector
{
    public int Pick(bool flag) => flag ? 4 : 5;
}
```

## How to fix violations

There is no code fix. Correct the branch that should differ. If all branches are meant to
do the same work, keep one copy and remove the conditional only after checking what its
condition or switch input does. Removing it can also remove a call, assignment, or exception.

An `if` chain without a final `else`, or a switch statement without `default`, is outside
this rule. Duplicate pairs of branches can still be reported by [SST2414](SST2414.md).
Empty bodies are below the default size limit; see [SST1439](SST1439.md) for empty blocks.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1476.severity = error
stylesharp.SST1476.minimum_statements = 1
```

`stylesharp.SST1476.minimum_statements` accepts a positive integer and defaults to `1`.
It sets the smallest branch body to check. An expression arm counts as one statement, so
setting the minimum to `2` excludes conditional expressions, switch expressions, and
single-statement `if` bodies from this rule. In a switch statement, `break` also counts
as a statement.

The project-wide key is `stylesharp.minimum_statements`. A valid rule-specific value wins;
otherwise the rule uses a valid project-wide value, then the default. The setting does
not change the duplicate-pair checks in [SST2414](SST2414.md).

Severity defaults to `warning` and accepts `none`, `silent`, `suggestion`, `warning`, or
`error`. See [configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress locally when separate branches deliberately mirror a specification or test case
and make it easier to review. Also check whether the condition performs required work
before removing it. Raise the minimum when short matching branches are common and intentional.
