# SST1480 — A constructed exception should be thrown

**Category:** Maintainability  
**Default severity:** Warning  
**Enabled by default:** Yes  
**Code fix:** Yes (supports Fix All)

## Cause

An exception is created as a statement and its value is discarded. This applies to
`System.Exception` and types derived from it, including your own exception classes.
Creating the exception does not throw it, so execution can continue past an intended guard.

## Example

Before:

```csharp
using System;

public class Validator
{
    public void Validate(string value)
    {
        if (value is null)
        {
            new ArgumentNullException(nameof(value));
        }
    }
}
```

After:

```csharp
using System;

public class Validator
{
    public void Validate(string value)
    {
        if (value is null)
        {
            throw new ArgumentNullException(nameof(value));
        }
    }
}
```

## What is not reported

An exception that is thrown, returned, assigned, passed as an argument, or stored in a
collection is not reported. Neither is an exception returned by a lambda, such as an
exception factory. An explicit discard assignment, `_ = new Exception();`, is also allowed.
Creating an object that is not an exception is outside this rule.

## Code fix

The fix inserts `throw` before the existing exception creation. It keeps the exception
type, arguments, indentation, and statement comments. The statement then throws instead
of continuing normally. If the exception is unused code rather than a guard, remove the
statement manually.

## Configuration

There are no rule-specific options. Severity defaults to `warning` and accepts `none`,
`silent`, `suggestion`, `warning`, or `error`. For example:

```ini
[*.cs]
dotnet_diagnostic.SST1480.severity = error
```

See [configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress locally when a constructor test deliberately creates an exception without
throwing it. An explicit discard assignment can also make that intent clear.
Do not suppress a guard that is missing `throw`.
