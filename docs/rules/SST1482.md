# SST1482 — GetHashCode should not read mutable state

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A parameterless `GetHashCode()` override reads a field that is neither `readonly` nor
`const`, or a property with a `set` accessor. A `private set` accessor also counts.
If that value changes while the object is in a `Dictionary` or `HashSet`, lookups
and removal can fail.

## Example

Bad:

```csharp
public class Order
{
    public int Id { get; set; }

    public override int GetHashCode() => Id;
}
```

Corrected:

```csharp
public class Order
{
    public Order(int id) => Id = id;

    public int Id { get; }

    public override int GetHashCode() => Id;
}
```

## What is reported

Reads with no qualifier, with `this.`, or with `base.` are checked. An unqualified
mutable static field also counts. Passing mutable state to `HashCode.Combine`
does not make it safe.

## What is not reported

Locals, parameters, `nameof` operands, `readonly` and `const` fields, and properties
with only `get` or `init` accessors are excluded. Members accessed through another
object are excluded, though the field holding that object can still be reported.

The rule does not follow reads through methods or computed properties. A get-only
property that returns changing data can still produce an unstable hash. A
`readonly` reference also does not prevent the referenced object's contents from changing.

## How to fix violations

Use state that remains fixed, such as a constructor-assigned `readonly` field or
get-only property. An `init` accessor is another option in C# 9 or later. Keep the
hash consistent with `Equals`: equal objects must return the same hash.

There is no code fix.

## Configuration

There are no rule-specific options. The default severity is `warning`.

```ini
[*.cs]
dotnet_diagnostic.SST1482.severity = warning
```

See [configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress when the type must remain mutable and its usage guarantees that the
hash inputs cannot change while the object is a key or set member. Document that
restriction for callers.
