# SST1486 — Repeated string literals should be named constants

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

The same string value appears at least three times in one file, and each counted
literal is at least five characters long. These limits are configurable. The
diagnostic marks the first counted copy and gives the total count.

A shared name lets you update the value in one place and avoids spelling mistakes
between copies. Equal values count together even when they use different literal
forms, such as ordinary and verbatim strings. Matching is case-sensitive.

## Example

Bad:

```csharp
public class Labels
{
    public string First => "repeated-value";
    public string Second => "repeated-value";
    public string Third => "repeated-value";
}
```

Corrected:

```csharp
public class Labels
{
    private const string SharedLabel = "repeated-value";

    public string First => SharedLabel;
    public string Second => SharedLabel;
    public string Third => SharedLabel;
}
```

## What is not reported

- Strings shorter than the configured minimum, empty strings, and whitespace-only strings.
- Attribute arguments and `nameof` operands.
- Values in `const` field or local initializers, or `static readonly` field initializers.
- `case` labels and switch expression patterns. Values returned by switch arms still count.
- Text portions of interpolated strings. String literals inside interpolation expressions still count.
- Generated code and preprocessor directives.

Counts do not cross file boundaries. Ordinary field and property initializers and
default parameter values count. A literal inside a lambda still counts when the
lambda is assigned to a `static readonly` field.

## How to fix violations

Introduce a named constant and replace the repeated literals with that name.
Choose a name and scope that describe what the value means. Use resources for
user-facing text that needs translation.

There is no code fix.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST1486.severity = warning
stylesharp.SST1486.duplicate_string_threshold = 3
stylesharp.SST1486.minimum_string_length = 5
```

| Key | Values | Default |
| --- | --- | --- |
| `stylesharp.SST1486.duplicate_string_threshold` | Integer at least `2` | `3` |
| `stylesharp.SST1486.minimum_string_length` | Integer at least `1` | `5` |

Project-wide fallbacks are `stylesharp.duplicate_string_threshold` and
`stylesharp.minimum_string_length`. Each valid rule-specific value takes precedence;
an invalid value falls back to the general key, then to the default. The default
severity is `warning`.

See [configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress when equal text has unrelated meanings and should change independently,
or when keeping test inputs and expected output explicit makes the test easier to read.
Raise the threshold if the default produces too many low-value suggestions.
