# SST1493 — Methods should not return a constant

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A parameterless, non-generic method returns only a constant value. Its body is
either an expression or a block containing one `return` statement. A get-only
property expresses a fixed value without making callers write a method call.

The rule accepts literals, signed numeric literals, named constants, and enum
members. Both instance and static methods are checked.

## Example

Bad:

```csharp
public sealed class Limits
{
    public int Limit() => 5;

    public int Twice() => Limit() * 2;
}
```

Corrected:

```csharp
public sealed class Limits
{
    public int Limit => 5;

    public int Twice() => Limit * 2;
}
```

## What is not reported

- Methods with parameters or type parameters, and local functions.
- `override`, `virtual`, `abstract`, `partial`, or `extern` methods.
- Interface declarations and implicit or explicit interface implementations.
- Methods with any attribute.
- A direct return of `null`, `default`, or `default(T)`.
- Reads of non-constant fields or properties, including `static readonly` values.
- Other expression forms, including arithmetic such as `1 + 2`.

## Code fix

The fix converts the method to an expression-bodied, get-only property, keeping
its name, type, access modifiers, and `static` modifier. It removes the empty
argument list from supported calls across the solution and formats the property.

The diagnostic can appear without a fix. No fix is offered if another member in
the same type has the same name, or if any reference cannot become a property
read. Examples include assigning the method to a delegate, calling it as a
standalone statement, or referring to it in `nameof`.

Leading documentation and comments on the declaration are retained. Comments
inside a replaced block body or inside removed call parentheses can be lost.
Review them before accepting.

The fix cannot update callers outside the solution or method names stored as
text for reflection. Changing a public method to a property breaks those callers.
A property is also not a compile-time constant: use a `const` field instead if
the value must be used in an attribute argument or a `case` label.

## Configuration

There are no rule-specific options. The default severity is `warning`.

```ini
[*.cs]
dotnet_diagnostic.SST1493.severity = warning
```

See [configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress when compatibility requires a method, a framework finds it by reflection,
or callers need a method reference for a delegate. Interface implementations,
overrides, and attributed methods are already excluded.
