# SST1494 — Do not pass an argument that repeats the parameter's default

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Severity | Warning |
| Code fix | Yes — removes trailing arguments |
| Default | Enabled |

## Cause

A trailing argument has the same constant value as its optional parameter's default.
This applies to method calls, `new Type(...)`, and `base(...)` or `this(...)` constructor calls.
Named arguments count too, but only a trailing group of matching arguments is reported.

## Example

Before:

```csharp
public sealed class Settings
{
    public void Configure(string name, int size = 8, bool cache = true)
    {
    }

    public void Use() => Configure("orders", 8, true);
}
```

After:

```csharp
public sealed class Settings
{
    public void Configure(string name, int size = 8, bool cache = true)
    {
    }

    public void Use() => Configure("orders");
}
```

The constant value matters, not its spelling: `0`, `0x0`, and a constant equal to zero
all repeat a default of zero. Enum values and `null` defaults also count.

## What is not reported

- An argument before a non-default argument. In the example, `Configure("orders", 8, false)` is left alone.
- An argument needed to select a particular overload.
- Caller-information parameters, such as those marked `[CallerMemberName]`, or `params` arguments.
- Calls in expression trees (`Expression<TDelegate>`).
- Calls through `?.`, and `new(...)` calls that omit the type name.

## How to fix violations

The code fix removes the selected argument and every argument after it. It is offered
only when the shorter call still selects the same method or constructor. Comments attached
to removed arguments can be lost; check the preview before accepting the edit.

Omitting an argument uses the default available when the caller is compiled. If a library
changes that default, rebuilding the caller can change the value it passes.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository
sets it to `error`:

```ini
[*.cs]
dotnet_diagnostic.SST1494.severity = error
```

Use `warning`, `suggestion`, or `silent` for a lower severity, or `none` to disable the rule.

## When to suppress

Suppress a call when the explicit value is part of its contract and must stay fixed even
if the parameter's default changes.
