# SST1497 — Unused locals should be removed

| Item | Value |
| --- | --- |
| Category | Maintainability |
| Severity | Warning |
| Code fix | Yes, when the remaining expressions can be kept |
| Default | Enabled |

## Cause

A local variable or an `out var` variable is declared but never read. Assigning a new
value with `name = value;` does not count as a read, even if it happens several times.
Check whether the missing read is a bug before removing the variable.

Uses inside lambdas and local functions count as reads, as do `nameof`, compound
assignments such as `+=`, increments, and `ref` or `out` arguments using an existing variable.

The rule skips variables named `_`, `using` declarations, ref locals, loop-header
variables, pattern variables, deconstruction variables, and `fixed` declarations.

## Example

Before:

```csharp
public sealed class Worker
{
    public int Compute() => 1;

    public void Run()
    {
        var result = Compute();
    }
}
```

After:

```csharp
public sealed class Worker
{
    public int Compute() => 1;

    public void Run()
    {
        Compute();
    }
}
```

## How to fix violations

The code fix removes the declaration and later assignments to the unused variable.
It handles each assigned expression as follows:

| Expression | Result |
| --- | --- |
| A literal, name, member access, or arithmetic over those | Removed with the variable |
| A lambda or anonymous method | Removed without running its body |
| A method call, object creation, `await`, assignment, or increment | Kept as a statement |
| An expression such as `values[index]` that cannot stand alone | Kept with `_ =` to discard its result |
| An `out var value` declaration | Changed to `out _` |

Review member reads, casts, and operators before accepting the fix. It can remove a
property getter or operator call that has effects, or an expression that can throw.
Comments attached to deleted declarations or assignments can also be lost.

No fix is offered when a retained expression cannot be placed safely: for example,
an initializer in a declaration with several variables, a `stackalloc` expression,
or an expression needing a discard in a project below C# 7. Make those changes manually
and preserve the order of operations.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository
sets it to `error`:

```ini
[*.cs]
dotnet_diagnostic.SST1497.severity = error
```

Use `warning`, `suggestion`, or `silent` for a lower severity, or `none` to disable the rule.

## When to suppress

Suppress a local deliberately kept for debugger inspection. If only the computation
matters, keep the call or use a discard instead of suppressing an unused name.
