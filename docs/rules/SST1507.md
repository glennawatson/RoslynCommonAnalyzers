# SST1507 — Code should not contain multiple blank lines in a row

| Item | Value |
| --- | --- |
| Category | Layout |
| Default severity | Warning |
| Code fix | Yes |

## Cause

Two or more blank lines appear in a row. Lines containing only spaces or tabs
count as blank. Blank lines inside a multi-line string are ignored because
they are part of the string's value.

## Example

Reported:

```csharp
class C
{
    public int A = 1;


    public int B = 2;
}
```

Corrected:

```csharp
class C
{
    public int A = 1;

    public int B = 2;
}
```

## How to fix violations

The code fix keeps the first blank line in each reported run and deletes the
rest. It leaves the surrounding code and comments in place.

## Configuration

This rule is enabled by default with severity `warning`. It has no rule-specific
options. Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1507.severity = warning
```

Accepted values are `error`, `warning`, `suggestion`, `silent` and `none`.
Use `none` to disable the rule. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress this rule when extra blank lines are part of an agreed layout, such
as separating major sections in a long data declaration. Blank lines inside
multi-line strings do not need suppression.
