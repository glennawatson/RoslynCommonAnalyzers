# SST1517 — Code should not contain blank lines at the start of the file

| Item | Value |
| --- | --- |
| Category | Layout |
| Default severity | Warning |
| Code fix | Yes |

## Cause

The file begins with one or more blank lines, including lines containing
only spaces or tabs. Start the file with code, a directive or a header
comment. A blank line after a header comment is not a leading blank line.

## Example

Reported (the first line of this file is empty):

```csharp

class C
{
}
```

Corrected:

```csharp
class C
{
}
```

## How to fix violations

The code fix removes all blank lines at the start of the file. It keeps the
first content line, including any header comment, and its indentation.

## Configuration

This rule is enabled by default with severity `warning`. It has no rule-specific
options. Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1517.severity = warning
```

Accepted values are `error`, `warning`, `suggestion`, `silent` and `none`.
Use `none` to disable the rule. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress this rule when an external file format or tool requires leading
blank lines. Otherwise, remove them.
