# SST1518 — File should end with a single newline

| Item | Value |
| --- | --- |
| Category | Layout |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A file is missing its final newline, or has extra whitespace after its last content.
Exactly one LF (`\n`) or CRLF (`\r\n`) newline is accepted. Empty files and files
containing only whitespace are not reported.

## Example

Reported: an extra blank line follows the closing brace.

```csharp
internal class C
{
}

```

Corrected: the file ends immediately after the closing brace's newline.

```csharp
internal class C
{
}
```

## How to fix violations

The code fix adds a missing newline or replaces all trailing whitespace with one
newline. It uses the first line's LF or CRLF ending, and uses LF if the file has
no line break. It keeps comments and code intact.

## Configuration

There are no rule-specific options. The default severity is `warning`.

```ini
[*.cs]
dotnet_diagnostic.SST1518.severity = warning
```

Use `error` to fail the build or `none` to disable the rule.

## When to suppress

Suppress for a file whose exact ending must match an external format or fixture.
For ordinary source files, use the fix.
