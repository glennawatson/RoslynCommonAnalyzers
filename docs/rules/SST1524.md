# SST1524 — Switch sections should not be too long

| Item | Value |
| --- | --- |
| Category | Layout |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A `switch` section exceeds the configured maximum, which defaults to 20 code lines.
A section is one or more `case` or `default` labels followed by their shared statements.
The count includes every label, statement, and brace in that section. The
diagnostic appears on its first label.

Blank lines, comments, documentation, and directive-only lines do not count.
Lines inside a multi-line string do count. Switch expression arms are excluded.

## Example

With `stylesharp.max_switch_section_lines = 3`, `case 1` has four code lines and is reported:

```csharp
public class C
{
    public int Handle(int state)
    {
        switch (state)
        {
            case 1:
                var total = 1;
                total += 2;
                return total;
            default:
                return 0;
        }
    }
}
```

Corrected: `case 1` has two code lines.

```csharp
public class C
{
    public int Handle(int state)
    {
        switch (state)
        {
            case 1:
                return 1 + 2;
            default:
                return 0;
        }
    }
}
```

## How to fix violations

There is no code fix. Simplify the section or move its work into a named method
so the switch remains easy to scan.

## Configuration

These are the defaults:

```ini
[*.cs]
dotnet_diagnostic.SST1524.severity = warning
stylesharp.max_switch_section_lines = 20
```

You can also set `stylesharp.SST1524.max_switch_section_lines`. Both keys accept a
positive integer. A valid rule-specific value takes priority, followed by a valid
project-wide value, then `20`. Zero, negative values, and invalid text are ignored.
Use severity `error` to fail the build or `none` to disable the rule.

See [configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress or raise the limit when a section is clearer as one sequence, such as
a set of related assignments, and extracting it would obscure that sequence.
