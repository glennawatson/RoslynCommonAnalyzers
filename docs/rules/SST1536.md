# SST1536 — A conditional operator token should not be followed by a blank line

| Item | Value |
| --- | --- |
| Category | Layout |
| Severity | Warning |
| Code fix | Yes (remove the blank line) |

## Cause

A blank line follows the `?` or the `:` of a conditional operator.

## Rule description

A conditional operator is one expression. A blank line after its `?` or `:` separates the condition from
the branch it selects, so the reader has to carry the condition across empty space to reach the value it
produces.

Wrapping a long conditional across lines is fine; leaving a gap inside it is not.

```csharp
// 👎 reported
var value = flag
    ?

    1
    : 0;

// 👍 not reported
var value = flag
    ? 1
    : 0;
```

## How to fix violations

Remove the blank line so each branch follows its operator token.
