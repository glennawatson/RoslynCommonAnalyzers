# SST1601 — Partial elements should be documented

| Item | Value |
| --- | --- |
| Category | Documentation |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A partial class, struct, interface, record, or method has no XML documentation comment and falls
within the configured coverage. Public, protected, and internal declarations are covered by default.
Private classes, structs, records, and methods are excluded by default; interfaces have their own setting.
Each partial declaration is checked separately, so a comment on another part does not satisfy this
requirement. Generated code is excluded.

## Example

Before:

```csharp
public partial class C
{
}
```

After:

```csharp
/// <summary>A container.</summary>
public partial class C
{
}
```

## How to fix violations

Add XML documentation to the reported declaration. Use `<summary>` to describe the type. Another
part can use a non-empty `<content>` element to describe the members it adds without repeating the
summary. `<inheritdoc/>` also counts as documentation.

There is no code fix.

## Configuration

The rule is enabled as a warning by default. These `.editorconfig` entries show the coverage defaults:

```ini
[*.cs]
dotnet_diagnostic.SST1601.severity = warning
stylesharp.document_exposed_elements = true
stylesharp.document_internal_elements = true
stylesharp.document_private_elements = false
stylesharp.document_interfaces = all
```

Severity accepts `none`, `silent`, `suggestion`, `warning`, or `error`.

The three element options accept `true` or `false`; missing or invalid values use the defaults shown.
Containing types limit visibility, so a public method inside an internal type follows the internal
setting. Turning on `document_private_elements` requires all non-interface declarations, even if
the exposed or internal option is off.

`stylesharp.document_interfaces` accepts `all` (default), `exposed`, or `none`. `all` requires every
partial interface declaration; `exposed` skips internal declarations; `none` skips them all.
`true` means `all`, `false` means `none`, and unrecognised values use `all`.

The shared options are described in
[documentation coverage scope](../CONFIGURATION.md#documentation-coverage-scope).

## When to suppress

Suppress the rule for a partial declaration whose documentation is deliberately maintained only
on another part, or reduce coverage for internal implementation details. Set
`dotnet_diagnostic.SST1601.severity = none` for files that should be excluded.
