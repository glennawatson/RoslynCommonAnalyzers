# SST1604 — Element documentation should have a summary

| Item | Value |
| --- | --- |
| Category | Documentation |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A type, delegate, method, constructor, destructor, property, or enum item has an XML documentation
comment without a top-level `<summary>` element. A summary inside another element does not count.
This check includes documented private members, overrides, and partial declarations.

## Example

Before:

```csharp
/// <remarks>Notes.</remarks>
public class Widget { }
```

After:

```csharp
/// <summary>A widget.</summary>
/// <remarks>Notes.</remarks>
public class Widget { }
```

## How to fix violations

Add a `<summary>` that briefly describes the declaration. Keep longer details in `<remarks>`.

There is no code fix.

## What is not reported

- A comment with a top-level `<inheritdoc/>`, which takes its documentation from another declaration.
- A partial declaration with a non-empty `<content>` element describing what that part adds.
- A declaration with no XML documentation comment; the coverage rules handle missing documentation.
- Field declarations, field-like events, custom events, indexers, operators, and generated code.

An empty `<content>` element, or one on a non-partial declaration, does not replace a summary.
An empty `<summary>` satisfies this presence check, but [SST1606](SST1606.md) reports its missing text.

## Configuration

The rule is enabled as a warning by default and has no options beyond severity:

```ini
[*.cs]
dotnet_diagnostic.SST1604.severity = warning
```

Severity accepts `none`, `silent`, `suggestion`, `warning`, or `error`.

The `stylesharp.document_*` coverage options do not disable checks on existing documentation.

## When to suppress

Suppress the rule if a documentation tool deliberately uses another top-level element instead of a
summary. Set `dotnet_diagnostic.SST1604.severity = none` for the affected files. Inherited
documentation and non-empty partial `<content>` comments need no suppression.
