# SST1605 — Partial element documentation should have a summary

| Item | Value |
| --- | --- |
| Category | Documentation |
| Severity | Warning (disabled by default) |
| Code fix | No |

## Cause

A documented partial element's documentation has no `<summary>`.

## Rule description

Off by default — documenting one part of a partial declaration is
often enough. Enable it in `.editorconfig` to require a `<summary>` on every documented
partial element.

## What is not reported

A part that describes itself with `<content>`, which is how a further part of a partial declaration
says what it adds rather than repeating what the type is. An empty `<content>` does not stand in for
the summary.

## How to fix violations

Add a `<summary>` element to the documentation, or a `<content>` element describing what this part
adds.
