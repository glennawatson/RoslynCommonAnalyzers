# SST1623 — Property summary should describe its accessors

| Item | Value |
| --- | --- |
| Category | Documentation |
| Default severity | Warning |
| Code fix | Yes |

## Cause

A property's non-empty `<summary>` does not start with the expected phrase in
plain text. Leading whitespace is allowed; capital letters must match.

| Property | Expected start |
| --- | --- |
| `get` and `set`, with no access modifier on `set` | `Gets or sets ` |
| `get` only, an expression body, or `init` | `Gets ` |
| `set` only, with no access modifier on `set` | `Sets ` |

The rule also accepts `Gets or sets ...` on get-only and `init` properties.
Properties with a more restricted `set` or `init`, such as `private set`, are
handled by [SST1624](SST1624.md), even when that rule is disabled.

Missing or empty summaries are handled by other documentation rules. A
top-level `<inheritdoc>`, or an `<inheritdoc>` inside the summary, skips this check.

## How to fix violations

Start the summary with the phrase that describes how callers use the property.

Bad:

```csharp
public class Counter
{
    /// <summary>The count.</summary>
    public int Count { get; set; }
}
```

Corrected:

```csharp
public class Counter
{
    /// <summary>Gets or sets the count.</summary>
    public int Count { get; set; }
}
```

The code fix inserts the required phrase before the first existing text character
and lowercases that character. It does not remove an incorrect opening phrase,
so review the result for repeated words. If the summary starts with an XML element
such as `<c>` or `<see>`, add the phrase before that element by hand.

## Configuration

Enabled by default as a warning. The example changes it to an error.
There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1623.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
Use `none` to disable the rule. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when your documentation uses a different consistent wording or language,
or when the required phrase would make a clear summary harder to read.
