# SST1624 — Property summaries should omit restricted set accessors

| Item | Value |
| --- | --- |
| Category | Documentation |
| Default severity | Warning (disabled by default) |
| Code fix | Yes, for a leading "Gets or sets" phrase |

## Cause

A property has a `set` or `init` accessor with its own access modifier, such as
`private`, and its non-empty summary does not start with `Gets ` or starts with
`Gets or sets `. The summary should describe access available to all callers
who can read the property.

Properties without a restricted write accessor are handled by [SST1623](SST1623.md).
Explicit interface implementations are excluded from this rule. Missing or empty
summaries, and summaries that use `<inheritdoc>`, are not reported here.

## How to fix violations

Begin the summary with `Gets ` and describe the value.

Bad:

```csharp
public class Container
{
    /// <summary>Gets or sets the value.</summary>
    public int Value { get; private set; }
}
```

Corrected:

```csharp
public class Container
{
    /// <summary>Gets the value.</summary>
    public int Value { get; private set; }
}
```

**Describe the readable accessor only** replaces a leading `Gets or sets` with
`Gets` in the first piece of documentation text. It preserves the remaining text
and spacing. Other incorrect openings, such as `The value`, need a manual edit;
the offered fix makes no change when it cannot find that leading phrase.

## Configuration

Disabled by default. Set a severity to enable it; the example enables it as an error.
There are no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST1624.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
Use `none` to disable the rule. See [configuration](../CONFIGURATION.md).

## When to suppress

Leave the rule disabled or suppress it when documentation intentionally describes
the setter for callers who can use it, such as derived classes with access to a
protected setter. It is also reasonable to use a different documentation language.
