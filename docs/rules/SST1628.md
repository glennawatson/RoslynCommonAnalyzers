# SST1628 — Documentation text should begin with a capital letter

| Item | Value |
| --- | --- |
| Category | Documentation |
| Severity | Warning (disabled by default) |
| Code fix | No |

## Cause

A documentation summary begins with a lower-case letter.

## Rule description

Off by default. Enable it to require summaries to read as proper
sentences beginning with a capital letter.

A summary that opens with an element — `<c>`, `<see>`, `<paramref>` — is not reported. It
starts with a code fragment or a name whose casing the language decides, so there is no
sentence-initial letter to capitalise and changing the one inside the element would break it.

```csharp
/// <summary><c>while (true)</c> loops forever.</summary>   // not reported
```

## How to fix violations

Capitalise the first letter of the summary.
