# SST1630 — Documentation text should contain whitespace

| Item | Value |
| --- | --- |
| Category | Documentation |
| Severity | Warning (disabled by default) |
| Code fix | No |

## Cause

A documentation summary is a single word with no whitespace.

## Rule description

Off by default. Enable it to require summaries to contain more than a
single word.

A summary that captions one code form — everything outside its elements being punctuation —
is not reported. Its spacing and its ratio of letters to symbols belong to the language, not
the author.

```csharp
/// <summary><c>string.IsNullOrEmpty(text.Trim())</c>.</summary>   // not reported
```
## How to fix violations

Expand the summary into a descriptive phrase.
