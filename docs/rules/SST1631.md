# SST1631 — Documentation text should be mostly letters

| Item | Value |
| --- | --- |
| Category | Documentation |
| Severity | Warning (disabled by default) |
| Code fix | No |

## Cause

Less than half of a documentation summary's characters are letters or whitespace.

## Rule description

Off by default. Enable it to flag summaries made up mostly of symbols
or punctuation rather than real prose.

A summary that captions one code form — everything outside its elements being punctuation —
is not reported. Its spacing and its ratio of letters to symbols belong to the language, not
the author.

```csharp
/// <summary><c>string.IsNullOrEmpty(text.Trim())</c>.</summary>   // not reported
```
## How to fix violations

Rewrite the summary as readable prose.
