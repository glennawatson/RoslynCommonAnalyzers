# SST1631 — Documentation text should be mostly letters

| Item | Value |
| --- | --- |
| Category | Documentation |
| Default | Disabled; warning when enabled |
| Code fix | No |

## Cause

Less than half of a nonempty `<summary>` consists of letters or whitespace.
Digits, punctuation, and symbols count against this total. Exactly half is accepted.
The check ignores spaces at the ends and counts each run of whitespace as one space.

A summary made only of XML elements and punctuation is exempt. For example,
`<summary><c>string.IsNullOrEmpty(text.Trim())</c>.</summary>` is accepted.
Text mixed with code elements is still checked.

## Example

Before:

```csharp
internal class C
{
    /// <summary>12 34 56</summary>
    public void M() { }
}
```

After:

```csharp
internal class C
{
    /// <summary>Does the work.</summary>
    public void M() { }
}
```

## How to fix violations

Replace unexplained numbers or symbols with a description of the member.
There is no code fix.

## Configuration

The rule is disabled by default. The 50% threshold cannot be configured.
Enable the rule in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1631.severity = warning
```

Use `error` to fail the build or `none` to disable it.

## When to suppress

Suppress it when a formula, protocol value, or other symbol-heavy text is the
clearest description and extra prose would add no useful information.
