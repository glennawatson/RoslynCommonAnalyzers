# SST1632 — Documentation text should meet a minimum length

| Item | Value |
| --- | --- |
| Category | Documentation |
| Default | Disabled; warning when enabled |
| Code fix | No |

## Cause

A nonempty `<summary>` contains fewer than four text characters. The check ignores
whitespace at the ends and counts each run of spaces, tabs, or line breaks as one
space. Four characters are enough to pass.

Empty summaries are not reported by this rule. Text inside code elements is still
subject to the minimum length.

## Example

Before:

```csharp
internal class C
{
    /// <summary>A b</summary>
    public void M() { }
}
```

After:

```csharp
internal class C
{
    /// <summary>Does the work.</summary>
    public void M() { }
}
```

## How to fix violations

Write a description that tells the reader what the member does.
There is no code fix.

## Configuration

The rule is disabled by default. The four-character minimum cannot be configured.
Enable the rule in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1632.severity = warning
```

Use `error` to fail the build or `none` to disable it.

## When to suppress

Suppress it when a short term fully describes the member, or when the documentation
language can express the meaning in fewer than four characters.
