# SST1710 — Prefer an extension indexer over an accessor-shaped extension method

| Item | Value |
| --- | --- |
| Category | Extensions |
| Severity | Warning |
| Enabled by default | **No** (opt-in) |
| Code fix | No |
| Applies to | C# 15 or later |

## Cause

A classic `this`-parameter extension method takes a receiver and one index, and returns an element.

```csharp
public static class SequenceExtensions
{
    public static int ElementAt(this int[] source, int index) => source[index];
}
```

## Rule description

That is an indexer written as a call. C# 15 allows an indexer inside an `extension(Receiver) { … }`
block, so the operation can be spelled the way indexing is spelled everywhere else:

```csharp
// 👍
public static class SequenceExtensions
{
    extension(int[] source)
    {
        public int this[int index] => source[index];
    }
}

int third = numbers[2];   // rather than numbers.ElementAt(2)
```

Because indexers are always instance members, an extension block declaring one must give its receiver
a name — `extension(int[] source)` rather than `extension(int[])`.

## What is reported

All of the following must hold:

- the method is a `this`-parameter extension method
- it takes exactly one further parameter, passed by value, of type `int`, `string`, `Index`, or
  `Range`
- it returns a value
- it declares no type parameters of its own
- its name is one of `ElementAt`, `ItemAt`, `GetAt`, `GetItem`, `At`, `Get`, or `Item`

A `void` method, one taking several arguments, or one whose name describes a computation rather than
an element lookup is not an indexer and is not reported.

## Why it is opt-in

The rule is **disabled by default**: converting changes the call syntax at every call site, so it is a
deliberate migration. Enable it in `.editorconfig` when you are ready:

```ini
dotnet_diagnostic.SST1710.severity = warning
```

## How to fix violations

Move the method into an `extension(Receiver receiver) { … }` block and declare it as
`public T this[int index]`, dropping the `this` parameter and referring to the receiver by name.
Update call sites from `receiver.Get(i)` to `receiver[i]`.
