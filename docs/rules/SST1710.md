# SST1710 — Prefer an extension indexer over an accessor-shaped extension method

| Item | Value |
| --- | --- |
| Category | Extensions |
| Default severity | Warning |
| Enabled by default | No |
| Code fix | No |
| Applies to | C# 15 or later |

## Cause

A classic extension method looks like an element lookup that could be written as `receiver[index]`.
All of these conditions must hold:

- The method is named `ElementAt`, `ItemAt`, `GetAt`, `GetItem`, `At`, `Get`, or `Item`.
- It returns a value and declares no type parameters.
- Besides its `this` receiver, it takes exactly one parameter, passed by value without `params`.
- That parameter is `int`, `string`, or a type named `Index` or `Range`.

The name checks are case-sensitive. The rule does not check whether the method's body actually
looks up an element. It reports nothing below C# 15.

## Example

Before, reported when the rule is enabled:

```csharp
public static class SequenceExtensions
{
    public static int ElementAt(this int[] source, int index) => source[index];
}
```

An array already has an indexer. Remove the redundant extension and let callers use it directly:

```csharp
int[] numbers = { 10, 20, 30 };
System.Console.WriteLine(numbers[2]);
```

## How to fix violations

If the receiver already provides the required indexer, use it as above. Otherwise, on C# 15 or later,
move the lookup into an `extension` block and declare an indexer with the same return type and
index parameter. Give the block's receiver a name so the indexer can use it.

Update callers from `receiver.Get(index)` to `receiver[index]`. There is no automatic code fix.

## Configuration

The rule is disabled by default. There are no options to change the recognised names or index types.
Set a severity to enable it:

```ini
[*.cs]
dotnet_diagnostic.SST1710.severity = error
```

Use `warning` for warnings, `suggestion` for suggestions, or `silent` for a hidden diagnostic.
Use `none` to disable the rule.

## When to suppress

Suppress when the method performs a computation that is clearer as a call, or when changing call
syntax would break a public API. Leave the rule disabled for source shared with projects that
cannot use C# 15 extension indexers.
