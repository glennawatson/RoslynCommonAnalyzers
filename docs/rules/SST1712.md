# SST1712 — Extension blocks with only static members should omit the receiver name

| Item | Value |
| --- | --- |
| Category | Extensions |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Yes — *Drop the receiver name* |
| Applies to | C# 14 or later |
| Analyzer | `Sst1712UnusableReceiverNameAnalyzer` |

## Cause

An `extension(Receiver receiver) { … }` block names its receiver, but every member it declares is
`static`.

```csharp
public static class StringExtensions
{
    // 👎 reported — nothing in the block can read 'text'
    extension(string text)
    {
        public static string Blank => "   ";
    }

    // 👍
    extension(string)
    {
        public static string Blank => "   ";
    }
}
```

## Rule description

A static extension member is declared on the receiver **type**, not on a value, so the receiver name
is not in scope for it. A block holding nothing but static members therefore names something no member
can read, which reads as though an instance member were intended and leaves the next person looking
for the use of a name that has none.

C# 14 allows the receiver type on its own — `extension(string)` — which states exactly what the block
does: it extends the type.

A block holding **any** instance member keeps its name, even alongside static ones, because the
instance member needs it:

```csharp
extension(string text)
{
    public static string Blank => "   ";
    public int Doubled => text.Length * 2; // needs 'text', so the name stays
}
```

An **empty** block names an unusable receiver too, but that is the shape
[SST1700](SST1700.md) reports, so this rule stays silent on it.

## How to fix violations

Apply the code fix, which drops the name and leaves the type. How the receiver is passed is left
alone — `extension(in Point point)` becomes `extension(in Point)` — because that is part of what the
block extends rather than part of the name.

## Related rules

- [SST1711](SST1711.md) — an instance block member that never reads the receiver it does have.
- [SST1700](SST1700.md) — an extension block with no members at all.

## Performance

The rule runs on class declarations and inspects only the modifier list of each block member, stopping
at the first non-static one. Nothing is materialized for a block that keeps its name.
