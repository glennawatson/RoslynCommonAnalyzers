# SST1804 — Empty positional record bodies should be a semicolon

| Item | Value |
| --- | --- |
| Category | Records |
| Default severity | Info |
| Enabled by default | Yes |
| Code fix | Yes |

## Cause

A `record` or `record struct` has a parameter list and a `{ }` body with no members. Comments inside the braces do not count as members. Records without a parameter list are excluded.

## How to fix violations

Replace the empty body with a semicolon.

Reported:

```csharp
public sealed record Point(int X, int Y) { }
```

Corrected:

```csharp
public sealed record Point(int X, int Y);
```

## Code fix

**Replace the empty body with a semicolon** removes the braces and the spacing before them. It keeps comments and line breaks after the closing brace.

The fix removes comments inside the braces and comments immediately before the opening brace. Move those comments before accepting the fix.

## Configuration

There are no rule-specific options. Set the severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1804.severity = suggestion
```

Values are `error`, `warning`, `suggestion` (the default Info level), `silent`, and `none`.

## When to suppress

Suppress when the body holds a comment that belongs there, or when your project consistently uses braces for record declarations.
