# SST1905 — Do not use async void

| Item | Value |
| --- | --- |
| Category | Concurrency |
| Default severity | Warning |
| Enabled by default | Yes |
| Code fix | Yes, for methods and local functions |

## Cause

An async method or local function returns `void`, or an async lambda or anonymous method is used where a delegate returning `void` is expected, such as `Action`.

Callers cannot await this work or catch its failures by wrapping the call in `try`/`catch`. An unhandled exception can terminate the application.

## What is not reported

The rule excludes functions with exactly two parameters: an `object` followed by `EventArgs` or a type derived from it. This is the usual event-handler shape; the names of the parameters do not matter, and the function need not be attached to an event.

Methods that override a base method or implement an interface method are also excluded. Functions that return a value, including `Task` and `ValueTask`, are not reported.

## How to fix violations

Return `Task` so callers can await completion and handle failures.

Reported:

```csharp
using System.Threading.Tasks;

public class Worker
{
    public async void Run()
    {
        await Task.Yield();
    }
}
```

Corrected:

```csharp
using System.Threading.Tasks;

public class Worker
{
    public async Task Run()
    {
        await Task.Yield();
    }
}
```

Update callers to use `await worker.Run()`. For an async lambda, change an `Action` target to `Func<Task>` and await the returned task where the delegate is called.

## Code fix

**Return Task instead of void** changes the return type of a method or local function to `System.Threading.Tasks.Task`. It uses the short name when it is available and preserves comments around the return type. The editor formats the replacement.

The fix does not add `await` at call sites or update delegate types. It is not offered for lambdas or anonymous methods; change their delegate contract manually.

## Configuration

There are no rule-specific options. Set the severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST1905.severity = warning
```

Values are `error`, `warning` (default), `suggestion`, `silent`, and `none`.

## When to suppress

Suppress when a required callback contract returns `void` and cannot be changed to return `Task`. Catch and handle failures inside that callback. Apply the same exception handling to async event handlers, even though the rule excludes them.
