# SST2003 — Use ObjectDisposedException.ThrowIf

| Item | Value |
| --- | --- |
| Category | Modernization |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An `if` in an instance member only throws a new `ObjectDisposedException` with
one `nameof(...)` argument. The `if` must have no `else` branch. Guards in static
members and guards with a custom message are not reported.

The rule reports nothing when `ObjectDisposedException.ThrowIf` is unavailable.
The helper is included in .NET 8 and later.

## Example

Before:

```csharp
using System;

public class Resource
{
    private bool _disposed;

    public void Dispose() => _disposed = true;

    public void Check()
    {
        if (_disposed) throw new ObjectDisposedException(nameof(Resource));
    }
}
```

After:

```csharp
using System;

public class Resource
{
    private bool _disposed;

    public void Dispose() => _disposed = true;

    public void Check()
    {
        ObjectDisposedException.ThrowIf(_disposed, this);
    }
}
```

## How to fix violations

The code fix replaces the whole guard with
`ObjectDisposedException.ThrowIf(condition, this)`. It keeps the condition and uses the current instance to identify the
disposed object. The helper takes the object name from the instance's runtime
type, so the exception's object name and message can differ from `nameof(...)`.

Comments before and after the `if` are kept. Comments inside the removed guard
can be lost. Fix All is supported.

## Configuration

There are no rule-specific options. The rule is enabled by default at `warning`
severity. Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2003.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and
`default`. Use `none` to disable the rule or `default` to restore its default.

## When to suppress

Suppress when the exception must name a different object, or callers depend on
the exact object name or message. A guard for a disposed child object may need to
keep naming that child instead of `this`.
