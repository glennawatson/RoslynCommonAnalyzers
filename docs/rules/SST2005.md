# SST2005 — Use the 'is' type pattern instead of comparing an 'as' cast to null

| Item | Value |
| --- | --- |
| Category | Modernization |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An `as` cast to a reference type is compared with `null` using `==` or `!=`.
The null literal can be on either side. Use `is` to test the type directly.
Casts to nullable value types, such as `as int?`, are not reported.

The `== null` form is reported only in C# 9 or later because its replacement uses
`is not`. The `!= null` form does not need C# 9.

## Example

Before:

```csharp
public class Example
{
    public bool IsText(object value) => (value as string) != null;

    public bool IsNotText(object value) => (value as string) == null;
}
```

After, in C# 9 or later:

```csharp
public class Example
{
    public bool IsText(object value) => value is string;

    public bool IsNotText(object value) => value is not string;
}
```

## How to fix violations

The code fix replaces the comparison with `value is T` for `!= null`, or
`value is not T` for `== null`. It removes the cast's extra parentheses and
uses single spaces around the new pattern. Comments on removed operators or
parentheses can be lost. Fix All is supported.

## Configuration

There are no rule-specific options. The rule is enabled by default at `warning`
severity. Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2005.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and
`default`. Use `none` to disable the rule or `default` to restore its default.

## When to suppress

Suppress if the cast type defines a custom `==` or `!=` operator whose null
comparison you need to preserve. An `is` test does not call those operators.
