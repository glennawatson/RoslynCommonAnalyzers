# SST2006 — Use the 'is not' pattern instead of negating an 'is' check

| Item | Value |
| --- | --- |
| Category | Modernization |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A type test is negated as `!(value is T)`. In C# 9 or later, `value is not T`
expresses the same test with less punctuation. Earlier language versions are not
reported.

Tests that declare a variable, such as `value is string text`, and other patterns,
such as `value is null`, are handled by [SST2008](SST2008.md).

## Example

Before:

```csharp
public class Example
{
    public bool IsNotText(object value) => !(value is string);
}
```

After:

```csharp
public class Example
{
    public bool IsNotText(object value) => value is not string;
}
```

## How to fix violations

The code fix replaces `!(value is T)` with `value is not T`, removes the wrapping
parentheses, and uses single spaces around the new pattern. Comments on removed
operators or parentheses can be lost. Fix All is supported.

## Configuration

There are no rule-specific options. The rule is enabled by default at `warning`
severity. Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2006.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and
`default`. Use `none` to disable the rule or `default` to restore its default.

## When to suppress

Suppress when shared source must also compile with a language version before
C# 9, or when a consistent use of `!` makes a group of related conditions easier
to read.
