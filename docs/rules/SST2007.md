# SST2007 — Declare the checked type in the pattern

| Item | Value |
| --- | --- |
| Category | Modernization |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An `if (value is T)` block starts by declaring one local variable initialized with
`(T)value`. Both expressions must read the same local variable or parameter, and
the checked and cast types must match. Fields, properties, and method calls are
not reported. The rule requires C# 7 or later.

A declaration pattern, such as `value is string text`, tests the type and gives
the matched value a name in one step.

## Example

Before:

```csharp
public class Example
{
    public int Length(object value)
    {
        if (value is string)
        {
            var text = (string)value;
            return text.Length;
        }

        return 0;
    }
}
```

After:

```csharp
public class Example
{
    public int Length(object value)
    {
        if (value is string text)
        {
            return text.Length;
        }

        return 0;
    }
}
```

## How to fix violations

The code fix moves the local's name into the `is` test and deletes the local
declaration. The remaining statements and any `else` branch stay in place.
Comments attached to the deleted declaration are removed too. No fix is offered
when the `if` contains directives such as `#region` or `#if`. Fix All is supported.

The variable takes the tested type and is declared in the condition. Review the
change if the original local used a broader type, or if the same name is used
elsewhere in the surrounding block.

## Configuration

There are no rule-specific options. The rule is enabled by default at `warning`
severity. Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2007.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and
`default`. Use `none` to disable the rule or `default` to restore its default.

## When to suppress

Suppress when the local needs its explicit broader type or its scope inside the
block. Also suppress for shared source that must compile before C# 7.
