# SST2011 — Record instants in UTC

| Item | Value |
| --- | --- |
| Category | Modernization |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A local clock read is used directly to initialize or assign a field or property,
or as a returned value. This includes members written with `=>`. The reported
reads are `DateTime.Now`, `DateTimeOffset.Now`, `DateTime.Today`, and
`DateTimeOffset.Now.DateTime`.

Use UTC for timestamps that record when an event happened. A local `DateTime`
can be ambiguous when daylight saving ends. `DateTimeOffset` keeps its offset,
but using UTC gives recorded timestamps a consistent offset across machines.

Local variables and expressions that consume the clock read, such as
`DateTime.Now.Hour` or `DateTime.Now.ToString("t")`, are not reported. Neither are
`DateTimeOffset.Now.UtcDateTime` and `DateTimeOffset.UtcNow.DateTime`.

## Example

Before:

```csharp
using System;

public class AuditEntry
{
    public DateTime Created { get; } = DateTime.Now;
}
```

After:

```csharp
using System;

public class AuditEntry
{
    public DateTime Created { get; } = DateTime.UtcNow;
}
```

## How to fix violations

The code fix replaces the clock read without changing its type. For `Today`,
comments attached to the replaced property name can be lost. Fix All is supported.

| Reported read | Replacement |
| --- | --- |
| `DateTime.Now` | `DateTime.UtcNow` |
| `DateTimeOffset.Now` | `DateTimeOffset.UtcNow` |
| `DateTime.Today` | `DateTime.UtcNow.Date` |
| `DateTimeOffset.Now.DateTime` | `DateTimeOffset.UtcNow.UtcDateTime` |

The last replacement uses `UtcDateTime` so the resulting `DateTime.Kind` is
`Utc`. Reading `.DateTime` instead would leave its kind as `Unspecified`.

The fix changes the clock value or offset. In particular, replacing `Today`
selects midnight on the UTC date, which can differ from the local date. It does
not convert local midnight to UTC. Review code that stores, compares, or formats
the result. Convert timestamps to local time at the point of display, for
example with `Created.ToLocalTime()`.

## Configuration

There are no rule-specific options. The rule is enabled by default at `warning`
severity. Set its severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2011.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and
`default`. Use `none` to disable the rule or `default` to restore its default.

## When to suppress

Suppress when the value intentionally represents a local calendar date, a local
appointment time, or an offset that must be retained. Also suppress when an
existing storage or API contract requires local time and cannot be changed with
the clock read.

## Related rules

[SST2010](SST2010.md), when enabled, asks for a `TimeProvider` even for UTC clock
reads. [SST2016](SST2016.md) can also report a public `DateTime` type; changing
the clock read does not change that type. [SST2017](SST2017.md) leaves the
`DateTime.UtcNow.Date` replacement alone.
