# SST2013 — Merge an if that only wraps another if

| Item | Value |
| --- | --- |
| Category | Modernization |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An `if` contains only another `if`, and neither has an `else`. This applies with or without braces,
including an `else if` that wraps another `if`. Extra statements in the outer block prevent a report.

Combine the conditions with `&&` to remove one level of nesting. The second condition still runs
only when the first is true.

## Example

Before:

```csharp
public class Checks
{
    public void Run(bool a, bool b)
    {
        if (a)
        {
            if (b)
            {
                System.Console.WriteLine(1);
            }
        }
    }
}
```

After:

```csharp
public class Checks
{
    public void Run(bool a, bool b)
    {
        if (a && b)
        {
            System.Console.WriteLine(1);
        }
    }
}
```

## How to fix violations

The code fix joins the conditions with `&&`, keeps the inner body, and reformats the merged
statement. It adds parentheses where needed to preserve the order of operations, such as
`(a || b) && (c || d)`.

Comments around the removed braces or before the inner `if` move above the merged statement.
Comments inside the retained body stay with that body.

## Configuration

The default is `warning`. There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2013.severity = error
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none` (disabled).
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when separate conditions make a long decision easier to read or provide useful separate
breakpoint locations. Keep the nesting only when it helps explain the code.
