# SST2100 — Use an empty collection expression

| Item | Value |
| --- | --- |
| Category | CollectionExpressions |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled; requires C# 12 or later |

## Cause

An empty collection creation can use `[]`. Reported forms include `Array.Empty<T>()`,
`Enumerable.Empty<T>()`, empty or zero-length array creations, and constructors with no arguments
and no initializer, such as `new List<int>()`.

The destination must supply a type: a one-dimensional array, `List<T>`, `IList<T>`, `ICollection<T>`,
`IEnumerable<T>`, `IReadOnlyList<T>`, or `IReadOnlyCollection<T>`. This can come from a typed variable,
an assignment, a return type, or a method parameter. Collection expressions require C# 12 or later.

## Example

Before:

```csharp
using System;
using System.Collections.Generic;

public class Data
{
    public int[] Values = Array.Empty<int>();
    public List<int> Items = new List<int>();
}
```

After:

```csharp
using System;
using System.Collections.Generic;

public class Data
{
    public int[] Values = [];
    public List<int> Items = [];
}
```

## What is not reported

Initializers using `var`, `ImmutableArray<T>.Empty`, constructors with arguments, and `new()` are
excluded. Arguments whose parameter type uses a method's generic type parameter are also excluded.
A parameter type fixed by the containing type, such as `List<int[]>.Add`, is allowed.

## How to fix violations

The code fix replaces the whole creation or factory call with `[]`. It keeps the destination type
and leaves `using` directives in place. Comments inside the removed expression can be lost.

## Configuration

The default is `warning`. There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2100.severity = error
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none` (disabled).
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when code depends on a particular concrete collection type, constructor behavior, or
distinct array instance. With an interface destination, `[]` can create a different implementation.
Keep the explicit creation if it is needed to select a particular method overload.
