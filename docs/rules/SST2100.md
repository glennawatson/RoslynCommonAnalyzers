# SST2100 — Use an empty collection expression

| Item | Value |
| --- | --- |
| Category | CollectionExpressions |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled for C# 12 or later |

## Cause

An explicitly typed array or standard generic collection is created empty.

```csharp
int[] values = Array.Empty<int>();
```

## Rule description

C# 12 collection expressions provide the concise `[]` form. The rule requires a
supported explicit target type and excludes targetless `var` initializers and
`ImmutableArray<T>.Empty`.

## What is not reported

An argument a generic call infers a type argument from. A collection expression takes its type from
its target, so where the target is a method type parameter the reported target type was inferred from
this very expression; removing the creation leaves inference nothing to work from and the call fails
with CS0411 or CS0311. A type parameter the receiver already fixed is still reported.

## How to fix violations

Replace the creation with `[]`. The provided code fix does this automatically.
