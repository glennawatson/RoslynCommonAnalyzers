# SST2102 — Let the span target carry stack allocation

| Item | Value |
| --- | --- |
| Category | CollectionExpressions |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled; requires C# 12 or later |

## Cause

A non-empty `stackalloc` initializer has an explicit `Span<T>` or `ReadOnlySpan<T>` destination.
It can be written as a collection expression with the same elements. Both `stackalloc int[] { ... }`
and `stackalloc[] { ... }` are supported.

The rule requires C# 12 or later and a reference that provides
`System.Runtime.CompilerServices.CollectionBuilderAttribute`, included in .NET 8 and later.
Empty initializers, allocations without initializers, declarations using `var`, and pointer
destinations are not reported.

## Example

Before:

```csharp
using System;

public class Calculations
{
    public int Sum()
    {
        Span<int> values = stackalloc int[] { 1, 2, 3 };
        return values[0] + values[1] + values[2];
    }
}
```

After:

```csharp
using System;

public class Calculations
{
    public int Sum()
    {
        Span<int> values = [ 1, 2, 3 ];
        return values[0] + values[1] + values[2];
    }
}
```

## How to fix violations

The code fix removes `stackalloc` and the array type and replaces the initializer braces with
brackets. It keeps the span destination and the text inside the braces, including spaces, line
breaks, and comments. Comments in the removed allocation before the opening brace can be lost.

## Configuration

The default is `warning`. There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2102.severity = error
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none` (disabled).
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when explicit stack allocation is a requirement or when measurements show that the
collection expression changes memory use in a way that matters. A span collection expression lets
the compiler choose storage; the syntax alone does not guarantee stack allocation.
