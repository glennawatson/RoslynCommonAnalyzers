# SST2104 - Return builder contents directly

## Cause

A method creates a builder with `CreateBuilder` or `GetInstance`, calls `Add(value)` one or more
times, then returns its contents. The calls must be consecutive, with no other statements between
them. The final call must be `ToImmutable()`, `ToImmutableAndClear()`, `ToImmutableAndFree()`,
`ToArray()`, or `ToArrayAndFree()`.

This rule requires C# 12 or later and a reference that provides `CollectionBuilderAttribute`.
The return type must be a one-dimensional array or a collection marked with that attribute,
such as `ImmutableArray<T>`.

## Example

Before:

```csharp
using System.Collections.Immutable;

public class Example
{
    public ImmutableArray<int> Values()
    {
        var builder = ImmutableArray.CreateBuilder<int>();
        builder.Add(1);
        builder.Add(2);
        return builder.ToImmutable();
    }
}
```

After:

```csharp
using System.Collections.Immutable;

public class Example
{
    public ImmutableArray<int> Values()
    {
        return [1, 2];
    }
}
```

## Code fix

The fix replaces the builder declaration, `Add` calls, and conversion with one
`return [...];` statement. It puts the elements in their original order.

Use this fix only when the builder declaration starts its block. Rebuilding a block with
earlier statements can fail because the fix does not retain those statements. Comments on
the removed calls and return can also be lost. Rewrite by hand if the block has earlier
statements or comments you need to keep.
Fix All is not available.

## Configuration

Enabled by default as a warning. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2104.severity = error
```

There are no rule-specific options. Severity values are `error`, `warning`, `suggestion`,
`silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Keep the builder when its creation, `Add` calls, or conversion do required work beyond collecting
elements. Suppression also makes sense when measurements justify a pooled builder.
