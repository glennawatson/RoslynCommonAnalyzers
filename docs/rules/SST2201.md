# SST2201 - Express return-only switch as a value

## Cause

A switch statement has at least two sections, including `default`. Each section has exactly
one label and one `return value;` or `throw exception;` statement.

This rule requires C# 8 or later. It skips switches with stacked labels, extra statements,
braces around a section's statements, or no `default`.

## Example

Before:

```csharp
public class Example
{
    public int Map(int value)
    {
        switch (value)
        {
            case 0:
                return 1;
            default:
                return 2;
        }
    }
}
```

After:

```csharp
public class Example
{
    public int Map(int value)
    {
        return value switch
        {
            0 => 1,
            _ => 2
        };
    }
}
```

## How to fix violations

The code fix replaces the switch with `return value switch { ... };`. Each case becomes an
arm, `default` becomes `_`, and a thrown exception becomes a throw expression.

The fix does not preserve `when` conditions or comments attached to case labels and statements.
Rewrite those switches by hand. It keeps section order, so move a `default` section to the end
before applying the fix.

## Configuration

Enabled by default as a warning. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2201.severity = error
```

There are no rule-specific options. Severity values are `error`, `warning`, `suggestion`,
`silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when separate return statements make debugging or a long mapping easier to follow.
A switch statement is also reasonable when its case comments are clearer beside separate branches.
