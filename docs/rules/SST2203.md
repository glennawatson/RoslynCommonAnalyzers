# SST2203 - Index from the end directly

## Cause

An array or string is indexed as `values[values.Length - offset]`. The array or string must
be held in a local variable or parameter, and both names must refer to that same variable.

This rule requires C# 8 or later. It does not report field or property access, custom indexers,
or collection `Count` calculations.

## Example

Before:

```csharp
public class Example
{
    public int Last(int[] values) => values[values.Length - 1];
}
```

After:

```csharp
public class Example
{
    public int Last(int[] values) => values[^1];
}
```

`^1` means the last element. `^0` points past the end and cannot select an element.

## Code fix

The fix replaces `values.Length - offset` with `^offset` and keeps the indexed variable.
Comments inside the removed calculation can be lost.

No fix is offered when parentheses surround the whole subtraction. For a compound offset,
rewrite by hand and keep parentheses, for example `values[^(offset + 1)]`; the fix does not
add those parentheses.

## Configuration

Enabled by default as a warning. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2203.severity = error
```

There are no rule-specific options. Severity values are `error`, `warning`, `suggestion`,
`silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the explicit subtraction makes a surrounding indexing calculation easier to
understand, or when the same source must compile with a compiler that does not support `^`.
