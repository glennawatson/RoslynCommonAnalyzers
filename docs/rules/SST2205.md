# SST2205 - List every enum switch statement case

## Cause

A switch statement over a non-nullable enum omits a named enum member and has no `default`
section. Listing the members makes the intended handling visible.

An unguarded `case`, including named values joined by `or`, counts as handling those members.
A `when` condition does not guarantee that the member is handled. The rule checks member names:
a numeric case or a different enum member with the same numeric value does not stand in for
the missing name.

## Example

Before:

```csharp
public enum Color { Red, Blue }

public class Example
{
    public void Handle(Color color)
    {
        switch (color)
        {
            case Color.Red:
                break;
        }
    }
}
```

After:

```csharp
public enum Color { Red, Blue }

public class Example
{
    public void Handle(Color color)
    {
        switch (color)
        {
            case Color.Red:
                break;
            case Color.Blue:
                break;
        }
    }
}
```

## Code fix

The fix adds all missing labels to one section ending in `break;`. Add any required work
to that section. If a missing member is already named under a `when` condition, the fix
adds `default: break;` instead.

The fix formats the switch. It is not offered when the switch contains directives such as
`#region`.

## Configuration

Enabled by default as a warning. To disable it:

```ini
[*.cs]
dotnet_diagnostic.SST2205.severity = none
```

There are no rule-specific options. Severity values are `error`, `warning`, `suggestion`,
`silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the switch intentionally handles only a subset and execution should continue
after it for all other values. A `default` section also makes that choice explicit.

Suppress when enum aliases share a numeric value: adding a case for every name can create
duplicate case labels.
