# SST2205 - List every enum switch statement case

Enum switch statements should name every enum value unless they intentionally use a `default`
section.

## Example

```csharp
switch (mode)
{
    case Mode.First:
        break;
}
```

Use:

```csharp
switch (mode)
{
    case Mode.First:
        break;
    case Mode.Second:
        break;
}
```

## Notes

The analyzer checks enum symbols and existing case labels directly, and leaves switches with
`default` alone.

The code fix stacks the missing values onto one section, written the way the file itself names them
so the label binds wherever the file is compiled. Where a value is named only under a `when` guard,
a `default: break;` section is offered instead: a second unguarded label for that value reads as a
duplicate of the one already there.
