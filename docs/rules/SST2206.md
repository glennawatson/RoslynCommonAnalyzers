# SST2206 - List every enum switch expression arm

## Cause

A switch expression over a non-nullable enum omits a named member and has no `_` arm.
Write an arm for each member you intend to handle.

The rule counts arms written with a single enum member, such as `Color.Red => 1`. Patterns such as
`Color.Red or Color.Blue`, numeric patterns, and another member with the same numeric value
do not count for those names. A named arm counts even with a `when` condition, and any
`_` arm stops this rule from reporting. A clean result therefore does not prove that every
input has a matching arm.

Switch expressions require C# 8 or later.

## Example

Before:

```csharp
public enum Color { Red, Blue }

public class Example
{
    public int Map(Color color) => color switch
    {
        Color.Red => 1
    };
}
```

After applying the fix:

```csharp
public enum Color { Red, Blue }

public class Example
{
    public int Map(Color color) => color switch
    {
        Color.Red => 1,
        Color.Blue => throw new System.NotImplementedException()
    };
}
```

## Code fix

The fix appends an arm for each missing member. Each added arm throws
`System.NotImplementedException`; replace that placeholder with the intended result or
exception before relying on the new case. The fix formats the switch expression.

No fix is offered when the switch contains directives such as `#region`.

## Configuration

Enabled by default as a warning. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2206.severity = error
```

There are no rule-specific options. Severity values are `error`, `warning`, `suggestion`,
`silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when combined patterns already cover the intended values, or when enum aliases
would make added arms unreachable. Use a final `_` arm when one result or exception should
handle all other values, including unnamed numeric values.
