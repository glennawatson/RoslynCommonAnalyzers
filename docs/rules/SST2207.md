# SST2207 - Fold null guard into returned value

## Cause

An `if` checks a name against `null`, throws an exception, and is followed immediately in the
same block by `return` of that name. The check can use `is null`, `== null`, or `null ==`.

This rule requires C# 7 or later. It skips guards with an `else`, extra statements, or comments
before or after the guard. Returning a different expression is not reported.

## Example

Before:

```csharp
using System;

public class Example
{
    public string Require(string value)
    {
        if (value is null)
        {
            throw new ArgumentNullException(nameof(value));
        }

        return value;
    }
}
```

After:

```csharp
using System;

public class Example
{
    public string Require(string value)
    {
        return value ?? throw new ArgumentNullException(nameof(value));
    }
}
```

## Code fix

The fix replaces both statements with `return value ?? throw exception;`.
The expression returns the value when it is not null and throws otherwise.

Comments inside the guard or attached to the removed return can be lost. Move them before
accepting the fix. No fix is offered when a directive separates the guard and return.

## Configuration

Enabled by default as a warning. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2207.severity = error
```

There are no rule-specific options. Severity values are `error`, `warning`, `suggestion`,
`silent`, and `none`. See [configuration](../CONFIGURATION.md).

## When to suppress

Keep a separate guard when it makes validation or debugging clearer. Suppress if `==` has
custom null behavior, or if reading a property twice is intentional: `??` checks actual null
and reads its left side once.
