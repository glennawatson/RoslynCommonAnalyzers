# SST2211 - Remove nullable restore with no local effect

The rule reports `#nullable restore` before the file has used any `#nullable enable`
or `#nullable disable` directive. This includes restores targeting only `warnings`
or `annotations`.

A file already starts with the project's nullable settings. An early restore adds
nothing. Restores after an enable or disable directive are left alone.

## Example

```csharp
#nullable restore

class Example { }
```

Use:

```csharp
class Example { }
```

## Code fix

The fix deletes the directive's whole line, including its line break and any
comment on that line. Move a comment you need to keep before accepting the fix.

## Configuration

Enabled by default as a warning. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2211.severity = error
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`. There are no other
options. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when a section is copied between files and needs to restore project
settings regardless of the directives that precede it in the destination file.
