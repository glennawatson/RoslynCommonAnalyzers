# SST2212 - Use UTF-8 literal bytes

The rule reports `System.Text.Encoding.UTF8.GetBytes("...")` when the argument is
a string literal and the result is used as `byte[]` or `ReadOnlySpan<byte>`.
It requires C# 11 or later.

The `u8` suffix lets the compiler produce UTF-8 bytes from the text. A
`ReadOnlySpan<byte>` result avoids creating the byte array returned by `GetBytes`.
An array result still needs an array allocation.

Byte-array initializers, runtime strings, and results used as other types are not
reported.

## Example

```csharp
using System;

class Example
{
    public ReadOnlySpan<byte> Header() => System.Text.Encoding.UTF8.GetBytes("GET");
    public byte[] Copy() => System.Text.Encoding.UTF8.GetBytes("POST");
}
```

Use:

```csharp
using System;

class Example
{
    public ReadOnlySpan<byte> Header() => "GET"u8;
    public byte[] Copy() => "POST"u8.ToArray();
}
```

## Code fix

The fix replaces the call with a quoted `u8` literal. It adds `.ToArray()` for a
`byte[]` result. It keeps surrounding comments, but comments inside the removed
call can be lost.

## Configuration

Enabled by default as a warning. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2212.severity = error
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`. There are no other
options. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when shared source must compile with a compiler older than C# 11, or when
keeping literal and runtime encoding calls alike makes the surrounding code clearer.
