# SST2215 - Swap locals with tuple assignment

The rule reports three consecutive statements that use a temporary local to swap
two locals or parameters. The temporary must not be used later in the block.
Fields, properties, and indexers are excluded.

Tuple assignment expresses the swap in one statement and requires C# 7 or later.

## Example

```csharp
class Example
{
    public void Swap()
    {
        var left = 1;
        var right = 2;
        var temp = left;
        left = right;
        right = temp;
    }
}
```

Use:

```csharp
class Example
{
    public void Swap()
    {
        var left = 1;
        var right = 2;
        (left, right) = (right, left);
    }
}
```

## Code fix

The fix replaces the temporary declaration with `(left, right) = (right, left);`
and deletes the two assignments. Comments on those deleted assignments can be lost.

## Configuration

Enabled by default as a warning. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2215.severity = error
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`. There are no other
options. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when each assignment needs its own explanation or debugger breakpoint,
or when the same source must compile with a C# version older than 7.
