# SST2216 - Let tuple element names be inferred

The rule reports an explicit tuple element name that exactly matches the variable
or member used as its value. For example, `name: name` can be written as `name`.
C# takes the element name from the expression.

Different names, such as `Years: person.Age`, are left alone. The rule requires
C# 7.1 or later, which supports inferred tuple element names.

## Example

```csharp
class Person
{
    public int Age { get; set; }

    public (string name, int Age) Describe(string name) => (name: name, Age: this.Age);
}
```

Use:

```csharp
class Person
{
    public int Age { get; set; }

    public (string name, int Age) Describe(string name) => (name, this.Age);
}
```

## Code fix

The fix removes the repeated name and colon from each reported element. It keeps
the value expression. A comment between the removed name and colon can be lost.

## Configuration

Enabled by default as a warning. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2216.severity = error
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`. There are no other
options. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when explicit names make a long tuple easier to read, or when shared
source must compile with C# 7.0.
