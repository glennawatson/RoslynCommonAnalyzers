# SST2219 - Keep simple accessors expression-shaped

The rule reports a `get` accessor containing one `return` statement, or a `set` or
`init` accessor containing one assignment. Replace the block with `=>` and the
expression. Properties and indexers are supported.

Accessors with more than one statement, setter calls without an assignment, and
existing expression bodies are left alone. A lone getter that can become a
whole-property or whole-indexer expression body is handled by
[the property rule](SST2279.md) or [the indexer rule](SST2280.md).

Expression-bodied accessors require C# 7 or later. An `init` accessor requires C# 9
or later.

## Example

```csharp
class Example
{
    private int _value;

    public int Value
    {
        get { return _value; }
        set { _value = value; }
    }
}
```

Use:

```csharp
class Example
{
    private int _value;

    public int Value
    {
        get => _value;
        set => _value = value;
    }
}
```

## Code fix

The fix replaces each reported accessor's braces and statement with an expression
body and semicolon. It keeps the accessor's attributes and access modifiers.
Comments inside the removed block can be lost; move comments you need before
accepting the fix.

## Configuration

Enabled by default as a warning. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2219.severity = error
```

Values: `error`, `warning`, `suggestion`, `silent`, or `none`. There are no other
options. See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when block bodies make related accessors easier to read or provide room
for useful comments. Shared source targeting C# versions older than 7 also needs
block bodies.
