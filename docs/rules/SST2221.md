# SST2221 - Mark ignored expression values

## Cause

A method call or object creation stands alone as a statement, and its value is
ignored. Assign the value to `_`, the discard, to make that choice clear.

This rule requires C# 7 or later. It skips calls that return `void`, assignments,
increments, and `await` statements. It is disabled by default.

## Example

Before:

```csharp
class C
{
    public void Run()
    {
        Compute();
    }

    private int Compute() => 1;
}
```

After:

```csharp
class C
{
    public void Run()
    {
        _ = Compute();
    }

    private int Compute() => 1;
}
```

## Code fix

**Assign ignored value to discard** adds `_ =` before the expression. The call
still runs. The fix is not offered when a name such as a local, parameter, or
field called `_` is in scope, because the assignment would write to that name.
Rename it before using the fix. Fix All skips those occurrences.

Comments before or after the statement are kept. A comment between the expression
and its semicolon can be lost.

## Configuration

Disabled by default. Its default severity is warning when enabled. There are no
rule-specific options. To enable it as an error:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2221.severity = error
```

Use `none` to disable the rule, or choose `silent`, `suggestion`, `warning`, or
`error`.

## When to suppress

Suppress when ignoring a return value is normal for the API, such as a chain of
calls that returns the same object. Leave the rule disabled if discard assignments
would add noise throughout the project.
