# SST2223 - Assign fallback values with ??=

## Cause

An `if` statement checks a value for null and only assigns a fallback to that same
value. It has no `else`. Use `??=` to assign the fallback only when the value is null.
The rule also reports `value ?? (value = fallback)`.

This rule requires C# 8 or later. It accepts `is null`, `== null`, and `null ==`
checks, but skips overloaded `==` operators. Targets can be names or member chains
such as `this.cache.Value`. Targets containing calls or indexers are skipped.

## Example

Before:

```csharp
class C
{
    public string GetValue(string value)
    {
        if (value is null)
        {
            value = "fallback";
        }

        return value;
    }
}
```

After:

```csharp
class C
{
    public string GetValue(string value)
    {
        value ??= "fallback";
        return value;
    }
}
```

## Code fix

**Use coalescing assignment** replaces the whole `if` with a `??=` statement.
It also replaces `value ?? (value = fallback)` with `value ??= fallback`.
Comments on the removed condition, braces, or assignment can be lost; comments
outside the `if` are kept.

## Configuration

Enabled by default as a warning. There are no rule-specific options. To report it
as an error:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2223.severity = error
```

Use `none` to disable the rule, or choose `silent`, `suggestion`, `warning`, or
`error`.

## When to suppress

Suppress when the separate null branch is clearer for debugging. Review member
chains whose property getters do work: `??=` can evaluate the chain fewer times
than the separate check and assignment.
