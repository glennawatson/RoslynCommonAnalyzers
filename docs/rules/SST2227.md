# SST2227 - Fold null fallback into the assignment

## Cause

A declaration or assignment is immediately followed by a null check on the value
it wrote. The check has no `else` and its only statement throws an exception or
assigns a fallback. Put that action beside the assigned expression with `??`.

The assigned expression must have a reference type. Nullable value types are
skipped. Checks using an overloaded `==`, and targets containing calls or indexers,
are also skipped.

A throw needs C# 7 or later. In C# 8 or later, a fallback assignment is reported
by [SST2223](SST2223.md), which prefers `??=`.

## Example

Before:

```csharp
class C
{
    public string GetValue(string input)
    {
        string value = input;
        if (value == null)
        {
            throw new System.InvalidOperationException();
        }

        return value;
    }
}
```

After:

```csharp
class C
{
    public string GetValue(string input)
    {
        string value = input ?? throw new System.InvalidOperationException();
        return value;
    }
}
```

## Code fix

**Fold null check into assignment** appends `?? throw exception` or `?? fallback`
to the assigned expression, then removes the entire `if` statement. It keeps the
declaration or assignment. Comments attached to the removed `if`, including its
body, can be lost. Move useful comments before accepting the fix.

## Configuration

Enabled by default as a warning. There are no rule-specific options. To report it
as an error:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2227.severity = error
```

Use `none` to disable the rule, or choose `silent`, `suggestion`, `warning`, or
`error`.

## When to suppress

Suppress when a separate null branch is easier to debug or read. Keep separate
statements when a property getter or setter must run in the original order: the
combined expression changes when the assignment happens relative to the fallback
or exception.
