# SST2228 - Prefer a local function for local call sites

## Cause

A local variable has an explicit delegate type, is initialized with a non-async
lambda, and is used only for direct calls after its declaration. A local function
keeps those calls together without needing a delegate object.

This rule requires C# 7 or later. It skips `var` declarations, declarations with
multiple variables, unused delegates, and delegates passed, returned, assigned,
or read as values. Lambda parameters with modifiers such as `ref` are skipped.

## Example

Before:

```csharp
class C
{
    public int Run()
    {
        System.Func<int, int> add = value => value + 1;
        return add(1);
    }
}
```

After:

```csharp
class C
{
    public int Run()
    {
        int add(int value) => value + 1;
        return add(1);
    }
}
```

## Code fix

**Use a local function** replaces the delegate declaration with a function of the
same name. It takes the return and parameter types from the written `Func<...>` or
`Action<...>` type, keeps parameter names and the lambda body, and leaves calls
unchanged. Both expression and block bodies are supported.

The fix supports generic `Func` and `Action` spellings, including qualified names.
It is not offered for non-generic `Action`, custom delegates, or type aliases.
Those cases need a manual edit even when the diagnostic is reported.

The new function is not marked `static`. Parameter attributes and default values
are not copied, and comments attached to the removed declaration or lambda syntax
can be lost.

## Configuration

Enabled by default as a warning. There are no rule-specific options. To report it
as an error:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2228.severity = error
```

Use `none` to disable the rule, or choose `silent`, `suggestion`, `warning`, or
`error`.

## When to suppress

Suppress when keeping a delegate makes a group of similar callbacks easier to
understand. If parameter attributes or defaults matter, preserve them in a manual
rewrite instead of accepting the automatic fix.
