# SST2232 - Omit generic arguments inside nameof

## Cause

A `nameof` expression includes a generic name with concrete type arguments, such
as `List<int>`. The arguments do not appear in the resulting name. Omit them to
show that only the name matters.

This rule requires C# 14 or later. Names whose arguments are already omitted are
not reported.

## Example

Before:

```csharp
class C
{
    public string GetName() => nameof(System.Collections.Generic.List<int>);
}
```

After:

```csharp
class C
{
    public string GetName() => nameof(System.Collections.Generic.List<>);
}
```

Both methods return `"List"`.

## Code fix

**Omit generic arguments in nameof** removes the type arguments from generic
names in the `nameof` argument. It keeps the name and the number of argument slots:
`List<int>` becomes `List<>`, and `Dictionary<string, int>` becomes `Dictionary<,>`.
Comments inside the removed argument lists are lost.

## Configuration

Enabled by default as a warning. There are no rule-specific options. To report it
as an error:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2232.severity = error
```

Use `none` to disable the rule, or choose `silent`, `suggestion`, `warning`, or
`error`.

## When to suppress

Suppress when the same source must also compile with an older C# version, or when
concrete type arguments provide useful context for the reader.
