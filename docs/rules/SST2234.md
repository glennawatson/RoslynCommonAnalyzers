# SST2234 - Use the T? shorthand for nullable value types

## Cause

A nullable value type is written as `Nullable<T>` or `System.Nullable<T>` where
`T?` can be used. Both spellings mean the same type; for example, `int?` holds an
integer or null.

The rule skips `typeof(Nullable<>)`, direct `nameof` operands, names used to access
a member, `using` directive targets, and XML documentation references. It also
skips the non-generic `Nullable` helper class and unrelated types named `Nullable`.

## Example

Before:

```csharp
class C
{
    public System.Nullable<int> GetValue() => null;
}
```

After:

```csharp
class C
{
    public int? GetValue() => null;
}
```

## Code fix

**Use the T? shorthand** removes the `Nullable` wrapper and its namespace or alias
qualification, then adds `?` to the existing type argument. It supports Fix All.
Comments outside the replaced type are kept; comments inside the removed spelling
can be lost.

## Configuration

Enabled by default as a warning. There are no rule-specific options. To report it
as an error:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2234.severity = error
```

Use `none` to disable the rule, or choose `silent`, `suggestion`, `warning`, or
`error`.

See [docs/CONFIGURATION.md](../CONFIGURATION.md).

## When to suppress

Suppress when the explicit spelling is needed for consistency with nearby examples
or documentation. No suppression is needed for the skipped positions listed above.
