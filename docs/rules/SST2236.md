# SST2236 - Use using declarations for tail-position using blocks

**Category:** ModernSyntax  
**Default severity:** Warning (enabled)  
**Code fix:** None

## Cause

A `using` statement declares a resource, has a braced body, and is the last statement
inside another block. In C# 8 or later, a using declaration removes one level of
indentation and disposes the resource at the same point.

Blocks followed by other statements are not reported. Neither are `using (resource)`
statements that use an existing variable, or using statements without a braced body.

## Example

Before:

```csharp
using System.IO;

public class Example
{
    public void Write()
    {
        using (var stream = new MemoryStream())
        {
            stream.WriteByte(1);
        }
    }
}
```

After:

```csharp
using System.IO;

public class Example
{
    public void Write()
    {
        using var stream = new MemoryStream();
        stream.WriteByte(1);
    }
}
```

## How to fix violations

There is no code fix. Replace the parentheses with a declaration ending in `;`, then
remove the using block's braces. Keep `await` when converting an `await using` block.
Check for local names that conflict after removing the inner block.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST2236.severity = error
```

The default severity is `warning`. Values are `error`, `warning`, `suggestion`,
`silent`, and `none` (disabled). There are no rule-specific options.
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the braces make the resource's lifetime clearer, or removing the inner
scope would require confusing local renames.
