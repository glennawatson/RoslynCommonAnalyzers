# SST2242 - Complete enum switch statement mappings

**Category:** ModernSyntax  
**Default severity:** Warning (enabled)  
**Code fix:** Yes (supports Fix All)

## Cause

A switch statement over a non-nullable enum omits a named enum member and has no
`default` section. Name each member or add a `default` section to handle the rest.

Named values in `or` patterns count as covered. A label with a `when` condition does
not cover its value unconditionally. Numeric case labels do not count as naming enum
members. A switch with a section containing no statements is left alone.

## Example

Before:

```csharp
public enum Color { Red, Blue }

public class Example
{
    public int Map(Color color)
    {
        switch (color)
        {
            case Color.Red:
                return 1;
        }

        return 0;
    }
}
```

After adding the missing case:

```csharp
public enum Color { Red, Blue }

public class Example
{
    public int Map(Color color)
    {
        switch (color)
        {
            case Color.Red:
                return 1;
            case Color.Blue:
                break;
        }

        return 0;
    }
}
```

## Code fix

**Add missing enum cases** appends the missing labels to one shared section ending in
`break;`. It uses enum names valid in the file. The added section continues after the
switch; replace the `break` with real handling if needed.

**Add a catch-all section** appends `default: break;` instead when the enum comes from
a referenced assembly, or a missing value is already named under a `when` condition.
The fix formats the switch and is not offered when it contains preprocessor directives.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST2242.severity = error
```

The default severity is `warning`. Values are `error`, `warning`, `suggestion`,
`silent`, and `none` (disabled). There are no rule-specific options.
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an earlier check guarantees that only the listed values can reach the
switch and adding cases would obscure that contract. If other values should do nothing,
an explicit `default: break;` records that choice and satisfies the rule.
