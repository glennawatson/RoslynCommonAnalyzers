# SST2243 - Use a raw string literal

**Category:** ModernSyntax  
**Default severity:** Warning (enabled)  
**Code fix:** Yes (supports Fix All)

## Cause

In C# 11 or later, a verbatim string (`@"..."`) contains doubled quotes or spans
multiple lines. A raw string uses three or more quotes at each end and lets you write
quote characters directly in its contents.

The rule skips regular strings, interpolated strings, and strings inside preprocessor
directives. It also skips single-line values that start or end with a quote, and
multi-line values with a non-empty line made only of spaces or tabs. Empty lines are allowed.

## Example

Before:

```csharp
string greeting = @"say ""hi"" there";

string block = @"first
second";
```

After:

```csharp
string greeting = """say "hi" there""";

string block = """
first
second
""";
```

## Code fix

**Use a raw string literal** removes the doubled-quote escapes and chooses a delimiter
longer than any run of quotes in the content, with at least three quotes. Single-line
strings stay on one line. Multi-line strings get separate delimiter lines and content
indented to match the line where the literal starts.

The fix keeps surrounding comments. It uses the file's detected line ending throughout
multi-line content. If the original contains mixed Windows and Unix line endings, the
string's value can change; check strings whose exact line endings matter.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST2243.severity = error
```

The default severity is `warning`. Values are `error`, `warning`, `suggestion`,
`silent`, and `none` (disabled). There are no rule-specific options.
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when a verbatim string is easier to read, when the file is shared with an
older C# project, or when the fix would alter significant line endings or whitespace.
