# SST2245 - Use while when a for loop has no initializer or increment

**Category:** ModernSyntax  
**Default severity:** Warning (enabled)  
**Code fix:** Yes (supports Fix All)

## Cause

A `for` loop has a condition but no initializer, variable declaration, or increment
in its header. A `while` loop expresses the same condition without empty clauses.

`for (;;)` is not reported because it has no condition. A loop that uses either of
the other header clauses is also left alone.

## Example

Before:

```csharp
int i = 0;
for (; i < 10; )
{
    i++;
}
```

After:

```csharp
int i = 0;
while (i < 10)
{
    i++;
}
```

## How to fix violations

**Rewrite the loop as a while loop** keeps the condition and body and removes the
two header semicolons. `continue` still checks the condition before the next iteration.
The fix also supports a single statement without body braces.

Body comments and comments before the loop are kept. Comments attached to the removed
semicolons can be lost; move them before the loop if they need to stay.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.SST2245.severity = error
```

The default severity is `warning`. Values are `error`, `warning`, `suggestion`,
`silent`, and `none` (disabled). There are no rule-specific options.
See [configuration](../CONFIGURATION.md).

## When to suppress

Suppress when keeping a family of related loops in the same form makes them easier
to compare. Otherwise, `while` states the loop's purpose more directly.
