# SST2250 — Join a declaration with its first assignment

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Default severity | Warning |
| Code fix | Yes (supports Fix All) |
| Default | Enabled |

## Cause

A single local variable is declared without a value, and the next statement assigns it
with `name = value`. Both statements must be directly inside the same brace block.

Declarations of several variables, assignments inside an `if` or loop, and assignments
separated from the declaration by another statement are not reported. Declarations
directly under a `case` label need their own brace block to be covered.

## Example

Before:

```csharp
public class Calculator
{
    public int Double(int seed)
    {
        int total;
        total = seed * 2;
        return total;
    }
}
```

After:

```csharp
public class Calculator
{
    public int Double(int seed)
    {
        int total = seed * 2;
        return total;
    }
}
```

## How to fix violations

The code fix moves the assigned expression onto the declaration and removes the assignment
statement. It keeps the declared type and the declaration's comments. The single fix can
drop comments attached to the assignment, so move those to the declaration first.

A directive such as `#region` between the statements prevents the code fix, but the
diagnostic is still reported. Join the statements manually only if their directive
placement permits it.

## Configuration

To report violations as errors, set:

```ini
[*.cs]
dotnet_diagnostic.SST2250.severity = error
```

There are no rule-specific options.

Severity values are `none`, `silent`, `suggestion`, `warning` and `error`. The default is `warning`. Use `none` to disable the rule.
See [Configuration](../CONFIGURATION.md) for details.

## When to suppress

Suppress when directives or comments need to keep the declaration separate from the
assignment, or when the initializer would use the variable before its declaration is complete.
