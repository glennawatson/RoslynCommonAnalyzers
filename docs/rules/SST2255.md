# SST2255 — Use string.IsNullOrEmpty

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Default severity | Warning |
| Code fix | Yes (supports Fix All) |
| Default | Enabled |

## Cause

Two comparisons test the same string for null and emptiness. The rule reports
`s == null || s.Length == 0` and `s == null || s == ""`, plus the corresponding
`!=` comparisons joined by `&&`.

Comparing with `""` can come before or after the null test. Reading `Length` must come
after the null test; the reverse order can throw on null and is left alone. Constants
can appear on either side of `==` or `!=`, and comparisons may have parentheses.

Both checks must use the same written string expression. Calls, indexers and non-string
values are left alone. Property and field reads can be reported.

## Example

Before:

```csharp
public class Checks
{
    public bool IsEmpty(string s) => s == null || s.Length == 0;
    public bool HasText(string s) => s != null && s != "";
}
```

After:

```csharp
public class Checks
{
    public bool IsEmpty(string s) => string.IsNullOrEmpty(s);
    public bool HasText(string s) => !string.IsNullOrEmpty(s);
}
```

## How to fix violations

The code fix replaces the whole test with `string.IsNullOrEmpty(value)`. For the `&&`
form it adds `!` before the call. It keeps comments outside the whole test, but comments
inside the removed comparisons can be lost.

The replacement reads the string expression once. If a property getter returns different
values on successive reads or performs work on each read, review that change before
applying the fix. `string.IsNullOrEmpty` does not treat spaces as empty text.

## Configuration

To report violations as errors, set:

```ini
[*.cs]
dotnet_diagnostic.SST2255.severity = error
```

There are no rule-specific options.

Severity values are `none`, `silent`, `suggestion`, `warning` and `error`. The default is `warning`. Use `none` to disable the rule.
See [Configuration](../CONFIGURATION.md) for details.

## When to suppress

Suppress when the separate checks make surrounding validation clearer, or when the code
needs the repeated reads of a property or field.
