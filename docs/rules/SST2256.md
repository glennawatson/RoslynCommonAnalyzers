# SST2256 — Call extension methods in instance form

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Default severity | Info |
| Code fix | Yes (supports Fix All) |
| Default | Enabled |

## Cause

An extension method is called through its static class, with the value it extends as the
first argument. The rule asks for that value before the dot, as in `value.Wrap(prefix)`.
It reports only when the shorter call selects the same extension method.

Ordinary static methods and calls already written in instance form are left alone.
The rule also skips a named first argument, a first argument marked `ref`, `in` or `out`,
and calls whose argument count differs from the declared parameter count. It does not
report calls where the extension is unavailable through the value or another method
would be selected.

## Example

Before:

```csharp
public static class Extensions
{
    public static string Wrap(this string value, string prefix) => prefix + value;
}

public class C
{
    public string Make(string s) => Extensions.Wrap(s, ">");
}
```

After:

```csharp
public static class Extensions
{
    public static string Wrap(this string value, string prefix) => prefix + value;
}

public class C
{
    public string Make(string s) => s.Wrap(">");
}
```

## How to fix violations

The code fix moves the first argument before the method name and removes it from the
argument list. It keeps the remaining arguments in order and adds parentheses where
needed: `Extensions.Wrap(a + b, ">")` becomes `(a + b).Wrap(">")`.

The rebuilt call can change spacing. Comments beside the removed class name, first
argument or commas can be lost; move them before accepting the fix.

## Configuration

To report violations as errors, set:

```ini
[*.cs]
dotnet_diagnostic.SST2256.severity = error
```

There are no rule-specific options.

Severity values are `none`, `silent`, `suggestion`, `warning` and `error`. The default is `suggestion`. Use `none` to disable the rule.
See [Configuration](../CONFIGURATION.md) for details.

## When to suppress

Suppress when showing the static class helps readers identify which extension library
provides the method, or when a set of static calls is easier to read in a consistent form.
