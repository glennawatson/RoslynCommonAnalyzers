# SST2258 — Drop a redundant delegate wrapper

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Default severity | Info |
| Code fix | Yes (supports Fix All) |
| Default | Enabled |

## Cause

A delegate creation such as `new Action(OnChanged)` wraps a method name. A delegate is
a value that refers to a method you can call later. Where the required delegate type is
already given, the method name can be used directly.

The rule checks initializers, returns, expression bodies, casts, and the right side of
`=`, `+=` or `-=`. It does not report wrappers passed as method arguments or used inside
a `+` or `-` expression. Wrappers around lambdas or existing delegate variables are also
left alone.

## Example

Before:

```csharp
using System;

public class C
{
    public Action Make()
    {
        Action action = new Action(OnChanged);
        return action;
    }

    private void OnChanged() { }
}
```

After:

```csharp
using System;

public class C
{
    public Action Make()
    {
        Action action = OnChanged;
        return action;
    }

    private void OnChanged() { }
}
```

## How to fix violations

The code fix removes `new DelegateType(...)` and leaves the method name, including any
object or type before that name. Comments inside the removed wrapper can be lost.

Keep a concrete delegate type where it is needed. For example, with a `var` declaration,
change the declared type to `Action` if removing `new Action(...)` leaves the compiler
unable to choose a type. A method name by itself does not preserve a custom delegate
type named only by the removed wrapper.

## Configuration

To report violations as errors, set:

```ini
[*.cs]
dotnet_diagnostic.SST2258.severity = error
```

There are no rule-specific options.

Severity values are `none`, `silent`, `suggestion`, `warning` and `error`. The default is `suggestion`. Use `none` to disable the rule.
See [Configuration](../CONFIGURATION.md) for details.

## When to suppress

Suppress when the wrapper is needed to choose a particular delegate type or overloaded
method, or when spelling out that type makes an event subscription clearer.
