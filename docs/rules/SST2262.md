# SST2262 — Use a regular string literal

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Severity | Info |
| Code fix | Yes (supports Fix All) |
| Default | Enabled |

## Cause

A single-line raw string literal contains no double quote, backslash, or control
character below a space, such as a tab or line break. A regular string literal
holds the same text with fewer quote marks.

Multiline raw strings, interpolated strings, and regular strings are not reported.
Raw strings require C# 11 or later.

## Example

Before:

```csharp
class Message
{
    public string Text => """plain text""";
}
```

After:

```csharp
class Message
{
    public string Text => "plain text";
}
```

## How to fix violations

The code fix replaces the raw literal with a regular literal. It preserves the
string value and comments before and after the literal.

## Configuration

The rule is enabled by default at Info severity (`suggestion` in `.editorconfig`).
There are no rule-specific options. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2262.severity = error
```

Set the severity to `none` to disable it. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when keeping a group of related strings in raw form makes them easier
to compare or edit, such as test inputs that also contain quotes or backslashes.
