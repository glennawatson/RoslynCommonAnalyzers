# SST2263 — Hoist a loop's guard condition into its header

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Severity | Info |
| Code fix | Yes (supports Fix All) |
| Default | Enabled |

## Cause

A `while (true)` or `for (;;)` loop puts its stopping condition at the start of
its body. The rule reports either of these shapes inside a loop with braces:

- The entire body is an `if` with a nonempty true branch and an `else` containing only `break;`.
- The first statement is an `if` with no `else` whose body contains only `break;`, followed by other statements.

The `break` can have its own braces. Loops with other header conditions or
`for` header operations are not reported. An empty true branch in the first
shape is also left alone.

## Example

Before:

```csharp
using System.Collections.Generic;

class QueueReader
{
    public void Drain(Queue<int> queue)
    {
        while (true)
        {
            if (queue.Count > 0)
            {
                queue.Dequeue();
            }
            else
            {
                break;
            }
        }
    }
}
```

After:

```csharp
using System.Collections.Generic;

class QueueReader
{
    public void Drain(Queue<int> queue)
    {
        while (queue.Count > 0)
        {
            queue.Dequeue();
        }
    }
}
```

## How to fix violations

The code fix moves the condition into a `while` header, including when the
original loop is `for (;;)`. It removes the guard and uses the remaining work
as the body, with indentation adjusted to fit.

For a leading `if (done) break;`, the header becomes `while (!done)`. A leading
`if (!ready) break;` becomes `while (ready)`. Comments attached to removed
guards, braces, or `break` statements can be lost; move any useful explanation
to the resulting loop.

## Configuration

The rule is enabled by default at Info severity (`suggestion` in `.editorconfig`).
There are no rule-specific options. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2263.severity = error
```

Set the severity to `none` to disable it. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an explicit exit check inside the body makes a state machine or
algorithm easier to follow alongside its other exit checks.
