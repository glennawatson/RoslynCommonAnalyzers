# SST2264 — Name the enum member instead of casting a number

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Severity | Warning |
| Code fix | Yes (supports Fix All) |
| Default | Enabled |

## Cause

An integer literal is cast to an enum, and its value matches exactly one named
member. Naming that member tells the reader what the number means.

Zero and parenthesized literals are included. The rule skips values with no
matching name, values shared by multiple members, and casts of variables or
other expressions. A combination of flags is reported only if exactly one
member names that combined value; the fix does not build a combination with `|`.

## Example

Before:

```csharp
using System.Text.RegularExpressions;

class Settings
{
    public RegexOptions Options => (RegexOptions)1;
}
```

After:

```csharp
using System.Text.RegularExpressions;

class Settings
{
    public RegexOptions Options => RegexOptions.IgnoreCase;
}
```

## How to fix violations

The code fix replaces the entire cast with `EnumType.Member`. It is offered only
when that name refers to the matching member at the use site. Comments before
and after the cast are kept; comments inside the cast can be lost.

## Configuration

The rule is enabled by default at Warning severity. There are no rule-specific
options. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2264.severity = error
```

Set the severity to `none` to disable it. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the numeric value is the point of the code, such as a test of a
file format or network protocol's enum numbering.
