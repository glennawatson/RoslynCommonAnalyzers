# SST2269 — Keep conditional-condition parentheses consistent

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Severity | Warning |
| Code fix | Yes (supports Fix All) |
| Default | Disabled (opt-in) |

## Cause

The condition before `?` in a `condition ? value : otherValue` expression has
parentheses that do not match the selected style.

The default style removes one pair around a single name or literal, such as
`(ready)` or `(true)`. It leaves larger conditions such as `(a && b)`, member
accesses such as `(item.Ready)`, and nested parentheses such as `((ready))` alone.
The `include` style reports any condition without outer parentheses.

## Example

With the rule enabled and the default style, before:

```csharp
class Choice
{
    public int Pick(bool ready) => (ready) ? 1 : 2;
}
```

After:

```csharp
class Choice
{
    public int Pick(bool ready) => ready ? 1 : 2;
}
```

## How to fix violations

The code fix removes the parentheses around a reported name or literal, or
wraps the condition in parentheses for `include`. It keeps the two result
expressions. Comments outside the condition are kept; removing parentheses can
drop comments inside them.

## Configuration

The rule is disabled by default. Enable it and choose a style in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2269.severity = error
stylesharp.SST2269.conditional_condition_parentheses = omit_when_single_token
```

| Value | Effect |
| --- | --- |
| `omit_when_single_token` (default) | Remove one pair around a single name or literal. |
| `include` | Wrap a condition that has no outer parentheses. |

`stylesharp.conditional_condition_parentheses` is the project-wide alternative.
A nonempty rule-specific value takes precedence. Values ignore case and
surrounding spaces; a missing or unrecognized choice uses `omit_when_single_token`.

Use severity `warning` for warnings or `none` to disable the rule.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Leave the rule disabled if both forms are acceptable. Suppress when parentheses
make a particular expression easier to scan with nearby conditions.
