# SST2272 — Keep Flags-enum values in one consistent style

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Severity | Warning |
| Code fix | Yes (supports Fix All) |
| Default | Disabled (opt-in) |

## Cause

A member of a `[Flags]` enum writes a single flag's value against the selected
style. A single flag is a power of two: `1`, `2`, `4`, `8`, and so on. The
default style writes these as shifts, such as `1 << 2` for `4`.

Only values from `1` through `1 << 30` are checked. Zero, negative values,
combinations such as `3`, larger flags, and members without a written value
are left alone. Enums without `System.FlagsAttribute` are not reported.

## Example

With the rule enabled and the default `shift` style, before:

```csharp
[System.Flags]
public enum Access
{
    None = 0,
    Read = 1,
    Write = 2,
    Execute = 4,
    All = 7,
}
```

After:

```csharp
[System.Flags]
public enum Access
{
    None = 0,
    Read = 1 << 0,
    Write = 1 << 1,
    Execute = 1 << 2,
    All = 7,
}
```

## How to fix violations

The code fix changes the member's value to `1 << n` or a decimal number with
the same value. It keeps the member name and comments before and after the
value. Comments inside a replaced shift expression can be lost.

## Configuration

The rule is disabled by default. Enable it and choose a style in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2272.severity = error
stylesharp.SST2272.enum_flag_value_style = shift
```

| Value | Effect |
| --- | --- |
| `shift` (default) | Replace numeric literals with `1 << n`. Hexadecimal and binary literals are included. |
| `decimal` | Replace a shift of the form `1 << n`, with a literal shift amount, with its decimal value. |

The `decimal` choice does not convert hexadecimal or binary literals. It also
leaves other expressions alone, including parenthesized shifts and shifts
starting with `1L` or `1U`.

`stylesharp.enum_flag_value_style` is the project-wide alternative. A nonempty
rule-specific value takes precedence. Values ignore case and surrounding
spaces; a missing or unrecognized choice uses `shift`.

Use severity `warning` for warnings or `none` to disable the rule.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when numeric spelling helps compare flags with a protocol, hardware
register, or external specification. Leave the rule disabled if the enum needs
a consistent hexadecimal or binary style.
