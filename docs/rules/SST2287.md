# SST2287 — Use a for loop when a while loop owns its counter

| Item | Value |
| --- | --- |
| Category | ModernSyntax |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A counter is declared just before a `while` loop. The loop tests it in the
condition and changes it at the end of the body. No code reads or changes the
counter after the loop. A `for` header puts these three parts together.

The declaration must give one variable a starting value. The loop body must
have braces and at least two statements. Its last statement must use `++`, `--`,
`+=`, or `-=` on the counter. The amount added or subtracted must not read it.

The remaining body must not write the counter or pass it by `ref` or `out`. A loop that jumps
its counter forward or backward during its work keeps the `while` form.

## Example

Bad:

```csharp
public class Printer
{
    public void Print(int count)
    {
        int i = 0;
        while (i < count)
        {
            System.Console.WriteLine(i);
            i++;
        }
    }
}
```

Corrected:

```csharp
public class Printer
{
    public void Print(int count)
    {
        for (int i = 0; i < count; i++)
        {
            System.Console.WriteLine(i);
        }
    }
}
```

A `continue` in this loop prevents the diagnostic. It skips the last step in a
`while`, but runs that step in a `for`. A `continue` in a nested loop is allowed.

## Code fix

The fix moves the declaration and final step into a `for` header. It removes
them from the body and leaves the other statements in place. The counter
becomes local to the loop. Fix All is supported.

The header gets spaces after its semicolons. Comments before the counter declaration are kept,
but comments attached to the `while` header, the removed declaration semicolon, or the final step
can be lost. Move those comments to a statement that remains before applying the fix.

## Configuration

There are no rule-specific options. The default severity is `warning`:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2287.severity = warning
```

Accepted values are `none`, `silent`, `suggestion`, `warning`, and `error`.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the condition and step describe a process more clearly as a `while`, or when a long
step expression makes the `for` header hard to read.
