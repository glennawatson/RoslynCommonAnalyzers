# SST2303 — Flags enums should declare bit values

| Item | Value |
| --- | --- |
| Category | Design |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

An enum marked `[Flags]` has a value that is neither zero nor a single bit, and that value either
has no explicit initializer or contains a bit with no separate member in the enum.

Use powers of two such as `1`, `2`, `4`, and `8` for separate flags. They can be combined with `|`
without overlapping. In a sequence numbered `0, 1, 2, 3`, the value `3` overlaps `1 | 2`.

## Example

Bad:

```csharp
using System;

[Flags]
public enum Status
{
    None,
    Active,
    Pending,
    Done,
}
```

Corrected when each status is an independent flag:

```csharp
using System;

[Flags]
public enum Status
{
    None = 0,
    Active = 1,
    Pending = 2,
    Done = 4,
}
```

## What is not reported

- Enums without `[Flags]`.
- Zero and single-bit values, including automatically numbered `0`, `1`, and `2`.
- Explicit combinations of separately declared bits, such as `ReadWrite = Read | Write` or
  `ReadWrite = 3` when the enum declares flags with values `1` and `2`.

A value such as `Mixed = 5` is reported if the enum has no separate flag for bit `4`.

## How to fix violations

Give independent flags separate bit values, or give an intended combination an explicit initializer.
If the enum represents one choice at a time, remove `[Flags]` instead.

There is no code fix. Renumbering values can break stored data, messages, and compiled callers.
Plan that migration before changing a published enum. Removing `[Flags]` keeps the numeric values
but can change how combined values are formatted as text.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository sets it
to `error`:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2303.severity = error
```

Accepted values are `none`, `silent`, `suggestion`, `warning`, and `error`.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when numeric values are fixed by an external protocol or a published data format. An
intentional mask such as `Everything = -1` may also need suppression when it includes undeclared bits.
