# SST2313 — Enums should use an allowed storage type

| Item | Value |
| --- | --- |
| Category | Design |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

An enum explicitly names a storage type that is not in the configured list. Storage means the
integer type that holds each enum value. The default allowed list contains only `int`.

The rule applies to private and nested enums as well as public ones. `[Flags]` does not exempt an enum.
An enum that does not name a storage type is never reported, even if the list excludes `int`.

## How to fix violations

Remove an unnecessary storage type, or add a deliberately chosen type to the allowed list.

Bad with the default configuration:

```csharp
public enum Level : byte
{
    Low,
    High,
}
```

Corrected, when no specific width is needed:

```csharp
public enum Level
{
    Low,
    High,
}
```

There is no code fix.

## Configuration

| Key | Values | Default |
| --- | --- | --- |
| `stylesharp.SST2313.allowed_enum_storage` | List of integer type names | `int` |
| `stylesharp.allowed_enum_storage` | Fallback list of integer type names | `int` |
| `dotnet_diagnostic.SST2313.severity` | `error`, `warning`, `suggestion`, `silent`, `none` | `warning` |

Use `sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long` or `ulong`. Their .NET names are also
accepted: `SByte`, `Byte`, `Int16`, `UInt16`, `Int32`, `UInt32`, `Int64` and `UInt64`. Matching ignores
case. Separate names with commas, semicolons, spaces or tabs.

A nonempty rule-specific list takes precedence over the general list. If it is unset or empty, the
general list applies. If both are unset or empty, the list is `int`. Unrecognized names do not allow
any storage type.

For example, to permit wider enums and report other explicit types as errors:

```ini
[*.cs]
stylesharp.SST2313.allowed_enum_storage = int, uint, long, ulong
dotnet_diagnostic.SST2313.severity = error
```

## When to suppress

Keep the chosen width when it is required by a file format, native API, measured memory layout or
more than 32 independent flags. Add that width to the allowed list if it is a project convention;
suppress the declaration if it is an isolated exception. Changing storage can break compatibility.
