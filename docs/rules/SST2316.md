# SST2316 — A disposal method needs its disposal interface

| Item | Value |
| --- | --- |
| Category | Design |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A class or struct, including a record, declares either of these public instance methods without
implementing the corresponding interface:

- A parameterless `void Dispose()` without `IDisposable`.
- A parameterless `DisposeAsync()` with any non-void return type, without `IAsyncDisposable`.

Code that disposes objects through an interface cannot use a matching method name alone.
The asynchronous check applies only when the project has `IAsyncDisposable` available.

## How to fix violations

Add the interface for the cleanup method.

Bad:

```csharp
public class Cache
{
    public void Dispose() { }
}
```

Corrected:

```csharp
using System;

public class Cache : IDisposable
{
    public void Dispose() { }
}
```

For asynchronous cleanup, `IAsyncDisposable` requires a non-generic, parameterless method returning
`System.Threading.Tasks.ValueTask`. A `Task`-returning method is reported too, but its return type
must be changed before it can implement the interface. A generic `Dispose<T>()` also needs a
non-generic method to implement `IDisposable`.

## Code fix

The fix adds `IDisposable` or `IAsyncDisposable` to the type's list of interfaces and formats the
edited type. It keeps the method body and does not change the method's signature. Check that the
method matches the interface, especially its return type and lack of generic type parameters.

If both interfaces are missing, the synchronous method is reported first. After that is fixed,
the asynchronous method can be reported.

## What is not reported

- `ref struct` types.
- Types declaring both a public parameterless `bool MoveNext()` and a public `Current` property.
- Static or nonpublic disposal methods, and methods with parameters.
- Types that already implement the matching interface, including through a base class.
- Methods declared only in a base class, and generated code.

## Configuration

The default severity is `warning`. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2316.severity = error
```

Use `none` to disable the rule. There are no rule-specific options.

## When to suppress

Suppress it when `Dispose` names an unrelated operation and adding a disposal interface would give
callers the wrong contract. Rename the method if the public API permits it.
