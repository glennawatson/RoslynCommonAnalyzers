# SST2324 — Do not declare a member more accessible than its containing type

| Item | Value |
| --- | --- |
| Category | Design |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A method, event, or nested type has an access modifier that allows more callers than its containing
type allows. All enclosing types count. For example, `public` on a method inside an `internal` class
does not make that method available outside the assembly.

```csharp
internal class Cache
{
    public void Clear() { }

    public class Entry { }
}
```

A `protected internal` method inside an `internal` class is also reported. A `protected` method in
that class is not: `protected` and `internal` allow different groups of callers.

## What is not reported

- Fields and properties, because frameworks can use their public access even inside a non-public type.
- Constructors, overrides, interface members, and enum members.
- Interface implementations, including a base member used by a derived class in the same assembly to
  implement an interface.
- TUnit lifecycle hooks marked `[Before]`, `[After]`, `[BeforeEvery]`, or `[AfterEvery]`.
- Members of restricted nested types when an occurrence of their name elsewhere in the enclosing type
  indicates that narrowing access could break a caller.
- Members whose access is already equal to or narrower than their container, and members of public
  types with no more restrictive enclosing type.

## How to fix violations

Match the containing type's access:

```csharp
internal class Cache
{
    internal void Clear() { }

    internal class Entry { }
}
```

If the member belongs in a public API, make the containing types public instead, after reviewing what
else that exposes.

## Code fix

**Narrow the member to its container's accessibility** replaces the access keywords with the
accessibility shown in the diagnostic. For example, it changes `public` to `internal` in the example
above, or to `private` for an unused member of a private nested type.

It keeps other modifiers, the member body, and documentation before the first modifier. It rewrites
spacing around the access keywords and can drop comments between modifiers. Review those comments
before accepting the edit. Fix All is available.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST2324.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable the rule.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when reflection or a framework requires the member's declared accessibility and the rule
does not recognize that requirement. A member can need to remain public even when its containing
type is internal.
