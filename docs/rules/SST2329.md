# SST2329 — Flags enums should declare a zero value

| Item | Value |
| --- | --- |
| Category | Design |
| Severity | Warning |
| Code fix | Yes (add `None = 0`) |
| Default | Enabled |

## Cause

An enum marked `[Flags]` has no member whose value is zero. Zero represents no flags being set and is
also the default value of an enum.

```csharp
using System;

[Flags]
public enum Access
{
    Read = 1,
    Write = 2,
}
```

Any zero-valued member satisfies the rule, whatever its name. An implicit zero, such as the first
member of an enum without assigned values, also counts. Enums without `[Flags]` are not reported.

## How to fix violations

Add a name for zero, usually `None`:

```csharp
using System;

[Flags]
public enum Access
{
    None = 0,
    Read = 1,
    Write = 2,
}
```

Callers can use `Access.None` instead of `(Access)0`. To test for no flags, compare with `Access.None`;
`HasFlag(Access.None)` is true for every value.

## Code fix

**Add 'None = 0'** inserts that member first and uses the existing member indentation. It retains
existing values and the first member's documentation. Fix All is available.

The fix is not offered when a directive such as `#if` or `#region` occurs inside the enum's braces.
Add the member manually in the appropriate place. If `None` already names a nonzero member, choose
another name manually; the fix always inserts `None`.

For an empty enum, the fix places the new member on its own line. It can remove comments before the
closing brace in that case, so preserve those comments when reviewing the edit.

## Configuration

The rule is enabled by default as a warning. It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST2329.severity = warning
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable the rule.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the enum must exactly match an external contract that excludes a named zero value.
Otherwise, adding a zero member makes the empty state easier to read without changing the other values.
