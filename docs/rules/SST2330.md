# SST2330 — Write a combined flags value as the members it combines

| Item | Value |
| --- | --- |
| Category | Design |
| Severity | Info |
| Code fix | Yes |
| Default | Enabled |

## Cause

A `[Flags]` enum member is assigned a number that exactly combines two or more of the enum's
individual flags. An individual flag has one bit set, such as `1`, `2`, or `4`.

```csharp
using System;

[Flags]
public enum Access
{
    None = 0,
    Read = 1,
    Write = 2,
    Execute = 4,
    All = 7,
}
```

The number `7` hides that `All` means `Read`, `Write`, and `Execute` together. Naming those flags also
keeps the combination in step if their values change.

The rule only reports a numeric literal. It does not report zero, an individual flag, an expression
such as `Read | Write`, or a number containing a bit with no individual flag declared. Enums without
`[Flags]` are not reported.

## How to fix violations

Use `|` to combine the named flags:

```csharp
using System;

[Flags]
public enum Access
{
    None = 0,
    Read = 1,
    Write = 2,
    Execute = 4,
    All = Read | Write | Execute,
}
```

## Code fix

**Name the combined flags** replaces only the number with member names joined by ` | `, in their
declaration order. It preserves comments around the number and keeps the resulting numeric value.
If several members name the same individual bit, the expression includes each matching name.
Fix All is available.

If a flag uses an escaped keyword name such as `@class`, review the replacement and restore its `@`
prefix where needed; the fix can write the keyword without that prefix.

## Configuration

The rule is enabled by default as a suggestion (`Info`). It has no rule-specific options.

```ini
[*.cs]
dotnet_diagnostic.SST2330.severity = suggestion
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable the rule.
See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when a member must retain a fixed number from an external format or protocol independently
of the other flags, or when keeping numeric values aligned with an external specification aids review.
