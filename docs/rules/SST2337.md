# SST2337 — Declare a fully known hierarchy as closed

| Item | Value |
| --- | --- |
| Category | Design |
| Severity | Warning |
| Default | Disabled (opt-in) |
| Code fix | No |
| Applies to | C# 15 or later |

## Cause

An abstract class or record is hidden from code outside its assembly, has at least two directly derived types in the project, and is not marked `closed`.

A closed base limits direct inheritance to its own assembly. This lets the compiler check whether a switch handles all its derived types.

## Example

Before:

```csharp
internal abstract class GateState
{
}

internal sealed class Shut : GateState
{
}

internal sealed class Open : GateState
{
}
```

After, with C# 15 and .NET 11 references:

```csharp
internal closed class GateState
{
}

internal sealed class Shut : GateState
{
}

internal sealed class Open : GateState
{
}
```

## What is not reported

- A base type visible outside its assembly.
- A base with fewer than two directly derived types.
- A concrete or static class, or a base already marked `closed`.
- Code using a language version below C# 15.

## How to fix violations

Replace `abstract` with `closed`. A closed class is implicitly abstract; do not combine the modifier with `abstract`, `sealed`, or `static`. The target framework must provide `System.Runtime.CompilerServices.IsClosedTypeAttribute`, available in .NET 11.

Closing the base does not close its descendants. Mark intermediate descendants `closed` too if switches need to cover their subclasses.

There is no code fix.

## Configuration

There are no rule-specific options. To enable the rule as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2337.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. Use `none` to disable it or `default` to restore the package default shown above.

## When to suppress

Leave the rule disabled or suppress it when other code must be able to extend the hierarchy, including another assembly allowed to access your internal types. Also suppress it when your target framework cannot support `closed`.
