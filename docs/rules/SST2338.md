# SST2338 — Declare a hand-rolled discriminated type as a union

| Item | Value |
| --- | --- |
| Category | Design |
| Severity | Warning |
| Default | Disabled (opt-in) |
| Code fix | No |
| Applies to | C# 15 or later, with runtime support for unions |

## Cause

A non-abstract class, struct, or record has both:

- Exactly one enum field or property whose name ends in `Kind`, `Tag`, `Case`, `Discriminator`, or `Type`. These endings are case-sensitive.
- Fields or properties holding at least two distinct reference types or nullable value types.

Only declared instance members count; indexers are excluded. Reference members count with or without a nullable annotation. By default, any nullable value-type payload excludes the whole type.

The values alongside the enum are its payloads. This shape often represents a choice: the enum says which value is present. A union represents that choice directly, so callers cannot set two alternatives at once. The rule does not check whether your values are actually mutually exclusive.

## Example

Before:

```csharp
#nullable enable

public enum PayloadKind
{
    Text,
    Bytes,
}

public sealed class Payload
{
    public PayloadKind Kind { get; set; }

    public string? Text { get; set; }

    public byte[]? Bytes { get; set; }
}
```

After, with C# 15 and runtime support for unions:

```csharp
public union Payload(string, byte[]);
```

## How to fix violations

Declare the alternatives as a union. Update constructors, property reads, and serialization code to use the new type. Read a union with a switch over its case types. If a case needs several values, give it a separate record type.

There is no code fix; changing the type requires updating its callers and data contracts.

The rule reports nothing if the project lacks `System.Runtime.CompilerServices.IUnion`, or if the type already implements that interface.

## Configuration

To enable the rule as an error while excluding nullable value-type payloads:

```ini
[*.cs]
dotnet_diagnostic.SST2338.severity = error
stylesharp.SST2338.report_value_type_payloads = false
```

| Key | Values | Default |
| --- | --- | --- |
| `stylesharp.SST2338.report_value_type_payloads` | `true`, `false` | `false` |
| `stylesharp.report_value_type_payloads` | `true`, `false` | `false` |

A valid rule-specific value takes precedence over the project-wide value. If it is missing or invalid, the project-wide value applies; if neither is valid, the default applies.

Set the option to `true` to include types with payloads such as `int?`. A union stores a value-type case as an object, which requires boxing: allocating an object to hold a copy of the value. Account for that cost before migrating.

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. Use `none` to disable it or `default` to restore the package default shown above.

## When to suppress

Suppress the rule when multiple payloads can be valid together, when an existing API or saved data requires the current shape, or when the union would add unwanted allocations.
