# SST2400 — Arguments should be passed in the parameter's order

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

Two arguments in a method call or object creation have each other's parameter names. The names suggest that the arguments are swapped, even though the call compiles.

Both arguments must be plain names, such as `source` and `target`. Names are compared without regard to case. The corresponding parameters must have the same type and the same `ref`, `out`, or `in` requirement.

## Example

Before:

```csharp
public sealed class Copier
{
    public void Copy(string source, string target)
    {
    }

    public void Run(string source, string target) => Copy(target, source);
}
```

After:

```csharp
public sealed class Copier
{
    public void Copy(string source, string target)
    {
    }

    public void Run(string source, string target) => Copy(source, target);
}
```

## What is not reported

- A call with any named argument.
- A call that omits optional arguments, or calls a method with a `params` parameter or variable argument list.
- A pair containing a computed expression or a qualified member access, such as `GetTarget()` or `this.Target`.
- A rotation of three or more arguments without a swapped pair.

## How to fix violations

The code fix exchanges the two reported argument expressions. Other arguments stay in place. Comments, spacing, and line breaks at each argument position stay at that position.

Review whether the swap matches your intent before accepting it.

## Configuration

There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2400.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. Use `none` to disable it or `default` to restore the package default shown above.

## When to suppress

If the reversed order is intentional, use named arguments, such as `Copy(source: target, target: source)`, to make that choice clear and remove the diagnostic. Suppress only when adding those names would obscure the code.
