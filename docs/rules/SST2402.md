# SST2402 — Instance members should not write to static fields

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

An instance constructor, method, finalizer, property, indexer, or event accessor assigns a static field declared by its type using `=`.

A static field is shared by instances of the type. Each assignment replaces the value seen by the other objects, so one object's construction or update can change another object's behavior.

## Example

Before:

```csharp
public sealed class Counter
{
    public static int Latest;

    public Counter(int value) => Latest = value;
}
```

After, when the value belongs to each object:

```csharp
public sealed class Counter
{
    public int Latest;

    public Counter(int value) => Latest = value;
}
```

## What is not reported

- Writes from static constructors, methods, or accessors.
- Compound assignments, increments, and `??=`.
- Assignments inside an `if` whose condition mentions the field's name.
- Writes to `[ThreadStatic]` fields.
- Writes inside lambdas or local functions declared in a constructor.

A lambda or local function declared in another instance member is checked. The exclusions do not establish that shared-state updates are safe across threads.

## How to fix violations

Remove `static` when each object needs its own value. If the value belongs to the type, initialize it in the field declaration, a static constructor, or an appropriate static member.

There is no code fix; changing who owns the value changes what callers see.

## Configuration

There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2402.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. Use `none` to disable it or `default` to restore the package default shown above.

## When to suppress

Suppress when an instance intentionally updates shared state and the API must remain an instance member. Make sure concurrent readers and writers use the required synchronization.
