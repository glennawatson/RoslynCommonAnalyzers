# SST2404 — Validate an iterator's arguments before it starts yielding

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes, for synchronous iterators |
| Default | Enabled |

## Cause

A method containing `yield` starts with argument checks that throw. An iterator's body runs when the caller starts reading the sequence, so these checks do not run when the method is called.

The rule checks leading `if` statements that end in a throw and calls such as `ArgumentNullException.ThrowIfNull(values)`. At least one leading check must read a method parameter. Checks that only inspect the object's state are not reported. A `yield` inside a local function does not make the outer method an iterator.

## Example

The null check runs when the caller starts a `foreach`, rather than when it calls `Doubled`:

```csharp
using System;
using System.Collections.Generic;

public sealed class Numbers
{
    public IEnumerable<int> Doubled(int[] values)
    {
        if (values is null)
        {
            throw new ArgumentNullException(nameof(values));
        }

        foreach (var value in values)
        {
            yield return value * 2;
        }
    }
}
```

Keep the checks in the public method and move the yielding code into a local function:

```csharp
using System;
using System.Collections.Generic;

public sealed class Numbers
{
    public IEnumerable<int> Doubled(int[] values)
    {
        if (values is null)
        {
            throw new ArgumentNullException(nameof(values));
        }

        return Iterator();

        IEnumerable<int> Iterator()
        {
            foreach (var value in values)
            {
                yield return value * 2;
            }
        }
    }
}
```

## Code fix

The fix keeps all leading checks in the method, adds `return Iterator();`, and moves the remaining statements into that local function. It chooses another name if `Iterator` is taken. The method's parameters and type parameters remain available inside the local function.

The fix formats the rewritten method and adds blank lines around the return. Comments immediately before the first moved statement are dropped; preserve any useful comment before accepting the edit. Methods with directives in the body are reported without a fix.

Async iterators are also reported without a fix. Split them by hand. If a cancellation token has `[EnumeratorCancellation]`, put that attribute on the local iterator's token parameter and pass the token through. The local-function form requires C# 7 or later.

## Configuration

The rule is enabled by default as a warning. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2404.severity = error
```

Severity values are `none`, `silent`, `suggestion`, `warning` and `error`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an existing API deliberately promises to validate only when enumeration starts, and moving the exception to the call would break that contract.
