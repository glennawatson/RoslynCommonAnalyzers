# SST2408 — A StringBuilder that is filled should be read

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A local `System.Text.StringBuilder` receives appended text, but nothing reads or uses the result. Building the text takes time and memory without producing the intended output.

Discarded calls to `Append`, `AppendLine`, `AppendFormat`, `AppendJoin`, `Insert`, `Remove`, `Replace` and `Clear` do not count as reads. Chained calls are included, and at least one append is required. Assigning a replacement builder to the local does not count as reading the old contents.

The rule skips fields and parameters. Reading a property, calling another method such as `ToString` or `CopyTo`, returning the builder, passing it elsewhere or using it in interpolation prevents a report.

## Example

The method builds a report and discards it:

```csharp
using System.Text;

public sealed class Reports
{
    public void Report(string[] lines)
    {
        var builder = new StringBuilder();
        foreach (var line in lines)
        {
            builder.AppendLine(line);
        }
    }
}
```

Return the completed string so the caller can use it:

```csharp
using System.Text;

public sealed class Reports
{
    public string Report(string[] lines)
    {
        var builder = new StringBuilder();
        foreach (var line in lines)
        {
            builder.AppendLine(line);
        }

        return builder.ToString();
    }
}
```

There is no code fix; return, store or write the result where it belongs. Calling `ToString()` and discarding its return value removes the diagnostic but still loses the output.

## Configuration

The rule is enabled by default as a warning. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2408.severity = error
```

Severity values are `none`, `silent`, `suggestion`, `warning` and `error`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress in a focused test or benchmark that deliberately measures appending without reading the result. For ordinary output code, use the text or remove the unused work.
