# SST2412 — A for loop should step its counter toward the bound

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A `for` loop increases its counter while testing `>` or `>=`, or decreases it while testing `<` or `<=`. The update moves away from the value that would stop the loop. The loop can keep running or fail to start.

The rule checks one update: `++`, `--`, or `+=`/`-=` with a positive integer literal. The counter may appear on either side of a single comparison. It skips `==` and `!=`, updates such as `i += delta`, multiple updates in the header, and bodies that also write to the counter.

## Example

The increasing counter uses a greater-than test:

```csharp
using System;

for (var i = 0; i > 10; i++)
{
    Console.WriteLine(i);
}
```

If the intended range is 0 through 10, change the comparison:

```csharp
using System;

for (var i = 0; i <= 10; i++)
{
    Console.WriteLine(i);
}
```

## Code fix

The fix replaces the comparison with its opposite:

| Before | After |
| --- | --- |
| `<` | `>=` |
| `<=` | `>` |
| `>` | `<=` |
| `>=` | `<` |

It preserves the operands, update, body, comments and spacing. Check whether the endpoint should be included before accepting the fix: changing `i > limit` produces `i <= limit`, which includes `limit`. If the comparison is correct, change the update direction by hand instead.

## Configuration

The rule is enabled by default as a warning. To report it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2412.severity = error
```

Severity values are `none`, `silent`, `suggestion`, `warning` and `error`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when the direction is deliberate and a separate exit or a changing bound controls termination. Document how the loop stops.
