# SST2416 — A remainder test should account for negative values

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes, for odd/even tests |
| Default | Enabled |

## Cause

A `%` result is compared with a non-zero integer constant using `==` or `!=`. The divisor is also a non-zero integer constant, and the value being divided has a signed type: `sbyte`, `short`, `int`, `long`, `nint`, `decimal` or `BigInteger`.

For example, this odd-number test fails for negative odd numbers. In C#, `-3 % 2` is `-1`.

```csharp
public sealed class Numbers
{
    public bool IsOdd(int n) => n % 2 == 1;
}
```

The comparison can be written either way round. Comparisons with zero, unsigned values, member reads named `Length` or `Count`, and member calls named `Abs` are not reported.

## How to fix violations

For an odd-number test on integers, compare the remainder with zero:

```csharp
public sealed class Numbers
{
    public bool IsOdd(int n) => n % 2 != 0;
}
```

For other remainder tests, decide how negative inputs should behave before changing the comparison.

## Code fix

The fix handles `% 2 == 1` and `% 2 != 1`, including reversed comparisons, when `2` and `1` are `int` constants. It offers no fix for other divisors or remainder values.

If the value's type has the matching helper, the fix uses `int.IsOddInteger(n)` or `int.IsEvenInteger(n)` for an `int`. These helpers are available in .NET 7 and later. Otherwise, it changes the tests to `n % 2 != 0` and `n % 2 == 0`, respectively. Comments inside the replaced comparison can be lost; check the preview.

## Configuration

The rule is enabled by default at `warning`. It has no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2416.severity = error
```

Allowed severity values are `error`, `warning`, `suggestion`, `silent` and `none`. See [Configuration](../CONFIGURATION.md) for scope and other configuration guidance.

## When to suppress

Suppress when negative inputs are ruled out by a checked contract, or when the test deliberately distinguishes positive and negative remainders. State that intent beside the test.
