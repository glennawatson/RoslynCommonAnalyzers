# SST2418 — The result of an immutable value's method should be used

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A call such as `date.AddDays(1);` stands alone and discards its return value. An immutable value cannot be changed in place, so this call leaves `date` unchanged:

```csharp
using System;

public sealed class Dates
{
    public void Advance(DateTime date)
    {
        date.AddDays(1);
    }
}
```

## What is reported

The rule checks calls written as `value.Method(...)` or `Type.Method(...)` that return a value and are used as a whole statement. It covers:

- Methods declared on `DateTime`, `TimeSpan`, `Guid` and `decimal`.
- Static methods on `Math`, `MathF`, `Convert`, `HashCode` and `BitConverter`.
- Methods returning `Span<T>`, `ReadOnlySpan<T>`, `Memory<T>` or `ReadOnlyMemory<T>`.
- Methods on a `readonly struct`, including a `readonly record struct`, that return that same type and have no `ref` or `out` parameters.

String methods, `Enumerable` methods, methods named `TryParse`, and methods marked `[Pure]` are excluded. Calls returning `void`, object creation, and calls whose results are used are also excluded.

## How to fix violations

Store the returned value, return it to the caller, or pass it to another method. For example:

```csharp
using System;

public sealed class Dates
{
    public DateTime Advance(DateTime date) => date.AddDays(1);
}
```

There is no code fix.

## Configuration

The rule is enabled by default at `warning`. It has no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2418.severity = error
```

Allowed severity values are `error`, `warning`, `suggestion`, `silent` and `none`. See [Configuration](../CONFIGURATION.md) for scope and other configuration guidance.

## When to suppress

Suppress when you intentionally call the method for validation, an expected exception, or another documented effect. A method on a readonly type can still change external state; check what the call does before removing it.
