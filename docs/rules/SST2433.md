# SST2433 — A caller-info parameter must come last and have a default

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A parameter marked with `[CallerMemberName]`, `[CallerFilePath]`, `[CallerLineNumber]`, or `[CallerArgumentExpression]` is followed by an ordinary parameter, or is not optional. The rule checks methods and constructors.

Caller-info attributes let the compiler supply information about the calling code when the caller omits that argument. Putting ordinary parameters after them makes positional calls easy to misread:

```csharp
using System.Runtime.CompilerServices;

public sealed class Logger
{
    public void Write([CallerMemberName] string caller = "", string message = "")
    {
    }
}
```

Here, `logger.Write("hello")` assigns `"hello"` to `caller` and leaves `message` empty.

## How to fix violations

Put ordinary parameters first, then the caller-info parameters. Give each caller-info parameter a default value:

```csharp
using System.Runtime.CompilerServices;

public sealed class Logger
{
    public void Write(string message, [CallerMemberName] string caller = "")
    {
    }
}
```

Several caller-info parameters may appear together at the end. A missing default is also a compiler error.

There is no code fix. When changing an existing parameter order, update every positional call. If external callers depend on the signature, retain it and introduce a replacement method or an overload with a distinct signature. Reordering parameters of the same types does not create a new overload.

## Configuration

The rule is enabled by default with severity `warning`. To treat it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2433.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. There are no rule-specific options.

## When to suppress

Suppress an ordering diagnostic on a public signature that must remain compatible. Use named arguments at call sites you control. Do not suppress a missing default; the compiler requires it.
