# SST2436 — Do not raise an event with a null sender or null args

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An event is raised through `.Invoke(...)` or `?.Invoke(...)` with a null sender or null event arguments. The event must take two parameters: an `object` sender and an `EventArgs` value or a value derived from `EventArgs`.

```csharp
using System;

public sealed class Widget
{
    public event EventHandler? Changed;

    public void Raise() => Changed?.Invoke(null, null!);
}
```

A handler that accesses a member of either null value will throw. The rule reports null written directly, inside parentheses, or as `null!`; it does not trace values stored in variables.

A static event may have a null sender, but null event arguments are still reported. Direct calls such as `Changed(this, null!)`, local delegate copies, and delegates with a different parameter pattern are not checked.

## How to fix violations

For an instance event, pass the object raising the event as the sender. Use `EventArgs.Empty` when there is no additional event data:

```csharp
using System;

public sealed class Widget
{
    public event EventHandler? Changed;

    public void Raise() => Changed?.Invoke(this, EventArgs.Empty);
}
```

For a custom event-arguments type, create an instance containing the data handlers need.

## Code fix

The fix replaces a reported null sender with `this`. It replaces null event arguments with `EventArgs.Empty` only when the parameter type is exactly `System.EventArgs`; there is no arguments fix for a derived type. Each reported null is a separate edit.

The fix writes `EventArgs.Empty` without adding `using System;`. If `EventArgs` is not in scope, add that import or qualify it as `System.EventArgs.Empty`. Comments around the replaced expression are kept; comments inside removed parentheses are not preserved.

## Configuration

The rule is enabled by default with severity `warning`. To treat it as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2436.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`. There are no rule-specific options.

## When to suppress

Suppress only when an established event contract explicitly allows null for the reported argument and subscribers handle it. A static event's null sender needs no suppression.
