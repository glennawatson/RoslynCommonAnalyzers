# SST2440 - Log values should follow the order of the template placeholders

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

Two log arguments appear in each other's placeholder positions. Log templates match values by position, so swapping arguments records each value under the wrong name.

This rule checks string literals passed to `Microsoft.Extensions.Logging` logging methods and `BeginScope`. It reports a pair only when each argument's name matches the other placeholder, ignoring case. Arguments must be names such as `userId` or member accesses such as `user.Id`. Every placeholder must have a distinct name, and the number of values must match the number of placeholders.

Calls used as values, repeated placeholder names, and rotations involving three or more values are not reported. Templates passed through variables or interpolation are not checked.

## Example

Incorrect:

```csharp
using Microsoft.Extensions.Logging;

public class Example
{
    public void Log(ILogger logger, int first, int second) =>
        logger.LogInformation("{First} {Second}", second, first);
}
```

Correct:

```csharp
using Microsoft.Extensions.Logging;

public class Example
{
    public void Log(ILogger logger, int first, int second) =>
        logger.LogInformation("{First} {Second}", first, second);
}
```

## Code fix

**Swap the values into the placeholders' order** swaps the two reported argument expressions. Other arguments and the template stay in place. Surrounding comments and line breaks stay at their argument positions, so review comments that describe a moved value. Swapping property accesses also changes their evaluation order.

## Configuration

There are no rule-specific options. The rule is enabled as a warning by default; this repository sets its severity to `error`.

```editorconfig
[*.cs]
dotnet_diagnostic.SST2440.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress a call only when the argument names are misleading and the values intentionally belong under the reported placeholders. Prefer clearer argument or placeholder names.
