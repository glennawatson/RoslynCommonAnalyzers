# SST2441 - A message template placeholder should name a property

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A log template contains an empty placeholder, whitespace, or a name containing characters other than `A-Z`, `a-z`, `0-9`, and underscores. For example, `{}` and `{Item Count}` are reported. Use a meaningful property name so log consumers can identify the value.

This rule checks string literals passed to `Microsoft.Extensions.Logging` logging methods and `BeginScope`. It ignores a leading `@` or `$` and any alignment or format suffix when checking the name, so `{@Order}`, `{$Id}`, and `{Count,5:N0}` are accepted.

Purely numeric placeholders, escaped braces (`{{` and `}}`), and unmatched braces are outside this rule. Templates passed through variables or interpolation are not checked.

## Example

Incorrect:

```csharp
using Microsoft.Extensions.Logging;

public class Example
{
    public void Log(ILogger logger, int count) =>
        logger.LogInformation("{Item Count} items", count);
}
```

Correct:

```csharp
using Microsoft.Extensions.Logging;

public class Example
{
    public void Log(ILogger logger, int count) =>
        logger.LogInformation("{Count} items", count);
}
```

## How to fix violations

Give each placeholder a property name. If the braces are literal text, escape them as `{{` and `}}` and remove any argument intended only for that placeholder.

There is no code fix because the intended property name must be chosen by the developer.

## Configuration

There are no rule-specific options. The rule is enabled as a warning by default; this repository sets its severity to `error`.

```editorconfig
[*.cs]
dotnet_diagnostic.SST2441.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress when an existing log format requires a name outside the accepted character set and your logging provider and consumers support it. Fix accidental empty or misspelled placeholders.
