# SST2448 - Delegate subtraction has order-dependent results

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

Delegate values are subtracted with `-`, or `-=` removes a delegate that appears to contain several handlers. A delegate can hold an ordered list of methods to call. Subtracting a combined delegate removes its list only if the same handlers appear together, in the same order, in the target. If the list appears more than once, only the last matching group is removed.

The rule reports binary delegate subtraction such as `a - b`. For `-=`, it reports inline combinations such as `a + b`, a name combined with `+` or `+=` in the same member, and delegate results from calls, conditional expressions, or `??`.

Ordinary `-=` removal of a method name or stored handler is not reported. Member accesses, array elements, conditional accesses, and explicit delegate constructions are also excluded. A field combined in another method is not tracked. These exclusions do not prove that a value holds only one handler. Removing a lambda is covered by [SST2449](SST2449.md).

## Example

Incorrect when both handlers must be removed regardless of their order:

```csharp
using System;

public class Example
{
    public void RunRemaining(Action target, Action first, Action second)
    {
        target -= first + second;
        target?.Invoke();
    }
}
```

Correct when `first` and `second` each hold one handler:

```csharp
using System;

public class Example
{
    public void RunRemaining(Action target, Action first, Action second)
    {
        target -= first;
        target -= second;
        target?.Invoke();
    }
}
```

## How to fix violations

Keep each subscription separately and remove handlers one at a time. If repeated subscriptions are allowed, decide how many occurrences must be removed; each single-handler removal removes only the last match.

There is no code fix because removing each handler separately changes the behavior of combined removal.

## Configuration

There are no rule-specific options. The rule is enabled as a warning by default; this repository sets its severity to `error`.

```editorconfig
[*.cs]
dotnet_diagnostic.SST2448.severity = warning
```

Severity values are `none`, `silent`, `suggestion`, `warning`, and `error`.

## When to suppress

Suppress when removing the last matching group is intentional, or when a returned delegate is guaranteed to hold one handler. Document and test the required subscription order.
