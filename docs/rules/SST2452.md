# SST2452 — A pure method should return a value

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A method has `System.Diagnostics.Contracts.PureAttribute` but returns `void`, `Task`, or `ValueTask`. `[Pure]` promises that the method changes no visible state. A method that makes that promise should return a result.

Methods with an `out` or `ref` parameter are not reported because they can return results through those parameters. Methods returning a value, including `Task<T>` and `ValueTask<T>`, are also excluded. An unrelated attribute named `Pure` does not trigger the rule.

## How to fix violations

Remove `[Pure]` when the method changes state or performs an action:

```csharp
using System.Diagnostics.Contracts;

public class Logger
{
    [Pure]
    public void Log(string message) => System.Console.WriteLine(message);
}
```

Corrected:

```csharp
public class Logger
{
    public void Log(string message) => System.Console.WriteLine(message);
}
```

If the method computes a value without changing state, return that value and keep `[Pure]`.

## Code fix

The fix removes `[Pure]`, including its brackets when it is the only attribute in that list. It keeps other attributes and the method's leading documentation comment. Comments inside the removed attribute or list can be lost. The method body and return type stay the same.

## Configuration

The rule is enabled by default as a warning. This repository sets it to an error:

```editorconfig
dotnet_diagnostic.SST2452.severity = error
```

Supported severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an external contract requires `[Pure]` on a method with no return value and you cannot change that contract. For code you control, remove the attribute or return the result.
