# SST2453 — A coalescing fallback that cannot change the value should be removed

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A `??` expression falls back to a constant null or repeats the value on its left. The operator uses its right side only when the left side is null, so these fallbacks usually add nothing.

The rule reports:

- A null fallback, including `null`, a constant with a null value, or a `default` expression that means null. The result must have the same type as the left side.
- The same name or member access written on both sides, such as `text ?? text` or `owner.Name ?? owner.Name`.

Repeated calls such as `Get() ?? Get()` and repeated index lookups are not reported. Neither is `??=`. A fallback that changes the result type, such as `intValue ?? (long?)null`, is excluded. A constant-null fallback whose left side is also a constant null is left to [SST2494](SST2494.md).

## How to fix violations

Remove the fallback if it serves no purpose:

```csharp
public class Names
{
    public string Read(string text) => text ?? null;
    public string Repeat(string text) => text ?? text;
}
```

Corrected:

```csharp
public class Names
{
    public string Read(string text) => text;
    public string Repeat(string text) => text;
}
```

If a real fallback was intended, supply one, such as `text ?? "anonymous"`.

## Code fix

The fix replaces the whole `??` expression with its left side. It keeps comments before and after the whole expression; comments around `??` or inside the removed fallback can be lost.

For a repeated property read, check whether its getter can return a different value on the second read. The fix removes that second read.

## Configuration

The rule is enabled by default as a warning. This repository sets it to an error:

```editorconfig
dotnet_diagnostic.SST2453.severity = error
```

Supported severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress a repeated-property report when the second getter call is intentional and changing it would alter behavior. A constant-null fallback rarely needs suppression; remove it or supply the intended default.
