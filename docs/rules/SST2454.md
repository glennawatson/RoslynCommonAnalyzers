# SST2454 — Do not dereference the result of an 'as' conversion

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

Code accesses a member or an index directly on the result of an `as` conversion, without checking for null. This includes method calls such as `(value as string).Trim()` and nullable values such as `(value as int?).Value`.

An `as` conversion returns null when the value has the wrong type. Reading a member or index through that null then throws an exception.

Extra parentheses do not avoid the report. Null-conditional access (`?.` or `?[]`), null tests, and ordinary casts are excluded. The rule does not check later uses of a result stored in a local variable.

## How to fix violations

Handle a failed conversion before using the result:

```csharp
public class Text
{
    public int Length(object value) => (value as string).Length;
}
```

Corrected, when a failed conversion should produce zero:

```csharp
public class Text
{
    public int Length(object value) => (value as string)?.Length ?? 0;
}
```

Use `value is string text` when only a successful conversion should run the following code. If the value must be a string, use `((string)value).Length`; a wrong type then throws `InvalidCastException`. A cast does not protect against a null input.

There is no code fix; choose how the program should handle a failed conversion.

## Configuration

The rule is enabled by default as a warning. This repository sets it to an error:

```editorconfig
dotnet_diagnostic.SST2454.severity = error
```

Supported severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an earlier check guarantees the value has the required type and is not null, and changing this expression would make the code less clear. Otherwise, handle null or use a cast that states the type requirement.
