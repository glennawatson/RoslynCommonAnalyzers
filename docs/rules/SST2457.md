# SST2457 — Wrapping a sequence sum in unchecked does not stop it throwing

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

`System.Linq.Enumerable.Sum` returns `int`, `long`, `int?`, or `long?` and is called inside an `unchecked` expression or block. Overloads that take a selector function are included.

`unchecked` controls arithmetic written inside it. It does not change arithmetic inside a method it calls. Integer `Sum` overloads check for overflow internally, so they can still throw `OverflowException`.

The rule excludes `float`, `double`, and `decimal` sums, `Queryable.Sum`, and methods named `Sum` that belong to other types. It also excludes calls whose nearest enclosing `checked` or `unchecked` block or expression is `checked`.

## How to fix violations

This wrapper does not make the sum wrap around on overflow:

```csharp
using System.Linq;

public class Ledger
{
    public int Total(int[] values) => unchecked(values.Sum());
}
```

If overflow should throw, remove the wrapper:

```csharp
using System.Linq;

public class Ledger
{
    public int Total(int[] values) => values.Sum();
}
```

If overflow should wrap around, perform the addition inside your own `unchecked` loop:

```csharp
public class Ledger
{
    public int Total(int[] values)
    {
        int total = 0;
        unchecked
        {
            foreach (int value in values)
            {
                total += value;
            }
        }

        return total;
    }
}
```

To allow larger totals, choose a wider result type, such as `values.Sum(value => (long)value)`. A wider type still has a limit; check that it can hold the expected total.

There is no code fix; choose the required overflow behavior.

## Configuration

The rule is enabled by default as a warning. This repository sets it to an error:

```editorconfig
dotnet_diagnostic.SST2457.severity = error
```

Supported severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when a larger `unchecked` block is needed for other arithmetic and `Sum` is intentionally allowed to throw. Make that choice clear near the call.
