# SST2458 — Bitwise operations should not be applied to a non-flags enum

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A bitwise operator is applied to an enum without `System.FlagsAttribute`. These operators combine or test individual bits in a number. Ordinary enum values represent alternatives, so a bitwise operation can produce a different member or a value with no name.

The rule reports `|`, `&`, `^`, `~`, `|=`, `&=`, and `^=`, including operations on nullable enum values. A chain such as `a | b | c` produces one report. Tests such as `(value & mask) != 0` are included.

Operations on `[Flags]` enums, equality comparisons, and operations on numbers or booleans are excluded. Casting enum values to integers before combining them is also excluded.

## How to fix violations

This enum does not declare its values as flags:

```csharp
public enum Color
{
    Red,
    Green,
    Blue,
}

public static class Palette
{
    public static Color Combine() => Color.Green | Color.Blue;
}
```

If the values are meant to combine, add `[Flags]` and give each independent flag its own bit:

```csharp
using System;

[Flags]
public enum Color
{
    None = 0,
    Red = 1,
    Green = 2,
    Blue = 4,
}

public static class Palette
{
    public static Color Combine() => Color.Green | Color.Blue;
}
```

Check stored data and callers before changing enum numbers. Adding `[Flags]` alone does not correct overlapping values. If the values are alternatives, use comparisons such as `color == Color.Green || color == Color.Blue`, or store multiple choices in a collection.

There is no code fix; the rule cannot decide whether to change the enum or the operation.

## Configuration

The rule is enabled by default as a warning. This repository sets it to an error:

```editorconfig
dotnet_diagnostic.SST2458.severity = error
```

Supported severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an enum from an external API defines independent bits but lacks `[Flags]`, and you cannot change its declaration. Confirm the numeric values before treating it as a flag set.
