# SST2461 — A combined flags value should only set bits the enum defines

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A combined value in a `[Flags]` enum includes a bit that no member defines on its own. For example, `7` combines bits with values `1`, `2`, and `4`; it includes an unnamed flag if only `1` and `2` are declared.

The diagnostic names the lowest missing bit, counting from zero. Zero and positive values with exactly one bit set are not reported. A lone `Reserved = 64` defines its own bit and needs no smaller flags.

Combinations are checked by their values. Naming another member does not exempt a combination if that member also contains undefined bits. Enums without a `Flags` or `FlagsAttribute` attribute are excluded.

## How to fix violations

This combined value includes the undefined bit with value `4`:

```csharp
using System;

[Flags]
public enum Access
{
    None = 0,
    Read = 1,
    Write = 2,
    All = 7,
}
```

Corrected, when only reading and writing are intended:

```csharp
using System;

[Flags]
public enum Access
{
    None = 0,
    Read = 1,
    Write = 2,
    All = Read | Write,
}
```

If the missing bit is intentional, declare its own member, such as `Execute = 4`. Otherwise, adding that member later would silently include it in the existing combination.

There is no code fix; choose whether to remove the bit or define its meaning.

## Configuration

The rule is enabled by default as a warning. This repository sets it to an error:

```editorconfig
dotnet_diagnostic.SST2461.severity = error
```

Supported severity values are `error`, `warning`, `suggestion`, `silent`, `none`, and `default`. There are no rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when an external format requires reserved bits in a combined value, or when an all-bits mask such as `All = -1` intentionally includes undefined flags. Document which future or reserved bits the value is meant to include.
