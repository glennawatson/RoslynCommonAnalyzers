# SST2465 — A for loop's body reassigns a variable its condition depends on

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A `for` loop body assigns to a local variable or parameter used by its condition. This can
stop the loop early or keep it running forever.

The rule checks loops with one comparison (`<`, `<=`, `>`, `>=`, `==`, or `!=`) and one counter
update in the header. The condition must read that counter and use only names, literals, and
operators; calls and member access such as `list.Count` are excluded. Conditions with more
than four variable-name occurrences are also excluded.

Assignments, compound assignments, `++`, and `--` directly in the body or a plain nested block
are reported. Writes inside an `if`, `switch`, nested loop, `try`, or lambda are not reported.
Neither are writes to fields or properties, or loops with no counter update in the header.

## Example

Resetting the bound stops this loop after its first pass:

```csharp
using System;

int n = 3;
for (int i = 0; i < n; i++)
{
    Console.WriteLine(i);
    n = 0;
}
```

Remove the assignment if all three passes are intended:

```csharp
using System;

int n = 3;
for (int i = 0; i < n; i++)
{
    Console.WriteLine(i);
}
```

If changing the counter or bound inside the body is part of the algorithm, consider a `while`
loop so the updates are easier to follow. There is no automatic code fix.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository sets
it to `error`. Set the severity in `.editorconfig`:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2465.severity = warning
```

Allowed values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable
the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when the body deliberately changes the counter or bound and keeping the `for` loop
makes the algorithm clearer. Check both its stopping condition and its counter updates first.
