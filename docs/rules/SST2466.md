# SST2466 — An empty finally clause should be removed

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A `finally` block contains no statements and no comments. It performs no cleanup and makes the
surrounding code harder to read. A block containing only a comment is not reported.

## Example

The empty clause adds no behavior:

```csharp
using System;

public class Worker
{
    public void Run()
    {
        try
        {
            Console.WriteLine(1);
        }
        finally
        {
        }
    }
}
```

With no `catch` to keep, remove the `try` as well:

```csharp
using System;

public class Worker
{
    public void Run()
    {
        Console.WriteLine(1);
    }
}
```

## Code fix

**Remove the empty finally clause** removes only `finally` when there is a `catch`.
Without a `catch`, it moves the `try` body's statements into the enclosing block and formats
that block. If the `try` is not directly inside a block, it replaces the `try` with its body,
keeping the body's braces.

Moving statements out of the `try` removes their separate local-variable scope. Review local
names and `using` declarations whose lifetime depended on that scope. Comments attached to
removed keywords or braces can be lost; comments on retained statements remain.

The fix is not offered when the `try` statement contains preprocessor directives, such as
`#if` or `#region`. Remove the empty clause by hand while preserving those directives.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository sets
it to `error`. Set the severity in `.editorconfig`:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2466.severity = warning
```

Allowed values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable
the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress only when an empty clause must remain to match a required code template. If cleanup
is missing, add it. If nothing needs cleanup, remove the clause.
