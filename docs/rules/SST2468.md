# SST2468 — A partial method with no implementation is silently discarded

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A `partial void` method has no implementation, no access modifier such as `private`, and no
`out` parameters. The compiler removes this optional method and all calls to it. Expressions
passed as its arguments are not evaluated either.

Static methods and methods with ordinary or `ref` parameters are included. An implementation
in another part of the same partial type satisfies the rule, even when it is in another file.
A partial method with an access modifier, a return value, or an `out` parameter needs an
implementation to compile; this rule does not report those forms.

## Example

Calling `Set` does not run `OnChanged`:

```csharp
public partial class Widget
{
    partial void OnChanged();
    public void Set() => OnChanged();
}
```

Add the intended implementation:

```csharp
using System;

public partial class Widget
{
    partial void OnChanged();
    public void Set() => OnChanged();
}

public partial class Widget
{
    partial void OnChanged() => Console.WriteLine("Changed");
}
```

If the hook is not needed, remove its declaration and calls. There is no automatic code fix.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository sets
it to `error`. Set the severity in `.editorconfig`:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2468.severity = warning
```

Allowed values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable
the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when the method is an intentional optional hook and doing nothing is valid for this
build. Check that no required work is hidden in the call or its arguments.
