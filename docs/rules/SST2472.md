# SST2472 — An exported contract type must be implemented by the exporting type

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A type has `[Export(typeof(...))]` for a type it does not implement or inherit. The type in
`typeof(...)` is the contract: the interface or class that consumers ask the composition
container to provide. The attribute compiles, but the container cannot use this export to
satisfy that contract.

Both `System.ComponentModel.Composition` and `System.Composition` exports are supported,
including `Export(contractType: typeof(IService))`. Exporting a type as itself, a base type,
or an interface it implements is allowed. An interface implemented by a base class also counts.
`[Export]` without a contract type is not reported. The rule requires the MEF export types
to be available in the project.

## Example

These examples use `System.ComponentModel.Composition`. `Widget` does not provide `IService`:

```csharp
using System.ComponentModel.Composition;

public interface IService { }

[Export(typeof(IService))]
public class Widget { }
```

Implement the contract if that is the intended service:

```csharp
using System.ComponentModel.Composition;

public interface IService { }

[Export(typeof(IService))]
public class Widget : IService { }
```

Otherwise, change the export to a contract the class actually provides and update the matching
imports. There is no automatic code fix.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository sets
it to `error`. Set the severity in `.editorconfig`:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2472.severity = warning
```

Allowed values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable
the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress for a test that deliberately declares an invalid export to check composition failures.
For an export used by the application, fix the contract mismatch.
