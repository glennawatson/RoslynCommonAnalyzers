# SST2473 — A shared export part should be obtained from the container, not constructed with 'new'

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

Code uses `new Service()` or target-typed `new()` to construct an exported type explicitly
marked as shared. A composition container reuses a shared instance within its lifetime or
sharing boundary. Direct construction creates a separate instance outside that container.

The rule recognizes `[Export]` with `[PartCreationPolicy(CreationPolicy.Shared)]` from
`System.ComponentModel.Composition`, or `[Export]` with `[Shared]` from `System.Composition`.
Custom attributes derived from either `ExportAttribute` also count as exports.

Types with no export, no explicit shared marker, or only `CreationPolicy.NonShared` or
`CreationPolicy.Any` are not reported. The rule requires the relevant MEF attributes to be
available in the project.

## Example

This consumer creates its own service:

```csharp
using System.ComponentModel.Composition;

public interface IService { }

[Export(typeof(IService))]
[PartCreationPolicy(CreationPolicy.Shared)]
public class Service : IService { }

public class Consumer
{
    public IService Create() => new Service();
}
```

Import the service and obtain the consumer through the container:

```csharp
using System.ComponentModel.Composition;

public interface IService { }

[Export(typeof(IService))]
[PartCreationPolicy(CreationPolicy.Shared)]
public class Service : IService { }

[Export]
public class Consumer
{
    [ImportingConstructor]
    public Consumer(IService service) => Service = service;

    public IService Service { get; }
}
```

If separate instances are intended, review the service's creation policy and its callers.
There is no automatic code fix.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository sets
it to `error`. Set the severity in `.editorconfig`:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2473.severity = warning
```

Allowed values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable
the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress for an isolated unit test that needs to construct the service directly, or for code
that deliberately owns a separate instance and supplies all its dependencies. Do not assume
that manually created instances share state or lifetime with the container's instance.
