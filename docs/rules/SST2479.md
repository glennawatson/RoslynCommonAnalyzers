# SST2479 — A delegate that outlives a loop should not capture the loop's changing variable

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A lambda, anonymous method, or local function uses a local variable changed by a `for`,
`while`, or `do` loop and is passed or stored for later use. A delegate keeps access to the
variable itself, not a copy of its value at creation time. Calls made after the loop read
its final value. Work scheduled during the loop can also read intermediate values.

The variable must be declared outside the loop body and changed by an assignment, `++`, `--`,
or a `ref` or `out` argument in the body or the `for` header's update expressions.

## What is reported

For lambdas and anonymous methods, the rule checks:

- Arguments to `Add`, `AddRange`, `AddFirst`, `AddLast`, `Insert`, `Enqueue`, `Push`, and `TryAdd`.
- Arguments to `Task.Run`, `Factory.StartNew`, and `ThreadPool.QueueUserWorkItem`.
- The right side of `+=`, including event subscriptions.
- Assignments through member or element access, such as `this.Handler` or `handlers[i]`.
- `yield return` expressions.

Local functions declared inside the loop are checked when passed by name to the listed
methods. Method names are recognized without checking whether their implementations store
the delegate. Storing a delegate in a local and passing that local later is not checked.

A per-iteration local copy, a `foreach` iteration variable, an unchanged local, or a captured
parameter or field is not reported. Directly invoking the delegate inside the loop and
returning it with ordinary `return` are also outside these checks.

## Example

All three handlers print `3`:

```csharp
using System;
using System.Collections.Generic;

var handlers = new List<Action>();
for (int i = 0; i < 3; i++)
{
    handlers.Add(() => Console.WriteLine(i));
}

foreach (var handler in handlers)
{
    handler();
}
```

Capture a new local on each iteration to print `0`, `1`, and `2`:

```csharp
using System;
using System.Collections.Generic;

var handlers = new List<Action>();
for (int i = 0; i < 3; i++)
{
    int copy = i;
    handlers.Add(() => Console.WriteLine(copy));
}

foreach (var handler in handlers)
{
    handler();
}
```

There is no automatic code fix.

## Configuration

There are no rule-specific options. The default severity is `warning`; this repository sets
it to `error`. Set the severity in `.editorconfig`:

```editorconfig
[*.cs]
dotnet_diagnostic.SST2479.severity = warning
```

Allowed values are `error`, `warning`, `suggestion`, `silent`, and `none`. Use `none` to disable
the rule. See [Configuration](../CONFIGURATION.md) for shared settings.

## When to suppress

Suppress when every delegate is meant to observe the same changing variable. Also suppress
when a method with a recognized name runs the delegate immediately and does not retain it.
Check the method's behavior before relying on that exception.
