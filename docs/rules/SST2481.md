# SST2481 — GetHashCode should not fold in the base object identity hash

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A parameterless `GetHashCode` override uses `base.GetHashCode()` as part of a larger
calculation, and that call reaches `object.GetHashCode()`. Storing the base hash in
a local variable is also reported.

The object hash identifies an instance, not its field values. Mixing it into a
value hash can give equal objects different hashes. A dictionary or hash set can
then fail to find an equal key.

The rule does not report a call to a base class's own override, a struct, or an
override that returns only `base.GetHashCode()`. Calls inside nested functions are
also excluded.

## Example

Bad: equal numbers can have different hashes.

```csharp
public sealed class Number
{
    public Number(int value) => Value = value;
    public int Value { get; }

    public override bool Equals(object obj) => obj is Number other && Value == other.Value;
    public override int GetHashCode() => base.GetHashCode() ^ Value.GetHashCode();
}
```

Corrected: hash the value that `Equals` compares.

```csharp
public sealed class Number
{
    public Number(int value) => Value = value;
    public int Value { get; }

    public override bool Equals(object obj) => obj is Number other && Value == other.Value;
    public override int GetHashCode() => Value.GetHashCode();
}
```

There is no code fix. Choose the hash fields to match the equality check.

## Configuration

The default severity is `warning`. There are no rule-specific options. To treat
the diagnostic as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2481.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress only when equality intentionally depends on object identity and the hash
uses only state that cannot change. Do not suppress for a type whose separate
instances can compare equal by value.
