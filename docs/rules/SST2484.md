# SST2484 — A raw handle read through DangerousGetHandle is not reference-counted

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

Code calls the parameterless `DangerousGetHandle()` method on `SafeHandle` or a
derived handle type. The rule reports every such call, including calls protected
by `DangerousAddRef`, null-conditional calls, and inherited calls within a handle
class. It does not report methods on unrelated types.

The returned `IntPtr` does not keep the operating-system resource open. Another
thread can dispose the handle while the raw value is in use. The operating system
can then reuse that value for a different resource.

## Example

Bad: the handle can close while `read` uses its raw value.

```csharp
using System;
using System.Runtime.InteropServices;

public static class Reader
{
    public static void Read(SafeHandle handle, Action<IntPtr> read)
    {
        read(handle.DangerousGetHandle());
    }
}
```

Corrected: keep a counted reference until all uses of the raw value finish.
The `read` callback must finish using the value before it returns. This protected
call still receives the diagnostic; suppress it locally after checking its lifetime.

```csharp
using System;
using System.Runtime.InteropServices;

public static class Reader
{
    public static void Read(SafeHandle handle, Action<IntPtr> read)
    {
        bool added = false;
        try
        {
            handle.DangerousAddRef(ref added);
            read(handle.DangerousGetHandle());
        }
        finally
        {
            if (added)
            {
                handle.DangerousRelease();
            }
        }
    }
}
```

Where possible, pass the `SafeHandle` directly to the native API declaration so
the runtime keeps it open for the call.

There is no code fix. The required lifetime depends on how the raw handle is used.

## Configuration

The default severity is `warning`. There are no rule-specific options. To treat
the diagnostic as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2484.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress a call when a successful `DangerousAddRef` protects all uses of the raw
value and a matching `DangerousRelease` runs in `finally`. If native work continues
after the call returns, the counted reference must last until that work finishes.
Keeping the wrapper reachable alone does not prevent another thread from disposing it.
