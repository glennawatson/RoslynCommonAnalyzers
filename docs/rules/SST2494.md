# SST2494 — Null-coalescing over a constant null always takes the right operand

| Item | Value |
| --- | --- |
| Category | Correctness |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

The left side of `left ?? right` is known to be null at compile time, so the
expression always chooses `right`. Examples include `null`, `default(string)`,
and a `const` whose value is null, including casts or parentheses around them.

A variable, non-constant field, or method call is not reported merely because it
holds or returns null at runtime. The rule does not check `??=`.

## Example

Bad: the fallback is always selected.

```csharp
public static class Names
{
    public static string GetName(string fallback) => default(string) ?? fallback;
}
```

Corrected: use the selected value directly.

```csharp
public static class Names
{
    public static string GetName(string fallback) => fallback;
}
```

If the left side was meant to read a value that can change, replace it with that
value instead of accepting the simplification.

## Code fix

The fix replaces the entire `left ?? right` expression with `right`. It does not
remove a constant declaration used on the left. Comments outside the expression
are kept; comments on the removed operand, operator, or before the right operand
can be lost.

The right side still runs each time, but removing the left side can change the
expression's type. Review assignments using `var` and calls with multiple
overloads. Keep an explicit cast when the original type is needed.

## Configuration

The default severity is `warning`. There are no rule-specific options. To treat
the diagnostic as an error:

```ini
[*.cs]
dotnet_diagnostic.SST2494.severity = error
```

Severity values are `error`, `warning`, `suggestion`, `silent`, and `none`.
See [Configuration](../CONFIGURATION.md) for severity settings.

## When to suppress

Suppress when shared source intentionally uses a constant that is null for only
some build configurations and the fallback must remain. For ordinary code,
remove the redundant choice or correct the left operand.
