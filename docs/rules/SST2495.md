# SST2495 — A flags combination should not repeat bits another operand already sets

| Item | Value |
| --- | --- |
| Category | Correctness |
| Default severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A `|` expression combines values from a `[Flags]` enum, and one value adds no bits
that another value does not already contain. For example, `ReadWrite` already
includes `Read`.

Only nonzero constant values are compared. Variables and zero-valued members such
as `None` are ignored. Other constant values in the same expression can still be
reported. When two values set the same bits, only the later one is reported.
Integer expressions and enums without `[Flags]` are not reported.

## Example

Before:

```csharp
[System.Flags]
public enum Access { Read = 1, Write = 2, ReadWrite = Read | Write }

public class Permissions
{
    public Access GetAccess() => Access.ReadWrite | Access.Read;
}
```

After:

```csharp
[System.Flags]
public enum Access { Read = 1, Write = 2, ReadWrite = Read | Write }

public class Permissions
{
    public Access GetAccess() => Access.ReadWrite;
}
```

If you meant to include a different flag, replace the repeated value with that flag.

## Code fix

The fix removes the reported value and its adjacent `|`. The combined value stays
the same. Comments within the removed part can be lost; move any useful comment
before accepting the fix.

## Configuration

Set the severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2495.severity = error
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`. There are no
rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when listing a flag separately is intentional and makes a required set of
permissions clearer. Check that a different flag was not omitted by mistake.
