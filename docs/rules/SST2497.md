# SST2497 — Do not forward a member to itself

| Item | Value |
| --- | --- |
| Category | Correctness |
| Default severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A method or local function with an `=>` body calls itself and passes every
parameter back unchanged, in the same order. Calls through `this` and calls with
no parameters are included. The repeated calls have no stopping point and can
terminate the process with a stack overflow.

## Example

Before:

```csharp
public class Base
{
    public virtual int Scale(int value) => value;
}

public class Derived : Base
{
    public override int Scale(int value) => Scale(value);
}
```

After:

```csharp
public class Base
{
    public virtual int Scale(int value) => value;
}

public class Derived : Base
{
    public override int Scale(int value) => base.Scale(value);
}
```

## How to fix violations

Call the intended method: use `base.` for a base implementation, change the
arguments to select another overload, or correct the method name.
There is no automatic code fix because the intended target is unknown.

## What is not reported

Block bodies, conditional bodies, named arguments, and reordered or changed
arguments are not reported. An unreported recursive call can still be faulty;
check that it has a stopping condition.

## Configuration

Set the severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2497.severity = error
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`. There are no
rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress only for a deliberate stack-overflow test that runs in a separate process.
For application code, correct the call.
