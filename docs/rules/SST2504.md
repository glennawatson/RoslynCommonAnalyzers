# SST2504 — A test class should declare at least one test method

| Item | Value |
| --- | --- |
| Category | Testing |
| Default severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A non-abstract class has MSTest's `[TestClass]` or NUnit's `[TestFixture]` attribute
but has no test methods of its own or inherited from a base class. Setup and helper
methods alone do not make it a useful test class.

## Example

Before:

```csharp
using Microsoft.VisualStudio.TestTools.UnitTesting;

[TestClass]
public class ArithmeticTests
{
    public void Adds()
    {
        Assert.AreEqual(2, 1 + 1);
    }
}
```

After:

```csharp
using Microsoft.VisualStudio.TestTools.UnitTesting;

[TestClass]
public class ArithmeticTests
{
    [TestMethod]
    public void Adds()
    {
        Assert.AreEqual(2, 1 + 1);
    }
}
```

## How to fix violations

Add the missing test attribute or write the intended tests. If the class only
provides shared setup for derived test classes, make it `abstract`. Remove an
unused class, or remove its test-class attribute if it only holds helpers.

There is no automatic code fix.

## What is not reported

Abstract classes, classes with a recognized test method, and classes without
either test-class attribute are excluded. xUnit and TUnit classes without those
attributes are outside this rule's scope.

A class is also excluded if any base class declares a test method or carries
either test-class attribute. A marked base class is enough, even if it has no
test methods. Tests declared in another part of a partial class count too.

## Configuration

Set the severity in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.SST2504.severity = error
```

Values are `error`, `warning`, `suggestion`, `silent`, and `none`. There are no
rule-specific options. See [Configuration](../CONFIGURATION.md).

## When to suppress

Suppress when a custom test runner supplies tests that the rule cannot recognize,
and you have checked that the class actually runs tests. Shared setup alone is
usually better expressed as an abstract base class.
