# SST2509 — Give test methods a supported signature

| Item | Value |
| --- | --- |
| Category | Testing |
| Severity | Warning |
| Code fix | No |
| Default | Enabled |

## Cause

A method with an xUnit, NUnit, MSTest, or TUnit test attribute has one of these shapes:

- It is not public. This check applies to xUnit, NUnit, and MSTest; TUnit is exempt.
- It has type parameters but no method parameters from which to infer their types.
- It returns a type other than `void`, `Task`, `Task<T>`, `ValueTask`, or `ValueTask<T>` from
  `System.Threading.Tasks`. Other types that can be awaited are still reported.

These shapes can prevent the runner from executing the test as intended. Check the requirements
of your framework and runner version.

Static methods are allowed by this rule. Generic methods with parameters are also allowed;
the rule does not check whether a data source supplies values for them. A return type that the
compiler cannot resolve is not reported as an invalid return type.

## Example

This test is private:

```csharp
using Xunit;

public class Tests
{
    [Fact]
    private void Adds()
    {
        Assert.Equal(3, 1 + 2);
    }
}
```

Make it public:

```csharp
using Xunit;

public class Tests
{
    [Fact]
    public void Adds()
    {
        Assert.Equal(3, 1 + 2);
    }
}
```

## How to fix violations

Follow the reason in the diagnostic: make the method public, remove unused type parameters or
supply typed test data, or use a supported return type. For an asynchronous test, return `Task`
or `ValueTask` so the runner can wait for it to finish.

There is no code fix.

## Configuration

There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2509.severity = error
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, `none`, or `default`.
Use `none` to disable the rule or `default` to restore its default setting.

## When to suppress

Suppress when your runner supports the reported signature and you have verified that it discovers
and executes the test, including its assertions.
