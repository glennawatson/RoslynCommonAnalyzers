# SST2701 — Make JavaScript-invokable methods public

| Item | Value |
| --- | --- |
| Category | Frameworks |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

A method marked `[Microsoft.JSInterop.JSInvokable]` is not public. JavaScript interop cannot find
it when the call is made.

The rule checks static and instance methods, including methods with no accessibility modifier.
It excludes explicit interface implementations. Methods without the attribute and unrelated
attributes named `JSInvokable` are not reported. The rule requires the JavaScript interop library.

## Example

This method cannot be called through JavaScript interop:

```csharp
using Microsoft.JSInterop;

public class Widget
{
    [JSInvokable]
    private void Ping() { }
}
```

Make it public:

```csharp
using Microsoft.JSInterop;

public class Widget
{
    [JSInvokable]
    public void Ping() { }
}
```

## Code fix

The fix changes the method's accessibility to `public`, adding the modifier if it was omitted.
It keeps the method body and attributes. It supports Fix All.

If JavaScript should not call the method, remove `[JSInvokable]` yourself instead.

## Configuration

There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2701.severity = error
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, `none`, or `default`.
Use `none` to disable the rule or `default` to restore its default setting.

## When to suppress

Suppress only when a custom invocation mechanism deliberately supports the non-public method.
For standard JavaScript interop, make it public or remove the attribute.
