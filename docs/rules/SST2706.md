# SST2706 — Set the Windows Forms entry thread's apartment

| Item | Value |
| --- | --- |
| Category | Frameworks |
| Severity | Warning |
| Code fix | Yes |
| Default | Enabled |

## Cause

An executable that references Windows Forms has an explicit entry-point method named `Main`
with neither `[System.STAThread]` nor `[System.MTAThread]`.

Windows Forms uses Windows COM services for features such as the clipboard, drag-and-drop,
and common dialogs. These features need a thread configured as a single-threaded apartment
(STA). Without the attribute, the entry thread starts in a multithreaded apartment and those
features can fail.

Only the actual entry point is checked. Class libraries, other methods named `Main`, and
programs that use top-level statements are excluded. A reference to Windows Forms is enough
to trigger the check, even if the program does not show a window. The rule reports nothing
when Windows Forms or `STAThreadAttribute` is unavailable.

## Example

This entry point does not declare an apartment:

```csharp
using System.Windows.Forms;

public static class Program
{
    public static void Main()
    {
        Application.Run(new Form());
    }
}
```

Add the STA attribute:

```csharp
using System.Windows.Forms;

public static class Program
{
    [System.STAThread]
    public static void Main()
    {
        Application.Run(new Form());
    }
}
```

## Code fix

The fix inserts `[System.STAThread]` on its own line before `Main` and any existing method
attributes. It preserves the leading comments, indentation, and line-ending style. It supports
Fix All.

If the entry thread deliberately needs a multithreaded apartment, add `[System.MTAThread]`
yourself. That satisfies the rule but does not make STA-only UI features work on that thread.

## Configuration

There are no rule-specific options. To report violations as errors:

```ini
[*.cs]
dotnet_diagnostic.SST2706.severity = error
```

Severity accepts `error`, `warning`, `suggestion`, `silent`, `none`, or `default`.
Use `none` to disable the rule or `default` to restore its default setting.

## When to suppress

Suppress when the executable references Windows Forms only for helper types, or runs its UI on
a separate STA thread, and the entry thread does not use features that require STA.
